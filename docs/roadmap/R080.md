**Two AL comment-strippers existed in two packages, and they disagreed about string literals.** `stripAlComments` (`packages/schemata/src/project.ts`) tracked strings but left their CONTENTS intact; `maskNonCode` (`packages/runner/src/discovery.ts`, R79) blanked the contents too, because a literal `codeunit 50100 "Sales Post"` has the same shape as a header. Written three weeks apart, in one codebase, for one class of bug, neither knowing about the other. The row warned the fix is NOT a blind merge: `stripAlComments` feeds `objectHeadersOf`, so widening it changes mutant ATTRIBUTION.
