**Filed 2026-11-05 by lethal-bugs, from GitHub SShadowS/LethAL#50.** Related: [[R196]], [[R446]], [[R480]], [[R294]], [[R810]],
[[R830]], [[R831]], [[R832]].

**What.** In `while Pos > 0 do begin ...; Text := Text.Substring(Pos + 2); Pos := Text.IndexOf('{{'); end`, the write to `Pos`
is refused, but the write to `Text`, which only the step reads, is not. `remove-assignment` of it makes a real hang. On BC 29 on
Linux that quarantined the reporter's run (#49): 72 of 359 mutants scored, then exit 3.

**Cause.** `loopExitParts` called `indirectFeeds` only when the condition read no name and called nothing (R480's boundary B1).

**Plan.** Follow the feeds for every condition that does not name a cursor method, to a fixpoint, by name, and take the guards
around a followed assignment too (a flag set under an `if` or a `case`). Plan and evidence: `/coord/handoff/R-818/`.

**Cost.** Over-refusal, sampled by eye: DC 17 sites, about 8 real hangs and 9 not; BC.History 15 sites, about 3 hangs, 2 unsure,
10 not. Most of the wrong ones have a second exit that always ends the loop. A wrong refusal loses one mutant; a miss can end a
run.
