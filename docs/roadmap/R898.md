Filed from SShadowS/LethAL#28 and coord task R-892. Evidence: `/coord/handoff/R-892/result.md`. Related: [[R894]] (several servers),
[[R197]] (test order), [[R826]].

**What.** A killed mutant stops at its first failing test; a survivor runs every covering test. When the tests are slow, survivors set
the run's length. #28's reporter: kills take a median of 0.4 s, survivors 80-192 tests and about 1,000-1,200 s each, so 1,022 mutants
were estimated at about 45 hours. Measured here on al-runner v3 (PaymentPractices, one-shot): survivors were 85% of the mutant time
(median 4 tests and 6.1 s, p90 24 tests and 30 s, against kills at 2 tests and 2.1 s). Test order (R197) cannot shorten a survivor: it
runs them all whatever the order.

**The idea.** An optional cap (time, or tests) per mutant. A mutant that reaches it without a kill gets a third verdict, **not
decided**, which names how many of its covering tests ran.

**What makes it honest, and therefore the conditions.**
- **Never counted as survived or killed:** not in the score's numerator or denominator, and named in the report next to no-coverage.
- **Off by default:** a cap changes what a run measures, so it is a scoping decision to pre-commit, like `--tests-only`.
- **Resumable:** a later run without the cap, or with a larger one, can finish those mutants from where they stopped.
- **Order:** with a cap, the tests that ran are the ones R197 put first, so the order decides which part was measured; the report must
  say so.
