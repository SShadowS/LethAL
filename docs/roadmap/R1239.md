**What each refusal costs, ranked (PR-492, lethal-code, 2026-11-27; `scripts/v3-refusal-cost.ts`).**
- **How it works:** every refusal text maps to a family and its upstream issue (or why it has none: by design, LethAL,
  culture, unfiled). Per family it counts:
  - tests refused at v3's baseline;
  - mutants v3 ends as `error` because of this family's refusal of the mutant itself;
  - cascade errors (an earlier test of the codeunit was refused while it ran), credited to that earlier test's own
    family through its name, never through the note's truncated quote;
  - over keys joined with BC: BC kills whose killing test v3 refused while v3 did not kill the mutant, and mutants BC
    reaches only through refused tests.
- **Runs:**
  - the Email area (PR-427's v3 run, 4,875 mutants; BC joined for file 1, 1,703);
  - the whole project (c5: 43,511 mutants, all tests, no BC).
- **The two runs overlap** (the area is part of the project, on another source copy), so the summed rank is an
  order, not a total. Kills lost exist only for the joined run.
