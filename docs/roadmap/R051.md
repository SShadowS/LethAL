**`force-reset-lease` could not reach an env-tool environment at all — the one recovery path a proxy-severed run needs.** `forceResetLeaseFromCli` built its OData URL with `odataBaseUrl(server, instance)`, which injects port 7048. That is right for a container and wrong for a hosted environment behind a path-routed HTTPS proxy (`https://host/{envId}` on 443), and unlike `runFromCli` it ignored an explicit `bcdev.baseUrl`. Same class as R18/R21: the env-tool session works, and a command beside it silently assumes a container. **Hit live 2026-07-27** recovering the DO survivor sweep — a mutant run outlived its budget, BC kept executing it, the next session found the operation stranded (`AcquireLease reported operation-orphaned twice with an UNCHANGED marker`), and the documented §8 recovery answered `HarnessInfo unreachable: Unable to connect`.
