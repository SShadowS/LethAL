**Found 2026-10-05 by the post-merge gpt-6.1-sol review of R-294**
(`/coord/reviews/postmerge-2026-10-05/sol-R-294.md`; static review, neither run nor compiled). No
critical finding.

1. **Field-designator arguments resolve as ordinary variables.** For `R: Record T` with Integer locals
   `Amount, Value` and a Decimal field `T.Amount`, `resolveIdentifierType` (`types.ts`) types both
   arguments of `R.SetRange(Amount, Value)` as Integer, so `swappablePair` (`swap-call-arguments.ts`)
   emits `R.SetRange(Value, Amount)`. The first argument names the receiver's FIELD, not the local.
   Measure with alc first which one AL binds. Then exclude field-designator arguments of proven record
   builtins (SetRange, SetFilter, Validate, TestField, CalcFields, ...) from swapping, and keep swaps
   between genuine value arguments.
2. **An unqualified call inside `with`.** `callType` (`types.ts`) resolves `F()` against the enclosing
   object and skips the shadowing checks. Inside `with R do`, a table method `F(): Text` shadows a
   codeunit `F(): Integer`, so `F() + F()` is typed numeric and `swap-additive` can subtract Text.
   Treat unqualified calls in a `with` body like identifiers (no type), or resolve the receiver scope.
3. Minor: R-294's implicit-with refusal is silent per run. Consider the same `excludedSites`
   treatment as [[R447]] if it matters to a reader (1,961 BaseApp sites).
4. Minor test gaps: `r294-implicit-with.test.ts` "reportextension modify: no swap" passes either way,
   because reportextension has no indexed scope (revisit with [[R254]]; **fixed by R254**: the
   scope exists now, a `reportextension procedure` control must swap, and removing the
   `dataset_section` case of `implicitRecordShadowsGlobals` turns the refusal test red); `types.test.ts` "n9: a
   trigger's named return Found is null with a global Found: Integer" also passes if named-return
   blocking breaks, since its page has `SourceTable`. Add an isolated case on a page without one.

The conditional `SourceTable`/`TableNo` point from the same review is [[R450]], closed as a ruling
