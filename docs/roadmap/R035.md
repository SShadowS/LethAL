**The `TestPermissions` diagnosis had two blind spots.** It fired only on the `unstable` path (`packages/runner/src/orchestrator.ts`, R27's fix). **(1)** A test refused at *baseline discovery* never reaches that path: it is dropped from the green set, and the mutants it alone covered were recorded `error` with the note "unsupported test type" — **a wrong diagnosis, not an absent one** (this entry originally said `no-coverage` with no explanation; the code says otherwise, corrected here on closing). It points the reader at their test's TYPE when the fix is one property in their own source. **(2)** The detector matches BC's English refusal text, so a non-English server gets a silent miss (never a wrong answer).
