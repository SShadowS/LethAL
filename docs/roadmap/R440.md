**Found 2026-10-05 by the orchestrator's merge review of R-307** (merge 4bd4b66b). R-307 made
`identityOrdinals` a required input of `writeInstrumentedProject` (`packages/schemata/src/project.ts`)
and updated every caller the type checker sees. `scripts/r402-shape-sweep.ts` (the R-402 shape sweep)
still calls it without that input, so the script now crashes inside `writeInstrumentedProject` when it
reads `input.identityOrdinals`.

The type checker cannot catch it: the script loads the runner through a dynamic `import`, and it is
not listed in `scripts/tsconfig.json`. So `bun run typecheck` is green while the script is broken, and
the next session that re-runs the sweep (R408's evidence came from it) meets a crash, not a result.

**To close.** Pass `identityOrdinals: identityOrdinalsOf(...)` the way the runner's own callers do, run
the sweep once to show it completes, and either add the script to `scripts/tsconfig.json` or say why
it cannot be typed, so a future required input fails at typecheck rather than at run time. Check the
other scripts that load the runner dynamically for the same gap.
