**Filed 2026-10-23 by lethal-code**, from R-672's plan review (`/coord/reviews/R-672-plan/adversary-r1.md`; plan
`/coord/handoff/R-672/plan.r2.md` §6). Related: [[R672]], [[R667]], [[R657]].

**What.** R672 makes K1(a) (`v3RowVerdict`), the v3 serve-keep rule and leg C's `message-has-no-type-prefix`
read one shared prefix, `V3_TYPE_PREFIX` = `[A-Za-z_][\w.]*: `: one word, dots allowed. Two shapes fill neither:
- a prefix with a space (`Runtime error: `);
- a Rust-style path (`al_runtime::Error: `).

Suppose a future v3 build wrote its failures that way, and ALSO wrote a refusal as a plain `fail` without
`notRun`. Then three things would go wrong:
- the refusal would score as a KILL;
- the serve daemon would be kept on a tainted runtime;
- the leg-C fact would still read `matches`.

Nothing measured writes either shape: alpha.2 and edge write no prefix, and 0 of 12,645 stored kills contain
`NotRun:`. The unit test that pins `Runtime error: NotRun: out-of-scope: x` as a `fail` names this item.

**To close.** Either:
- measure, on each new v3 build, that no failure message carries such a prefix; or
- widen `V3_TYPE_PREFIX` by a probe and a new pre-commitment (for example `::` in the class, or a bounded run of
  words), after checking that no `Assert.*` or BC text can then fill the slot.

FULL class: it touches a verdict rule.

**Closed by code** (plan `docs/superpowers/plans/2026-10-23-r675-v3-refusal-marker-anywhere.md`, measurement
`/coord/handoff/R-675/measure.md`). Neither path above: the prefix model is gone.
- `isV3RefusalText` (in `al-runner-rows.ts`, with `V3_REFUSAL_PREFIX` moved there) is now "the message holds
  `NotRun: out-of-scope:` anywhere". K1(a), the v3 serve-keep rule, `r672Unkept`, `refusal-row-shape` and
  `commit-under-test-isolation` read it unchanged. A `pass`/`fail` holding the marker after any text
  (`Runtime error: `, `al_runtime::Error: `, `A: B: `, ...) is `error`/`runner-test-error`, closes the daemon, and
  reads `diverged` in those two facts. `V3_TYPE_PREFIX` is deleted.
- Leg C's `message-has-no-type-prefix` (same name, still 27 facts) reads `diverged` unless `Fails` starts with
  `boom 5` and `AssertAreEqual` with `Assert.AreEqual failed.`; a session runs the same check on `Fails`.
- Measured: 0 of 13,773 kills and 0 stored v3 `pass`/`fail` rows hold the marker, and both probe texts start
  exactly so on alpha.2 and edge, so nothing moves on today's builds.

**KNOWN LIMIT:** a user Assert whose message quotes `NotRun: out-of-scope:` loses its kill (it scores `error`);
the safe direction; measured 0 of 13,773 kills.
