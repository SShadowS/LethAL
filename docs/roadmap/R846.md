**Filed 2026-11-06 by preproc.** Related: [[R830]], [[R829]].

**What.** [[R830]] refuses by name, the safe direction: a wrong refusal loses one mutant, a miss can end a run. Tracing 5 large BC.History
files (213 sites) showed two groups of refusals that cannot hang:
- `TestField` and `FieldError`: 17 of 60 receiver sites. Neither moves its receiver. They are refused when a helper in the `until` steps
  the record, because the rule does not see that step.
- A by-value argument of a simple type to a same-object procedure: 40 of 213 sites. Reference types such as `List` must stay refused, and
  temporary records need a check.

**Closed by ruling, 2026-11-06 (orchestrator, coord task R-842).** Sites that would come back, on master f901f666, fixtures / CDO / DO / DC / BC.History: `TestField` and `FieldError` receivers 0 / 0 / 0 / 0 / 14; by-value simple arguments 0 / 0 / 0 / 3 / 84. Disjoint.

The opus plan review showed each exemption can release a real hang, and the premise "cannot hang" above is wrong:
- A by-value key still moves rows: `while R.FindFirst() do Consume(R."No.")`, where `Consume` deletes through a local record.
- An event publisher takes a by-value argument while a subscriber steps: `repeat OnAdv(Cnt); until Cnt >= Limit`.
- A `TestField`'s error can be the loop's only way out: `repeat if Node.Get(Cur) then; Node.TestField(Parent); Cur := Node.Parent; until Cur = Target`. Same for a callee that raises.
- `Stepper.TestField(X)` on a codeunit matches by name; a split `#if` parameter list and `Rec.P(Cnt)` on a page read the wrong signature; `Show(R.Next)` steps inside the argument.

Each has a fix, about seven conditions together, and they would shrink the 101 further. A wrong refusal loses one mutant; a wrong exemption can end a run. No code, so `IDENTITY_SCHEME` stays 45. Plan and review: `/coord/handoff/R-842/plan-r846.md`.
