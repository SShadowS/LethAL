Found by lethal-code, 2026-11-11 (coord R-914). Tool friction, not a verdict.

**What happened.** `lethal run --project <p> --dry-run` on a project over 1000 sites prints `NOTE: ... 'lethal run' will refuse this
scope. Narrow it with --only <glob>, or pass --allow-large-run.` Adding `--dry-run` to the real command (which carries
`--allow-large-run`, `--time-budget` and `--tests`) exits 1: `--allow-large-run has no effect with --dry-run`. So a real command cannot
be previewed by adding one flag; the user strips flags first, then adds them back.

**Invented repro.** Any project over 1000 sites: `lethal run --project p --tests t --allow-large-run --time-budget 600 --dry-run`
exits 1; without the three flags it exits 0.

**Wanted.** A dry run accepts flags that only shape the real run, and says it ignored them (one line each), rather than refusing.
Flags whose meaning a dry run would change keep refusing.
