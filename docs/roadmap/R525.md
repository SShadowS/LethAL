**Filed 2026-10-08 by the [[R500]] build** (plan r3 `/coord/reviews/R-500-plan/plan.r3.md`, shape 2). A plausible
hang that is NOT refused.

**What.** R500 reads only the project being mutated. When a report calls an interface whose implementer lives in
another app, or raises an event another app subscribes to, that code is not refused. The reverse matters for a
project that mutates the subscriber: a subscriber in this project to an event raised by a report in ANOTHER app
(BaseApp's reports are the common case) is not refused, because the publisher's open item is not in the run.

**To close.** Decide whether a subscriber to an event of a dependency's report should be refused on the event's
name alone (a symbol-package read), measure that on CDO, DC and DO, and refuse or close it with a ruling.
