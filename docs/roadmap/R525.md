**Filed 2026-10-08 by the [[R500]] build** (plan r3 `/coord/reviews/R-500-plan/plan.r3.md`, shape 2). A plausible
hang that is NOT refused.

**What.** R500 reads only the project being mutated. When a report calls an interface whose implementer lives in
another app, or raises an event another app subscribes to, that code is not refused. The reverse matters for a
project that mutates the subscriber: a subscriber in this project to an event raised by a report in ANOTHER app
(BaseApp's reports are the common case) is not refused, because the publisher's open item is not in the run.

## Closed by ruling

R-522 measurement, 2026-10-23 (`/coord/handoff/R-522/measure.md`, section R525). (a) Subscribers to a dependency's
report: 23 (14 in production projects, 9 in test projects; DO 3, DC 2, CDO 0). Each was read: none consumes (one
reads and deletes its own table, the Copy Company ones run in OnPostDataItem, one narrows a temporary Line, one
only reads). (b) Direction (b), code in another app: 164 events raised from open code with no project subscriber,
50 dependency calls, 97 interface seeds (0 joined). A mutant cannot be made in another app in this run, so these
rows produce no mutant; a symbol-only refusal by event name would refuse with no evidence of a hang. Stated
limits: the empty-loop-table class column of R525a is not evidence (the per-subscriber reading is), and direction
(b) is ruled out by construction rather than measured. A reportextension outside the project already cannot reach
this project's items (R500 ruling).

**To close (original plan, closed by the ruling above).** Decide whether a subscriber to an event of a dependency's report should be refused on the event's
name alone (a symbol-package read), measure that on CDO, DC and DO, and refuse or close it with a ruling.
