**Filed 2026-11-06 by lethal-code, from R-841.** Related: [[R841]], [[R709]].

**What happened.** A scratch copy of `sandbox-app` gained a codeunit with id 79100, which `LethAL Sandbox Tests` already declares. Each
app compiles alone, so alc saw nothing. BC refused the upgrade: "The application object of type 'CodeUnit' with the ID '79100' is
defined in multiple apps". It could not restore, so it left the target uninstalled and removed the tests app, on `bc1`
(`/coord/handoff/R-841/shape1.log`). On a gate server only an owner restart recovers that. On a user's server it costs their
installed apps.

**To close.** Before anything is published, compare the two sources and refuse by name. A same id in another object type must not
refuse. Plan: one opus plan review, one opus build review, full v3 gate, `itest:bcdev` on a bc server.
