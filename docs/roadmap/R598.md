**Filed 2026-10-21 by R-592** (lethal-preproc; from the final-pass review, `/coord/handoff/R-592/review-opus-final.md` I1).

**What.** `scripts/bc-linux-setup.ts` hard-codes `const LANE = "code"` and passes it to `kraken coord lease
<server> <lane>`. Any lane that runs the setup script therefore holds the bc server's lease as `code`. That
breaks the coord rule "held by another lane: wait", because the holder shown is wrong, and it makes a stale
lease left by the script look like lane `code`'s.

**Evidence.** `LANE` and its use in the lease call in `scripts/bc-linux-setup.ts` (master 60e60bfd).

**To close.** Take the lane from the caller (an argument, or the lane the session runs in) and refuse to run
without one. CLAUDE.md's own lease line already says `kraken coord lease bcN <your lane>` (R-592).
