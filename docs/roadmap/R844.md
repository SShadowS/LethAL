**Filed 2026-11-06 by lethal-code, from R-841.** Related: [[R841]].

**What.** `mutationScore` is `(killed + timeoutKilled) / (killed + timeoutKilled + survived)`. An `error` mutant is in neither part, so
dropping one can raise the score. In one measured run, 6/7 = 85.7% with one `error` row would have read 6/8 = 75.0% had that mutant
survived.

**What the report says today.** The console's `score:` line lists `error N` among the other counts, with no word that those rows are
outside the score, and no caveat fires. `all-errors` covers only the case where every row is an error.

**To close.** A caveat, with the count, when some rows are `error` but not all, and a line beside the score stating the range the
score could read had they run. `mutationScore` itself does not change.
