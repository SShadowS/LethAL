**Measured, one run, 296 killed mutants, hosted sandbox (about 0.5 s per RunMutant call).**

- The killing test was the FIRST test tried for 141 of 296 kills (48%). Mean position 9.4.
- 2,476 calls returned `pass` before the call that killed: 21 minutes of this run's mutant phase
  spent on tests a better order would have skipped.
- Of the 257 kills that had an earlier kill in the SAME procedure, **207 (81%) were killed by a
  test that had already killed there.** The information needed to put that test first existed in
  the run at the moment it was needed.
- Survivors are untouched by any order: they run every covering test regardless (6,895 calls for
  196 survivors, 35 per survivor). That is [[R198]].

**Where the order comes from.** `runMutantsOnBackend` iterates `covering` as `perMutantTests`
produced it, which is the coverage index's order, which is baseline discovery order. No site sorts
it. `killingTest` in the report and in every per-mutant baseline is therefore "the first test in
discovery order that failed", not "the most specific test that failed".

**The heuristic, in order of evidence.** For each mutant, sort its covering tests by:

1. tests that have killed a mutant in the same procedure earlier in this run, most kills first;
2. then by the number of members the test covers, fewest first (a narrow test is more likely to be
   the one that asserts on this code);
3. then by baseline duration, fastest first, so a wrong guess costs least.

Deterministic (ties broken by qualified name), so a resumed or repeated run orders identically
given the same prior kills.

**Why not today.** The order decides `killingTest`, and every gate pins `killingTest` per mutant.
Landing this means re-recording `tables`, `bcdev`, `alrunner`, `envtool` and the campaign
baselines in one commit with a diff that shows verdicts unchanged and only `killingTest` moved, the
same proof [[R166]] gave for a relabelling. Estimated saving on a container, where a call is about
0.1 s: 4 minutes on a run this size. On a hosted sandbox: the 21 minutes above.
