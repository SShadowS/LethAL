**Filed 2026-10-09 by the [[R555]] build** (plan r2, finding 1 of `/coord/reviews/R-555-plan/adversary-r1.md`;
counts from `/coord/handoff/R-555/measure.md`, addendum, measured on master 48d5534f over BC.History, CDO,
DC, DO and the fixtures).

**What.** R555 refuses a call from any object to a preset writer of a project report (a procedure that
writes a name an open item's exit guard reads) when the receiver is declared `Report X` and X is a project
report or has a project reportextension. A call whose receiver does not resolve that way is not refused, so
deleting it (`void-method-call`, `empty-block` of its block) could leave the report's exit name at its
default and the report could walk forever. These are the groups, every one of them in BC.History (CDO, DC,
DO and the fixtures have none):

| receiver group | count | notes |
|---|---:|---|
| a report outside the project | 85 | 78 in BaseApp TEST apps (Tests-Report 31, Tests-SCM 10, Tests-SINGLESERVER 8, Tests-Resource 7, 22 in ten others), 5 in Application Test Library, 2 in Quality Management |
| interface | 17 | name match only: an upper bound, mostly coincidences (`Invoice Posting`.SetParameters, `Reminder Action`.Initialize) |
| untyped | 6 | includes `MfgWhseSourceCreateDocument.ReportExt.al` `?.SetParameters` |
| complex receiver | 15 | name match only |

**Why most of it is not a hole.** LethAL mutates only the run's TARGET project (`--project`); the test app
(`--tests`) is compiled and published, never walked for mutants. So the 78 calls in BaseApp test apps are
never mutated in a normal run, and neither are the Application Test Library's 5, unless that library is
itself the run's target. The real outside-project exposure is Quality Management's 2: a real app calling a
BaseApp report's writer. The interface, untyped and complex groups are name-match upper bounds: the member
name equals some report writer's name, not a resolved binding.

**To close.** For a report outside the project, read the writer set from the dependency's symbols (or
refuse every member call on a `Report X` receiver whose X is not in the project, and measure the cost). For
the other groups, census by hand which name matches really bind to a report writer, and refuse or close
with a ruling.

dependency source loader) is the mechanism that would fix it. Notes: `/coord/handoff/R-561/step1.md`.

**Why a name-only refusal was not taken.** The rule tried: refuse a call through a `Report X` receiver whose X is
outside the project, either every member or the non-built-in members only. Its cost, in deployed mutants
removed, on master 1d49fa1b:

| corpus | non-built-in only | every member |
|---|---:|---:|
| DC | 16 (0.009%) | 33 |
| DO | 28 (0.063%) | 41 |
| CDO | 33 (0.088%) | 46 |
| BC.History | 2,694 (0.147%) | 5,902 |

That is over the 0.05% bar on DO and CDO, and every hit there is false. Two cases account for them, and neither
called report has a preset writer in BaseApp's source (R-555's map):
- four warehouse "Actions" pages (CDO's, also under DO), 28, call `Create Invt Put-away/Pick/Mvmt`.InitializeRequest
  before RunModal;
- CDO's demo codeunit, 5, calls `Create Reminders`.InitializeRequest.

The "deployed" base counts only projects that declare a `Report` variable, which are the only ones the rule can
change. DC's base includes its test project. A dependency's symbols name its procedures but not what they write, so "known
writer" needs the dependency's source: that is [[R565]]. Microsoft's packages ship it.

**Closes** when R565 lands and refuses QM's 5 mutants (and any later case) by their known writer, or by ruling.

**Closed by [[R565]]** (branch `lethal/r565`, 2026-10-10). The "a report outside the project" row is closed for
every receiver whose report's source the dependency packages carry: X's source and its dependency
reportextensions are read, and a call to a preset writer of X is refused like R555's. Measured on the prototype
with al-runner's 28.5 platform apps: Quality Management loses 7 (these 5, plus the guard and the loop exit around
the call in `QltyDispWarehousePutAway`, R555's shape), the Application Test Library 15. The interface, untyped and
complex-receiver rows stay as R555 left them: none names a report, so no source can answer them. Re-measured on
the built branch: the same 7 and 15, and every dependency lookup came back `ok` (R565's cost table).
