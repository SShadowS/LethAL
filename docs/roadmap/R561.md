**Filed 2026-10-09 by the [[R555]] build** (plan r2, finding 1 of `/coord/reviews/R-555-plan/adversary-r1.md`;
counts from `/coord/handoff/R-555/measure.md`, addendum, measured on master 48d5534f over BC.History, CDO,
DC, DO and the fixtures).

**What.** R555 refuses a call from any object to a preset writer of a project report (a procedure that
writes a name an open item's exit guard reads) when the receiver is declared `Report X` and X is a project
report or has a project reportextension. A call whose receiver does not resolve that way is not refused, so
deleting it (`void-method-call`, `empty-block` of its block) could leave the report's exit name at its
default and the report could walk forever. These are the groups, every one of them in BC.History (CDO, DC,
DO and the fixtures have none):

| receiver group | count | notes |
|---|---:|---|
| a report outside the project | 85 | 80 in BaseApp TEST apps (Tests-Report 31), 5 in Application Test Library, 2 in Quality Management |
| interface | 17 | name match only: an upper bound, mostly coincidences (`Invoice Posting`.SetParameters, `Reminder Action`.Initialize) |
| untyped | 6 | includes `MfgWhseSourceCreateDocument.ReportExt.al` `?.SetParameters` |
| complex receiver | 15 | name match only |

**Why most of it is not a hole.** LethAL mutates only the run's TARGET project (`--project`); the test app
(`--tests`) is compiled and published, never walked for mutants. So the 80 calls in BaseApp test apps are
never mutated in a normal run, and neither are the Application Test Library's 5, unless that library is
itself the run's target. The real outside-project exposure is Quality Management's 2: a real app calling a
BaseApp report's writer. The interface, untyped and complex groups are name-match upper bounds: the member
name equals some report writer's name, not a resolved binding.

**To close.** For a report outside the project, read the writer set from the dependency's symbols (or
refuse every member call on a `Report X` receiver whose X is not in the project, and measure the cost). For
the other groups, census by hand which name matches really bind to a report writer, and refuse or close
with a ruling.
