**Filed 2026-11-06 by lethal-code, from R-835's build review.** Related: [[R408]], [[R402]], [[R801]].

**What.** `continuationRefusal` looks only at a `preproc_conditional_statement`, and only at what comes before and inside the `#if`.
These shapes get past it. Each one's source compiles, and the instrumented artifact fails alc, under builds `[]` and `[LETHALX]`
unless stated. The parse has no ERROR node.

| Shape | Parse | Artifact |
|---|---|---|
| `repeat A += 1; until A` `#if X` `* 2` `#endif` `> 3;` | tail mid-condition | AL0175 |
| `if Flag then Bar()` `#if X` (empty or comment) `#endif` `else Foo(1);` | `else` read as a `call_statement` | AL0110, orphaned ELSE |
| `if Flag then A := 1` `#if X` `+ B` `#endif` `else A := 2;` | tail in a then branch | AL0111 |
| the same with no `else`, ending in `;` | tail in a then branch | AL0631 |
| `case A of 1: Bar()` `#if X` `;` `#else` `else Foo(1);` `#endif` `end;` | `preproc_conditional_case` | AL0224, `[LETHALX]` only |
| `case A of 1: Bar()` `#if X` `; 2: Foo(1);` `#else` `;` `#endif` `end;` | `preproc_conditional_case` | AL0224 |

For-to, case-head and case-label tails, `if` condition tails, argument tails and a nested empty `#if` compiled fine.

**What it costs a user: not measured.** Nothing here reads as a wrong verdict so far. The artifact fails alc, and what happens then
is unchecked: whether bisection drops the file's mutants, or the run stops.

**Reach.** `#endif` directly followed by `else` has 0 hits in DC and DO. BC.History's scan also read 0, but it had a 150 s timeout and
may have been cut off. The other shapes are not measured.

**To close.**
1. Check what a run does on one of these shapes.
2. Count the shapes on the corpora, from the dump cache.
3. Refuse them by name, offline, as `directive-continues-statement` does: extend the rule to what follows `#endif`, a tail that does
   not end its condition, and `preproc_conditional_case`. Pin each as an `r402` fixture.
4. The `else` misparse is also an upstream tree-sitter-al bug: report it, with an invented repro.
