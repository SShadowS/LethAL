**v2 re-meaned exit codes 2 and 3, and our decode swallows the dangerous one.** `OneShotTransport` maps exit 2 to `kind:"skip"` and exit 3 to `kind:"error"` (`packages/runner/src/al-runner-transport.ts:74-76`). In v2, **2 = a bundle could not execute (process-level error)** and **3 = a bundle could not compile** (`al-runner --help`, EXECUTION section). So a genuine execution failure now becomes a silently skipped mutant with no verdict and no error, while a compile failure — the ordinary "this mutant does not build" case — is escalated to a hard error. The whole-session case is contained by the baseline-green gate (measured: every mutant came back `error note=no green baseline tests` rather than a plausible score), but a mid-run exec failure on SOME mutants is not: those would be skipped under a green baseline. Fix the mapping with the decode work in R93, and red-check that an exit-2 run cannot produce a scored mutant.
