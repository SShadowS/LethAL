Found by coord task R-913 (Excise Taxes on v3 serve, 2026-11-11). Evidence: `/coord/handoff/R-913/ext.stdout.txt`.

**What.** The console prints `TIMING: total X = generate + deploy + baseline + mutants + overhead`. `timings.mutantsMs` is, by its
own definition, the summed per-mutant TEST time. On serve-entries those tests overlap (prefetch requests, lanes), so the sum can
exceed the run's wall time. Measured: `TIMING: total 469.9s = generate 0.5s + deploy 15.6s + baseline 18.3s + mutants 39906.8s +
overhead 0.0s`. The overhead is clamped to 0, so the line states an equation that is false by a factor of 85, and hides that the
mutant phase took about 435 s.

**Fix.** When the parts overrun the total, print the mutant phase's wall time (the total less generate, deploy and baseline, with
overhead) and name the summed test time apart, as overlapping. The JSON's `timings` is unchanged.
