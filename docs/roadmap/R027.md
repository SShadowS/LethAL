~~Trigger mutants whose tests write are unscored~~ — **VOID, follows R1.** The unscored-mutant blast radius was real but its cause was a fixture that omitted `TestPermissions = Disabled`, not a platform limit. With the property declared, writing tests run and trigger mutants score normally. What survives as a genuine product concern: **a target suite whose test codeunits omit `TestPermissions` will have its writing tests refused**, and LethAL currently reports those mutants as `error cause=unstable` rather than naming the cause. Report the target codeunit's `TestPermissions` value — that is the actual predictor — and say so plainly when it is not `Disabled`.
