**Filed 2026-10-22 by lethal-preproc during R-644** (the measurement's side finding, `/coord/handoff/R-644/measure.md`,
section "Side finding"). The same hole as [[R644]], on the resume path instead of history. Related: [[R621]], [[R585]].

**What.** `carriedVerdictFor` (`packages/runner/src/resume.ts`) carries a stored verdict by identity key. Since R-585
(R621) it re-derives a stored no-coverage, and the mutant must be covered now. But it never checks that the tests
covering the mutant NOW are inside the `covering_tests` the stored verdict was scored against.

**Scenario.** The interrupted run's baseline had test X failing (data, company state, an environment glitch), so a
survivor M was scored against the green tests only. The resume re-runs or reuses a baseline in which X passes, and X
covers M. The resume carries M as `survived`, although X never ran against it. If X kills M, that is a false survive.

**Why it is separate from R644.** R644 is the history path (`--skip-known-survivors`). This is `--resume` and
`--resume-run`. The fix is the same subset rule: carry a survivor only when every test covering it now is inside its
stored `covering_tests`, and that set is not empty. Otherwise re-run it.

**To close.** Apply that rule in `carriedVerdictFor` (or where the resume carry decides per mutant), with a red test
per direction: a survivor whose covering tests are all inside the stored set carries; one with a newly green covering
test is re-run. Then check `itest:lend`'s R-legs (R1, R2, R3, RP) for a figure move, pre-commit it, and run the gate
live. Measure first how often a resumed run's baseline turns a test green.

**Narrowed by R-644 (2026-10-22), still open.** R-644's build review found 5b storing the tests covering a carried
survivor NOW, so a LATER history session could lend it against a test it never faced. R-644 fixed only that: the
carried row's store list is now the source row's (`ResultsStore.keepCarriedFacedTests`). The resume itself still
carries M as `survived` in its own report when a test newly green there covers it. That decision is this item's
whole remaining work.
