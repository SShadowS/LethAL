**Found by R-499's plan review** (`/coord/handoff/R-499/review-r1-opus-adversary.md`, side
finding; plan r3 section 8). Follows [[R499]].

The watchdog inside `RunMutantTransport.runMany` reads `GetOperationStatus` on each poll with no
`timeoutMs`, so that request has no abort timer and no `bounded(...)` race. Every exit of
`runManyOnce` awaits the watchdog. So a poll that BC accepts and never answers holds the whole call
forever: the hard cap (ceiling plus grace) aborts only the main `RunMutantMany` request, not the
poll the watchdog is waiting on.

Every other control request already ends by its own timer (`StopHungRun`, `StopHungRunAt`,
`GetOpAnswer` and the status read after a stop all pass a `timeoutMs` and are wrapped in `bounded`
with the same number). The poll is the one that is not.

Proposed fix: bound each poll the same way, with `bounded(this.getOperationStatus(..., bound),
bound)` in the watchdog, so a poll that never answers is treated like any other failed poll.

Unmeasured: whether Bun's socket idle timeout already ends such a poll on its own. If it does, the
hang is bounded today, but by a runtime default rather than by LethAL, and the bound is not known.
Measure it before deciding how urgent this is.

**Closed by R-503 (c637f2dd).** Each watchdog poll is now `bounded(getOperationStatus(...,
pollBound), pollBound)`, where `pollBound` is `KEPT_ANSWER_READ_MS` (15 s) clamped to what is left
of the call's hard cap. A poll that times out counts as a failed poll and polling goes on; a stop
still needs an answered poll. The fix does not depend on Bun's idle timeout, which stays
unmeasured. Proof: tests P1 to P6 in `run-mutant-many.test.ts`, each red-checked
(`/coord/handoff/R-503/redchecks.md`).

`docs/superpowers/specs/2026-10-08-r503-hang-poll-bound-precommitment.md`, committed before the
run: ON and SINGLE 24 killed / 5 timeout-killed / 9 survived / 0 errors, OFF quarantined with 0
timeout-killed. The R289 trace held 0 `poll-failed` lines and 25 `poll-ok` lines. **Measured poll
latency** (`at - sentAt` over those 25): 19 to 29 ms, mean 21.6 ms, so live polls answer about
