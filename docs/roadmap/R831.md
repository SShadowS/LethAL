## Plan (R-833, draft 2, after one adversarial review)

Read a subscript as its array's name, so `Buf[1]` and `Buf[2]` are one name: the safe direction for a refusal. [[R829]], which walks the
same feeds, has landed, so this builds on it. It goes in one change with [[R830]].

1. **Five places, not three:** `assignmentTargetOf`, `memberTargetOf`, `indirectFeeds`, and also `memberRefOf` and
   `loopConditionReadsByName`, which each test for a plain identifier. Without those two, `Recs[1].Field` stays claimed.
2. **An index on the left is a feed.** In `while Buf[3] = 0 do begin Buf[I] := 1; I += 1; end`, deleting `I += 1` hangs, so add the left
   side's index expression to `fed` in `indirectFeeds`.
3. **A mutant inside the left index.** `hangCapableForMutatedNode` reads only the value side, so `swap-additive` on `I + 1` in
   `Buf[I + 1] := 1` stays claimed. Refuse it, and update the stale comment in `loop-hazard.test.ts`.
4. **R829's promise.** `indirectFeeds` says other callers keep the plain walk so their figures do not move, and this change reaches
   `r572LoopRows`. Keep it behind `withGuards` unless the dump shows no move.
5. **Not reached:** `swap-call-arguments` passes `a.text`, so a subscript argument stays unmatched. Say so in the item if it stays.
6. **Measure, identity, gates and red checks:** as [[R830]]'s plan.
