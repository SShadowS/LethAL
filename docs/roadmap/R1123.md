Found by coord PR-145's Opus build review (lethal-code, 2026-11-18), while checking [[R1111]]'s readers.
- **What happens:**
  - Under `alRunnerV3.coverage: "none"`, `deploy` builds no coverage index, so `coverageOf` returns `undefined`.
  - The baseline verdicts carry no coverage, and the orchestrator stores `null` per test.
  - In `recheckReusedBaseline` (PR-126), a sampled codeunit's fresh coverage is also `undefined`. `"null" === "null"` counts as
    `compared += 1`, so review 2's guard ("a sampled codeunit with a passing test must compare at least one coverage map") passes
    having compared nothing.
- **Severity: low.** Under `"none"` coverage decides nothing: every green test runs every mutant (`perMutantTests` is the green
  set). The re-check's row comparison still runs. Only the coverage part of the guard is empty.
- **Possible fix:** count a comparison only when at least one side has coverage. Under `"none"`, say that the coverage part is not
  checked rather than passing it.
  - Red both ways: a null-vs-null sample gives no count, and a real map pair still does.
- Related: [[R1111]], [[R1092]].

**Done (coord PR-146, lethal-code, 2026-11-18).** In `recheckReusedBaseline`:
- **Without a coverage index** (`"none"`), the samples ask for no coverage and no map is compared. The re-check prints
  `al-runner-v3 re-check: coverage not compared (...)` by name, and the rows still decide.
- **With coverage on,** a test counts as compared only when this session read a map for it. A failing test's null vs null no
  longer satisfies review 2's guard.
- **What the tests had been checking:** every PR-21 and PR-123 re-check test ran under the rig's default `"none"`, so their
  coverage assertions compared null with null.
  - Both blocks now run with coverage on, so the index path runs and this session's maps are compared.
  - Under `plainCoverage` those maps are empty (no target line). Only the nested PR-123 "with a real coverage index" tests compare
    maps that hold target lines.
- **Two new tests**, each red on its own revert (`al-runner-v3-entries.test.ts`, named "R1123: ..."):
  - the "none" path: the line, and no sample request asks for coverage;
  - null vs null is not a comparison.
