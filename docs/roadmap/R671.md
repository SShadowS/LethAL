**Filed 2026-10-22 by the R-654 S3 builder** (coord R-654c). Related: [[R654]], [[R586]].

**What.** `runSession` refuses `workers > 1` for bcdev (Layer 5C-A: the single `LC Mutation Active` row
is not lease-protected) and for al-runner-v3 (R586 v1 is sequential). The retired .NET al-runner was the
only backend that ran the worker fan-out (`backendFactory`, sharding, per-worker deploy and bisection).
With it gone, that code path cannot be reached by any backend.

**What S3 did about the tests.** The unit tests that drove the fan-out through a v2 fake were re-pointed
to `al-runner-v3` like every other v2 fake, and then refused by the v3 guard. They are marked
`describe.skip` / `test.skip` in `tests/orchestrator.test.ts` with a comment naming this item:
- the describe "runSession — parallel workers" (9 tests);
- the worker cases under "bisection on compile failure", "Task 7: bisects the full manifest",
  "Task 7: only a typed AlcCompileError may be bisected", "Task 7b: bisection's compile-only seam",
  "Layer 5C-B1 fix round 1: deploy latch guard" and "C02-04 characterization" ("11: parallel workers");
- the worker cases of `tests/resume.test.ts` that ran `workers: 2`: "R514 fixed (a), single path,
  workers = 2", "R516 T2 (repro b)", "R515 T10: the re-budget is per shard" and "R517 wiring: under
  workers = 2"; and its "I3 wiring" test now checks the one session backend only.

Also: `parseCliConfig` refuses `--workers` > 1 for both backends, so `tests/cli.test.ts` reads
`--workers` through a `--workers 1` invocation and its refusal by name.

**To close.** Decide one of:
- delete the worker fan-out from `runSession` (and these skipped tests), since no backend uses it; or
- give a backend `workers > 1` (bcdev under 5C-B's real lease), then un-skip the tests against it.

**Closed (R-691): deleted.** The fan-out is gone from `runSession` (`backendFactory`, the sharding, per-worker deploy and
bisection, `executeCovering`, the worker backends in `closeLeaseScope`), and so are its skipped tests, `pool.ts`
(`Semaphore`, `shardEvenly`) and the `--compile-concurrency` flag, which only bounded the fan-out and is now an unknown
flag. `workers > 1` is still refused by name for bcdev and for al-runner-v3, and `--workers 1` is unchanged; both
refusals keep a test that goes red without them. Every non-skipped test passes unchanged.
