Coord task PR-83 (2026-11-16), PR-52's generator method. Family `record-filters` in `scripts/refusal-family.ts`: 270 cells in 13
groups (SetRange, SetFilter syntax, sort order on ties, FilterGroup and CopyFilters, GetFilters, Count/IsEmpty, CalcFields,
FlowFilters, CalcSums, ModifyAll, DeleteAll, marks, Danish 1030 filter text), on invented tables and data. Every cell reloads
the data, does one operation and raises its answer as `V:[...]`. Evidence in `/coord/handoff/PR-83/`.

**Runs.**
- al-runner edge-4ebfe7913, offline: 262 cells answered, 8 refused.
- BC 28.4 W1 on bc2 (lethal-bugs, run 2): 288 tests, every cell answered.
- Run 1 was void: BC's restrictive test default on the web-service path refused the seed's Insert (#8160). Since then the
  family sets `TestPermissions = Disabled` (a new `Family.testPermissions` option; other families are unchanged).
- The join (`--join ... --family record-filters`, generalised from format-evaluate) gives 259 equal, 3 different values and
  8 refusals (6 of them locale cells).

**Classes, each filed with an invented repro, a regression entry and an [[R586]] row:**
- **#8195, wrong answer (R586 row 23).** Text compares by character code: `Æ` sorts after `Z`, where BC's default W1
  collation sorts it as `AE`. It affects a SetRange on a text range and the order under SetCurrentKey on a text field (cells
  51011, 51112). Entry `u8195-text-collation`.
- **#8196, wrong answer (R586 row 24).** `@` ignores case but not accents; BC's `'@emile'` finds `Émile` (cell 51061). Entry
  `u8196-at-filter-accents`.
- **#8197, refusals with BC's answers (R586 row 25):** a non-member Option or Enum value, Danish date filter text under the
  en-US region, and Danish Boolean words (8 cells). Entry `u8197-filter-refusals`.

**Not differing:** FilterGroup isolation, CopyFilters, GetFilters text, CalcFields and CalcSums under filters, ModifyAll and
DeleteAll under filters, marks, and sort order on ties (the primary key breaks them) all match BC. The 18 Danish two-test cells
read 1030 on both sides; this family's reader sets the language itself, so it does not measure carry (PR-63 does).
