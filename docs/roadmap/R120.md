**Eight of 19 `scripts/` files do not compile under the repo's own strict flags.** Measured
2026-08-07 by the survey R119 asked for, before `scripts/tsconfig.json` landed: 11 files compile
clean and are admitted to `tsc --build`; these 8 are not, and were deliberately left out rather
than admitted by weakening a flag for everyone else.

What each fails on:

- `census-swap-call-arguments.ts`, `census-tier3-candidates.ts`, `probe-grammar-corpus.ts`,
  `probe-grammar-table.ts`, `measure-gui-guarded.ts` — **TS2367 / TS2345 against `ALNodeKind`**:
  they compare or pass node kinds (`"quoted_identifier"`, `"basic_type"`, `"argument_list"`,
  `"attribute_content"`, `"property_name"`, `"ERROR"`, `"MISSING"`, `"if_keyword"`,
  `"then_keyword"`) that are not members of the union. Either the grammar moved under them and the
  comparison is now dead code that silently never fires, or `ALNodeKind` is incomplete. **Both
  readings matter and neither is cosmetic**: a comparison that can never be true makes a census
  under-count without erroring, and `census-swap-call-arguments.ts` and `census-tier3-candidates.ts`
  are the scripts whose counting rules R82 and R13 were decided on. Deciding which reading is
  right needs a run against a corpus, not a type fix.
- `probe-alrunner-tables.ts` — treats a `MutationSetResult` as an array (`.reduce`, spread), which
  it is not; the two implicit-`any` errors are downstream of that.
- `probe-continia-env.ts` — imports `@modelcontextprotocol/sdk/*`, which is not a dependency of
  this repo.
- `roadmap-index.test.ts` — TS5097 only, and **already fixed**: it is admitted, because
  `allowImportingTsExtensions` in the new `scripts/tsconfig.json` is what its `./roadmap-index.ts`
  import needs.

Fix: admit them one at a time by adding each to `files` in `scripts/tsconfig.json` once it
compiles, starting with the two census scripts, since those are the ones whose output was
load-bearing for a decision. **Do not** widen `files` to a glob and relax a flag to make the set
pass — the point of the explicit list is that admitting a script is a decision somebody made.
Filed 2026-08-07 alongside R119's fix.
