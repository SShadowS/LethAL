Found by coord task R-954 (2026-11-13), in VERIFY FULL on lethal/r954 and again on lane-preproc's master code (`CI=true bun test
scripts/heavy-slot-class.test.ts`: 1 or 2 failures in 3 runs on each; R965 does not touch `scripts/`).
Related: [[R952]] (the FIFO queue the test covers).

**What happens.** The test runs `heavy-slot.sh` against its own lock folder, holds two of three slots, starts a `baseapp --wait`
waiter that the guard refuses (it marks its ticket `.refused`), and expects a plain `other` caller to take the third slot. It
sometimes gets exit 75 instead (the assertion on `plain.exited`).

**Cause (measured in coord R-952).** A refused waiter retries out of turn on every poll, and the test's waiter polled every 0.05 s.
Each retry takes the free slot with `flock` and holds it while its guard runs, then releases it. A plain caller that arrived in
that window found all three slots held and exited 75. It reproduced about 1 run in 3, and more often on a loaded machine, because a
slower guard is a longer window: that is why it looked load-dependent.

**The first text of this item named another cause, an inference that was never checked:** that the guard counted the container's
live heavy jobs. It does not, in this test: every `heavy-slot.sh` in that test block runs with `LETHAL_HEAVY_PS_FILE` (an empty
`ps`), a temp lock folder and (since R952) no cgroup, so the guard sees nothing of the container.

**Why it matters.** A full VERIFY failed by a test, not by the code under review, and every lane had to decide that by hand.

**Fixed (coord R-952, fce3b9fb).** The test is split. In the first, the waiter polls every 30 s: it marks itself on its first try
(before any sleep) and sleeps through the plain call, so no retry can hold the slot. The second shows that a refused waiter still
runs once a job ends, with no plain caller to race. Red both ways: a refused ticket that still blocks the queue fails the first; a
refused waiter that never retries out of turn fails the second. Six runs in a row passed with real heavy jobs up in the container.
