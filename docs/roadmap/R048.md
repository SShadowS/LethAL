**Nothing stopped a user pointing `lethal run` at a whole real app, and that path cannot succeed.** `--only` (R41), `--tests-only` (R45) and `--max-guards-per-batch` (R44) all exist, but every one of them is opt-in: the default invocation on Continia Document Output schedules **19,832 mutation sites**, which at that project's measured per-mutant cost (~19.5 s mean, p95 43 s) is days — and it fails long before that, because the artifact carrying every guard is severed by the hosting proxy at 362 s (R44). So the unscoped run is not merely slow; on a real project it usually cannot complete at all, and it fails after burning an hour. Filed 2026-07-27 as the cheapest single fix for first-run experience.
