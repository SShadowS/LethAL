Related: [[R985]] (the stand-ins and BC's measured bound), [[R1027]], [[R1031]].

**What.** Before edge-5a58a0f16, al-runner stored non-zero 1753 dates that BC refuses to write (upstream #8006). A test writing one
passed on al-runner and failed on BC.

**Measured:**
- **By parse:** no 1753 Date or DateTime literal, `DMY2Date(.., .., 1753)` or 1753 date string in 84 BC.History projects (app and
  test). The R985 stand-ins were never stored by the pre-fix builds.
- **By run:** 82 baselines re-run on 5a58a0f16 (4,760 tests) and compared per test with each project's latest pre-fix baseline.
  - 2,462 tests ran; none turned red with BC's "Cannot write the value" text for a 1753 date.
  - No baseline row in any re-run names 1753.
  - 2,298 tests were refused by al-runner: a 1753 write after a refusal point would not be seen.
  - The positive control (`u8006-date-1753`) shows the check detects the class.
- **Other moves:** 62 tests moved for other reasons, each attributed in the results. 38 of them come from triage budgets that ran
  out inside isolation auto's re-baseline, not from the build ([[R1031]]).
