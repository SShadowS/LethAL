**Low priority. Filed by R-302 run 003 (2026-09-29, review minor M5).** The recovery for
[[R330]] and [[R331]]'s fail-safe, which is under-generation in the safe direction.

**What was lost.** Run 003 made every member the symbol table does not index "unknown": a plain
procedure wrapped whole in `#if`, a split member swallowed by the global `var` section ([[R327]]),
and the names a member or trigger declares inside its own `#if` region. Those names get no type, so
no typed operator claims a site that reads them.

That removed 62 mutants:

- 19 in DC/Cloud, now 102584 raw and 97126 deployed;
- 43 across all of `BC.History/BaseApp`.

The plan's addendum 3 pins them. Every one sat inside a `#if`-wrapped member and was typed from
another member's declarations (a same-named DIRECT overload) or from a global.

These 62 are NOT known to be invalid. Many of them probably compiled, because the other overload
often has the same parameter types, so the borrowed type was right. They were removed because
nothing could PROVE their type, not because they were shown to fail. Nobody compiled DC or BaseApp
to tell the valid ones from the invalid ones. Recovering the valid ones is this item's purpose.

**Fix direction.** Index a `#if`-wrapped member as a symbol of its own, and resolve its names by
[[R302]]'s every-arm rule:

- a name resolves only when every build that has the member declares it with the same type;
- anything else is ambiguous.

Then each such member types by its OWN declarations, and the valid sites return. The same applies
to `#if`-wrapped objects, which are also unindexed today.

Pre-commit the corpus effect first, because this ADDS sites, and compile a sample of them under
every symbol subset.
