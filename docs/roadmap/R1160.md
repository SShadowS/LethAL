Found by coord PR-275 (lethal-code, 2026-11-20), the error census for alrunner (PERF-27). Evidence:
`/coord/handoff/PR-275/` (`result.md`, `census.py`, `census.tsv`). Source: perf10c (`/coord/handoff/PR-217/`, store
`doperf10c.sqlite`, events), with per-mutant test time from PR-273's model.

**What happens.**
- **The codeunit:** one DO test codeunit (id 68874, 10 tests) has 4 tests that al-runner refuses in the BASELINE. The refusal
  is the by-value `Record.SetFilter()` one, which alrunner ruled rule-3-correct in PERF-17
  (`/coord/handoff/from-alrunner/PERF-10-by-value-setfilter.md`). Its other tests: 3 fail and 3 pass.
- **The cut:** PR-250 cuts a covering entry before a test the baseline refused, because the daemon does not keep that refusal.
  So for a mutant whose covering tests in that codeunit sit AFTER a refused test, those tests are never measured, and LethAL
  scores the mutant `error`, even when all its other covering tests ran and passed (typically about 209 of 210).
- **The scale in perf10c:**
  - 614 mutants cover that codeunit: 207 survived, 104 killed, 303 error.
  - 301 of those errors carry the PR-250 cut note: 89% of all error test time (11,609 of 13,028 lane-s), about 28% of the
    41,678 lane-s of mutant test time.

**What could change (a verdict-policy decision, so the owner's call):**
1. **Keep `error`:** honest, but it spends about 11,600 lane-s a run on mutants that cannot get a verdict unless a measured
   covering test kills them.
2. **Measure the tests after the cut in their own entry** (the codeunit's tail, with `runSelectedOnly`). Earlier tests' state is
   then missing, so verdicts could move. Measure that first, the way R1094/R1097 measured prefix cuts.
3. **Score on the measured covering tests, with a caveat** naming the unmeasured ones. A survivor of this kind is weaker
   evidence than a full one.

**Also from the census (smaller):** 58 error mutants (rank 5) are refused because `FindSet` on the Company table needs the
companies named (`--companies` / the serve field). That is a LethAL configuration gap for DO, not an al-runner limit.
