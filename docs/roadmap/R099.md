**v2 fixes R7 and R8 — measured — so the canary and `authoritative: false` both need re-deciding, not re-asserting.** Both defects that justify `capabilities().authoritative = false` (`packages/runner/src/al-runner-backend.ts:104-118`) are gone on v2, measured 2026-08-05 with the same two probes `al-runner-canary.ts` uses, run against a local v2 build: `asserterror I := 1;` correctly **fails** — `NavNCLAssertErrorException: An error was expected inside an ASSERTERROR statement.` (v1: reported `pass`, R7); and a table-object global written by an `OnValidate` trigger **survives** the return from `Validate()` — `TouchCount()` returns 1 (v1: 0, R8). That is exactly the outcome the canary was built to detect instead of asserting a frozen claim, so the canary's design held; but the canary itself runs through `OneShotTransport` and therefore cannot execute at all on v2 (R93). Work: port the canary with the transport, and re-derive `authoritative` from what is actually left on v2 — `coverage: "none"` still stands, as do the architectural limits (no service tier, no transactions, `Commit()`/`Rollback()` no-ops, `StartSession` inline, empty base-app tables — upstream `docs/limitations.md`). Do NOT flip `authoritative` on the strength of these two probes alone.

**Re-decided 2026-08-07, and the answer is the same value for a different reason — which is the
point of re-deciding rather than re-asserting.** `authoritative` stays `false`. The comment that
justified it cited R7, and R7 is fixed on v2, so the old justification was simply no longer true and
the flag would have been correct by accident. It now rests on what v2 still is: `coverage: "none"`,
no service tier, no transactions, `Commit()`/`Rollback()` are no-ops, `StartSession` runs inline,
base-app tables are empty (upstream `docs/limitations.md`). Two fixed semantics do not make a
process-hosted runner authoritative about a server.

The canary itself was ported with the transport and now runs on v2, where it reports
`defect-not-reproduced` for both probes — the design working. Replacing it with a wire-contract
probe is R123.
