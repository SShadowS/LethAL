**Filed 2026-10-11 by R-394** (`/coord/handoff/R-394/repro-pagecov.md`, the report rows). Synthetic repro in
`/coord/handoff/R-394/scratch/repro-pagecov/`.

**What.** On al-runner `v2.12.0-main.f06ee78c`, a test that runs a report with `UseRequestPage(true)` and handles the
request page with a `[RequestPageHandler]` that clicks OK FAILS at the `RunModal` call with `NavCSideException: An
error occurred and the transaction is stopped`. No report trigger runs. The same report run with
`UseRequestPage(false)` passes, and its data-item trigger is counted by `--coverage`.

**Why it matters.** A suite whose tests show request pages fails at baseline on al-runner, so those tests are never
scored. On BC the same tests presumably pass. [[R554]] already notes that no gate measures a request page.

**To close.**
1. Run the repro's test on a BC container (Cronus28). If BC passes it, file it upstream at
   StefanMaron/BusinessCentral.AL.Runner with the synthetic repro, and link the issue here.
2. If BC also fails, close it as a repro defect.

**Closed 2026-10-23 by ruling (coord task R-537, lethal-code): v3 matches BC, so this is a repro defect.** The same
shape (an invented processing-only report with a request page, run with `UseRequestPage(true)` and handled by a
`[RequestPageHandler]` that invokes OK) was measured:
- **On v3** alpha.2 (91253f2d6) and edge (57f1e4f98): `fail`, `An error occurred and the transaction is stopped.
  Contact your administrator or partner for further assistance.` at `RunModal`.
- **On BC 28.4** (bc2), through LethAL's bcdev path and Microsoft's test runner: `fail` with the same text, at
  `RunModal` (line 27 of LethAL's instrumented build; v3 named line 5 of the source). The pre-committed prediction (BC passes) was refuted
  (`docs/superpowers/specs/2026-10-23-r537-bc-probe-precommitment.md`).
- **The control passes on both:** the same report run with `UseRequestPage(false)`.

A test that fails at baseline is never scored, so this was never a false kill. Evidence: `/coord/handoff/R-537/`
(`measure.md`).
