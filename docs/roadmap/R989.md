Found by the R-973 review (R976, 2026-11-14). Related: [[R975]], [[R976]], [[R926]].

R975 decides a trigger mutant, and R926 a v3 mutant's reach, by whether a test's baseline HIT the line of the mutant's reach
statement. R976 gave block-grain mutants the line of their block's first statement. Two shapes rest on lines whose meaning is not
measured:

1. **A loop or compound keyword line.** When the reach statement (or a block's first statement) is a `repeat`, `while`, `for`, `with` or
   `case`, the reach line is the line of that keyword. Nothing measured shows that al-runner v3 reports a hit on a bare `repeat` line
   (or `case X of`). If it does not, a test that runs the statement does not count as covering it: a trigger mutant reads
   `no-coverage` while a test runs it (a LOST KILL), and R926 reads `covered-but-unreached`. Not new with R976 (list-placed mutants on
   such statements already use the line); R976 adds the bodies that open with one.
2. **A one-line guarded block.** In `if c then begin X := 1; end` written on one line, X's original copy keeps the source line, so X's
   line is also the `if c` line: a baseline that evaluates `c` as false still "hits" it. R926 then reads reached, and a trigger mutant
   is covered (over-runs, scores `survived`). It never loses a kill. Slot-placed statements share it.

**To close.** Measure with an invented app on `current` (al-runner `--per-test-coverage`): a test that runs a `repeat ... until`, a
`while`, a `case` and a `with` as the first statement of a trigger body and of a procedure, and one that skips each; read which lines
v3 reports. If a keyword line is never reported, place the reach line on the first statement inside the loop body or refuse the line
(FALLBACK 1). For shape 2, a reach line shared with a guarding condition could be refused when the original copy starts on the
condition's line.

Also noted (conservative, not a wrong verdict): `firstStatementOf` returns no line for a body that opens with an empty nested
`begin end;` or a nested block opening with `#if`, so those keep FALLBACK 1.
