**Filed 2026-10-24 by lethal-preproc during R-643** (R603).

**What.** R603 made CI's Windows `check` job run the unit suite through `verify.ts` at `LETHAL_VERIFY_PARALLEL=4`, and
un-skipped tests A5 and A7 of `scripts/verify.test.ts` there. A5 passed on Windows. A7 failed (CI run 40064651790,
`check` job: `VERIFY FULL: FAIL (10012 pass / 98 skip / 1 fail)`). A7 spawns `bun test --parallel=2` over three test
files, with and without the repo's test preload, and asserts:
- with the preload, each worker's HOME, `homeDir()`, `os.homedir()`, USERPROFILE and TMPDIR are not the sentinels;
- without it, each of the three fails by name (the control).

verify printed only the test's name. The detail stayed in its log file on the runner, so which assertion failed is
not known. A7 skips on Windows again (`parallelOs`) until it is.

**Why it matters.** The preload is what hides the real home directory from every test (`real-home-guard.test.ts`).
If it does not move HOME or TMPDIR in a Windows `--parallel` worker, a test on Windows CI could write to the
runner's real home or temp folder. `real-home-guard.test.ts` passed in the same run. A7's failure may instead be in
its control half, or in the spawn itself (for example a junit path or the `bunfig.toml` it writes).

**To close.** Run A7 alone on the Windows runner (a dispatched run on a scratch branch, `[skip ci]` pushes) with its
full output kept. Name the failing assertion. Then fix the preload (if a worker keeps the real HOME or TMPDIR) or the
test (if it is the control or the spawn), and un-skip A7 on Windows with that fix's own red check.

**Done by R-704 (2026-10-24).** Cause (read on Windows, run 40065734047): no leak. A reused worker or a child of a
test re-ran the preload after an earlier one had set USERPROFILE/HOME, so `LETHAL_TEST_REAL_HOME = homedir()`
recorded that FAKE home as "real". `scripts/test-preload.ts` now keeps an inherited value only when
`LETHAL_TEST_FAKE_HOME` is set and equals the current HOME; a stray export is ignored. Tests in
`packages/runner/tests/real-home-guard.test.ts`: the child keeps the parent's real home (red on the old line), a
stray value is ignored (red under a plain `??=`). A7 runs on Windows again; only CI on Windows can show it green.
