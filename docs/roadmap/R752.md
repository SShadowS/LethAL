## Done (c81513dd, 75da0881)

**Cause.** Not [[R720]]. [[R731]] (69478059) made `lethal.toggle-blank-string` refuse a one-character literal whose
target types as `Char` or unknown. A bare field of the implicit record (`"No." := 'Z'` in a table trigger) has no type,
so it was refused: that is the missing spec. R731 re-ran only its two new sweep shapes, so the drop (29 to 28) stayed
hidden until R-737's full sweep. A table field is never a `Char` (AL0156). Evidence: `git bisect run` on the w6 spec
count from bc0f9a8f (29) to c1034f7c (28) named 69478059; trace in `/coord/handoff/R-752/trace.md`.
**Fix.** `bareProjectFieldAt` (`packages/engine/src/semantic/receiver.ts`) says a bare identifier provably binds a field
of a PROJECT table in the innermost record scope (table, tableextension on a project table, page with a project
SourceTable, TableNo codeunit `OnRun`, report data item, `with`); `oneCharacterMayBeChar` then does not refuse it.
AL's name order is kept: a local, parameter, return value or object global of the same name wins (read by
`bareFieldAssignable`, every `#if` arm by text), and in a tableextension so does a global of the base table. Anything
unresolvable (no table, a dependency table, a pageextension, an unindexed member) stays refused. Operator version 1.1.1.
**Tests.** `packages/builtin-tier1/tests/r731-char-blank.test.ts` T1 to T6 (14 new). Red checks (logs in
`/coord/handoff/R-752/red/`): exemption removed, T1/T4a/T5a/T6a red; name-order check removed, T2w/T3p red (the plain
local and global cases type as `Char` and stay refused on their own, so the tests use a `with` body and a page
global, where the type is unknown); project-table check removed, T4b red; base-global check removed, T4c red.
**Measured** (`corpus-snapshot diff`, branch vs master): fixtures identical; DO +4, CDO +3, DC +2 (both in
`CDCAppEntryCompany.Table.al`), BaseApp +4; all `toggle-blank-string` in a table or page file, none removed, none moved,
hang counts unchanged. R402 sweep: exit 0, `w6_var_swallowed_table` 29/15/29/15. DC `Cloud` offline compile
(`scripts/r315-dc-compile.ts`): control and instrumented 0 errors. Pinned fixture manifests re-pinned for the new
operator version (the only change in them).
