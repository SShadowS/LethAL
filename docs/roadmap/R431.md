**Found 2026-10-04 by the R-389 probe** (`scripts/r389-probe/`, pre-commitment `ed343f09`, results
`6e9b20ed`, measured live on Cronus284). Route S1: code in ANOTHER app called
`Codeunit.Run(<integer id>)` with the id of a test-app codeunit, and that codeunit's `OnRun` ran.
External code needs no Variant and no knowledge of the test app's types to do this: an Integer is
enough.

**Why verify misses it.** `lethal verify` decides whether a test is unchanged from a per-test digest
(R-371, `packages/runner/src/test-digest.ts`, `testpage-scan.ts`). The walk follows test-app code and
folds what a record, Variant or interface argument can hold. It does not track INTEGERS. So when a
test hands an object id to another app as a plain Integer (for example `Codeunit::"My Mock"` passed
as an argument, stored in a setup record field, or computed), and that app runs it, an edit to that
codeunit (or to what it calls) leaves the test's digest unchanged. Verify then treats the test as
old: the unsafe direction.

**Not R-389.** R-389 covers a Variant or interface that HOLDS the codeunit, including the probe's
route R4d (`Format(V)` gives the id, then `Codeunit.Run(id)`), because the Variant still holds the
codeunit and the plan traces it. A bare Integer holds no object, so R-389's trace does not reach it
(orchestrator ruling, 2026-10-04: file it separately, keep it out of R-389's plan).

**Shapes to consider.** An id literal (`Codeunit::"X"`) passed as an Integer argument to external
code; an id written to a record field that external code reads; an id built from data. The first is
traceable inside the test-app procedure; the other two are not.

**To close.** Measure first how often a test-app object id reaches external code as an Integer on the
R-371 corpus (DC, DO), as R-389 does for Variants. Then decide: trace an id literal to its object and
fold that object's reach; for an untraceable Integer, either fall back (the whole-source digest) or
accept and document the gap, depending on the measured cost. Pin with a red-first test (edit the
codeunit, the digest must move) and a control (an ordinary Integer argument must not move a digest).
