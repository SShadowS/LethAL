**Found by the R-214 lane (lethal-preproc), 2026-10-01.** Plan: `docs/superpowers/plans/2026-09-29-R-214-symbol-aware-site-enumeration.md`. Pre-commitment: `docs/superpowers/specs/2026-09-29-r214-precommitment.md`.

**What happens.** `SessionReport` records the symbols from configuration but not the effective set (config plus `app.json`). `excludedSites` carries the effective set only when a site was compiled out. A reader of the report alone cannot tell which symbols built the run.

**Why it matters.** R214's history, resume and marks checks need the effective set. They read it from the run store, so the gap is in the report only. The agent guide's mark recipe works around it.

**What would close it.** Add the effective set to the report. The ripple list in CLAUDE.md applies: events, fold, report, schemas, snapshots, committed samples.
