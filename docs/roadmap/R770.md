**Filed 2026-10-25 by lethal-bugs during R-762.** Related: [[R765]], [[R762]].

**What.** [[R765]]'s contract-probe cache writes one `.probe-cache-<digest>.json` per key beside `.gated` in the pinned
build folder, and a forced fresh probe (`--fresh-probe`, `LETHAL_V3_FRESH_PROBE=1`) still writes its entry when it
passes. The v3 itest forces a fresh probe and builds each session with its own temporary package and al-runner cache
directories, both of which are key parts, so every gate session writes an entry under a key no later session can match.
Measured: 53 entries (about 11 KB each) in the `edge-dcdf9e821` build folder after a few hours of gate runs on
2026-10-25. Harmless today (nothing that guards the folder lists its files; R765's submit checks), but the count grows
without bound for the life of a build.

**To close (one of).** Do not write the cache on a forced run (the itest and the update gate force fresh, so they would
stop writing); or skip writing when a key part is a temporary directory; or cap or prune entries per build. A test per
direction: a forced run writes nothing (or a normal run still writes and hits).
