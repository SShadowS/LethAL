Found by lethal-code, 2026-11-12 (coord R-942, window 1). Related: [[R955]], [[R896]], [[R866]].

**What happened.** During DO's baseline (1,979 tests, isolation `auto`, default transport), the processes running were one-shot
`al-runner test --isolation codeunit --test-exact <one test> --run-selected-only`, four at a time, each about 30 s and 3 GB (peak RSS of
the run about 20 GB). `--isolation codeunit` is the request mode of a codeunit `chooseIsolation` set to `method` (R896), and a
method-isolated codeunit's tests are baselined one process each (`fillIsolatedBaseline`, R866). R-925's eight BC.History apps all ran
on serve with at most 18 codeunits re-baselined; here the rate implies most of DO's 112 test codeunits went per-test. The run was
stopped before any report, so the fallback/auto caveats that would name the reason were never written (R955).

**To find out (offline, before any DO resume).** Which codeunits auto moved to `method` and why (the trigger in the re-baseline
rule), and whether serve was used at all (no "fallback" line in stderr). Reproduce on a few of DO's test codeunits (`--tests` scope
narrowed) with the report written. Then: a LethAL cost gap (per-test one-shot where a served per-test request would do, R866's
ponytail note), a real interference in DO's tests (then the cost is the price of a correct verdict), or an al-runner difference
(invented repro + upstream issue, no Continia source text).

**Diagnosed (2026-11-12, `/coord/handoff/R-942/diag.*`, `lic-*`).** Every DO test was refused before it started: company
initialization reaches a DO subscriber that reads `License Permission`, and al-runner with no license file answers only the rows it
pins ("with no license file loaded"). LethAL had no way to pass a license, and al-runner's default (the license in the BC artifacts) is
absent from the cache. Every codeunit then tied at 0 passes, and R921's rule moved each to `method`, hence the per-test one-shot
baseline; serve never started (daemons 0). One test without a license: refused; with the CRONUS demo license: runs. DO's whole suite in
one al-runner process with the license: 1,805 pass, 49 fail, 125 not run of 1,979, in 14 s.

**Done (coord R-944).** `alRunnerV3.license` (a `.bclicense` path) is passed as `--license` on one-shot and serve calls, is in the
session fingerprint and the R586 lending build tag (` license-<sha8>`), and is named in the report by path and sha256; a refusal
"with no license file loaded" points at the setting. A codeunit with 0 green under `test` whose rows are plain fails or by-name
refusals is no longer re-baselined per test (a tie at 0 decides nothing); one with a cascade row ("an earlier test of this codeunit")
still is (R921's case), and the auto row leaves the unmeasured `methodPassed` out.

**Measured after (coord R-942, 2026-11-13, the diagnosis slice: 3 test files, 38 tests, `/coord/handoff/R-942/d944-*`).** Before
R-944, no license: baseline 287.5 s, 0 of 38 green, every codeunit re-baselined per test, no serve daemon. After, no license: 13.0 s,
0 of 38 green, all three codeunits kept on `test` ("0 green under test: a tie at 0 decides nothing, kept on test (R956)"). After, with
the CRONUS license: 24.2 s, 33 of 38 green, on serve (1 daemon); one codeunit tied 1/1 and stayed on `test`.
