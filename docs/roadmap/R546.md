**Filed 2026-10-09** from the owner's report, through the orchestrator (coord task R-546).

**What.** The owner sees mutants survive on al-runner but not on BC, or the reverse. The only
evidence in the repo is fixtures: 52 of 55 per-mutant verdicts agree between `itest:alrunner` and
`itest:bcdev`-style runs, and the 3 differences are LethAL's deliberate wrapped-object coverage
refusal ([[R497]]). No real-project comparison exists, so nobody knows the agreement rate, or which
differences are al-runner defects, LethAL limitations (for example [[R383]] multi-object coverage
off) or intended.

**Known al-runner differences to report upstream first:** [[R471]] (accepts AL0155) and [[R453]]
(loses a reportextension after Code Coverage Mgt.).

**To close.**
1. Commit the method (slice, config, comparison rule) to master before the live runs.
2. Run one real slice (CDO or DC) through bcdev (Cronus28 lease) and al-runner, and compare per
   mutant by identity key.
3. Classify every difference. Kill-vs-survive flips are reported separately from verdict-vs-no-coverage.
4. File an upstream issue with a repro for each al-runner defect, and a roadmap item for each
   unfiled LethAL limitation.
5. Commit the redacted results under `docs/measurements/`.

**Result (5c2d3a39), `docs/measurements/2026-10-09-r546-alrunner-bc-agreement.md`.**
- Method 33682a59, committed before the runs. Slice: CDO `5f2a71d`, `CDO Recipient Mgt.` (63 mutants,
  21 tests), al-runner `v2.12.0-main.43f76177` `--server` against bcdev on Cronus28.
- **Every mutant agrees on both legs.** Leg A (coverage off): 63/63, with 51 killed and 12 survived on both sides. Leg B (defaults): 63/63, with 51 killed, 8 survived and 4 no-coverage on both.
- **No difference of any class:** 0 kill-vs-survive flips, 0 verdict-vs-no-coverage, 0 error/timeout and 0 one-side-only. Even the killing tests are identical, so there was nothing to classify and nothing to file upstream from this slice.
- **al-runner loaded its own BaseApp 28.5** while Cronus28 runs 28.4, and the verdicts still agreed.
- **This bounds one codeunit only.** The owner's differences are presumably in code shapes this slice does not have: dialogs, reports, TestPages, [[R383]] and [[R497]] files. A slice with those shapes is the natural next measurement.
- **Upstream:** [[R471]] was reported as al-runner #5471. [[R453]] was not reproduced on 43f76177 or c5bbaf89.
