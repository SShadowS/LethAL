Found by coord task PR-26 while ranking refusal families. Evidence: `/coord/handoff/PR-26/ledger-compare.ts`,
`ledger-compare.txt`. Related: [[R1031]] (the same first-pass rows misread by a triage), R921 and [[R890]] (isolation auto's
re-baseline), [[R1013]] (the ledger).

**What.** `readStore` took every baseline row of the run whose outcome was a refusal. Under isolation "auto", a codeunit's first
pass runs under per-test rollback. The codeunits whose rows need it are then re-baselined one test at a time, and the test's LAST
row is its baseline (`triage-baseline.ts` reads it so). So a first-pass refusal the re-baseline replaced with a pass was counted as a
sighting, although it cost no covered test. Measured on a finished Sustainability run (R-925 `sus`, edge-5a58a0f16): 412 refusal
rows, 119 tests still refused. #8002's number-sequence refusal: 213 rows, 0 standing.

**Fixed (6f4b96b9).**
- **The rule:** `readStore` keeps each test's last baseline row (by codeunit id and method) and counts it only if it is a refusal.
- **Test:** a first-pass refusal replaced by a pass is not a sighting, and a refusal in both passes counts once. Red when the
  rule is reverted to every row.
- **Over all 774 v3 stores under `/coord/handoff`:** 166,464 sightings before and 156,454 after. Open sightings by issue
  (before -> after):

  | issue | before | after |
  |---|---|---|
  | #7775 | 8,385 | 7,487 |
  | #7854 | 4,021 | 3,515 |
  | #8002 | 1,981 | 1,121 |
  | #8028 | 1,158 | 1,030 |
  | #7819 | 706 | 408 |
  | #7837 | 760 | 380 |
  | #7586 | 390 | 213 |

**What is still counted.** #8002's number-sequence refusals still stand in the last row, by the run's recorded isolation choice
(674 stores read):
- 720 come from runs that recorded none: an explicit isolation "test", or runs from before auto;
- about 400 come from runs under auto, whose choice left those codeunits on per-test rollback.

So the refusal does cost covered tests under the default too. The finished Sustainability run (auto) has 0.
