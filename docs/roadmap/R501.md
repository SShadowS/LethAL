**Found 2026-10-06 while measuring [[R487]] item 6** (plan r2 `/coord/reviews/R-487-plan/plan.r2.md`, section "Item
6"; census and sample in `/coord/handoff/R-487/survey.md`). Not covered by R487's blanket rule, which refuses only the
four VALUE operators (`remove-assignment`, `shift-integer`, `flip-boolean-literal`, `swap-additive`).

**What.** In an open `Integer` data item ([[R484]]), the condition of a `CurrReport.Break`/`Quit`/`Error` guard is
mutated by `remove-not` (359 on BC.History), `negate-conditional` (314), `conditional-boundary` (24) and `negate-guard`
(21), 718 in all. Those are not value writes, so R484 and R487 do not refuse them. Shift-integer literals (199) and
toggle-blank (72) also sit in those guards; R487 now refuses the shift-integer ones.

**Sample** (10 of 718 read by hand): 1 hangs, 1 depends on the data, 8 do not hang.
- Hang: `remove-not` on `if not Continue then CurrReport.Break()` (PurchaseInvoice).
- Data-dependent: `negate-conditional` on `TempBuffer.Next() = 0` (ArchivedPurchaseOrder). It hangs on a one-row
  buffer, which is R164's shape.
- No hang (8): `OnPreDataItem` gates (4), `Number = 1` negations (3), and a `const(1)` item voided by a mention (1).

**The exit itself.** Removing the exit is a certain hang where it is the only exit: `void-method-call` on
`CurrReport.Break` (510 on BC.History) and `empty-block` (488), in `OnPreDataItem`/`OnAfterGetRecord` of an open item.

CDO, DC and DO have 0 (they have no `Integer` items).

**To close.** Measure first, then design an R164-style cession for these operators in an open item (as
`loop-truncate` did for `repeat` exits), or close it with a ruling.

**Closed 2026-10-08 by `85b94713`** (plan `/coord/reviews/R-501-plan/plan.r3.md`, adversary r3 SOUND; build record
`/coord/handoff/R-501/build.md`). Identity scheme **33** (31 was held for this item and is unused, because [[R509]]
took 32 first).

**The rule.** One check at dispatch, not in any operator: `generateMutationSet` asks `openItemHangRefuses`
(`loop-hazard.ts`) for EVERY operator that targets a site. There is no operator list and no exemption. The check
holds when:
- the site is in open-item code (R487's scope: the item's triggers, its child items, a reportextension dataset
  block anchored on it, and same-object procedures that code reaches); or
- the site deletes or alters the `SetRange` call that is a bounded `Integer` item's ONLY bound (the single-mention
  certificate of [[R484]], on an item without `MaxIteration`). "Alters" means the site contains the call or sits
  inside it.

Only a mutable site is refused. A report column's source stays declarative and is not counted. Refused sites go to
[[R447]]'s `hang-refused` row, under the same `#if`, `--operator` and `--lines` filters. `loop-skip` and
`loop-truncate` are refused too: the r3 sample found two certain hangs where `loop-skip` froze an item's only
cursor step.

**What it does not cover.** The [[R500]] exclusions still apply to every operator: code that runs before the item,
procedures in other objects, table triggers reached through `Insert(true)`, items over ordinary tables, `Date` items,
XMLport `Integer` elements, reportextensions outside the project, and a `while`/`repeat` inside a bounded item's
code. Most refused sites would terminate; this is the over-refusal R484 and R487 already accepted, chosen over a
ruling because a hang strands the container when `--stop-hung-sessions` is off, and a `timeout-killed` verdict is a
kill no assertion produced.
