**Found 2026-10-04, running `bun update` for the kraken no-pinning change.** `bun outdated` shows
`@biomejs/biome` 1.9.4 current, 1.9.4 within range, 2.5.15 latest. The range is a major behind, so
`bun update` did not move it, and the lint rules and formatter output of 2.x differ (config schema,
rule names, import sorting), so it is a migration, not an update.

Evidence: `bun outdated` output on branch `lethal/kraken-corpora` (commit "bun update: in-range
updates"); `biome.json` and the pre-existing `organizeImports`/format debt in `engine` and
`builtin-tier1` that CLAUDE.md already calls noisy.

Gate: `biome migrate`, then `bun run typecheck`, `bun scripts/verify.ts`, and both CI jobs (`check`
on Windows, `unit-linux`) green. Format the touched files only, as CLAUDE.md says, and keep the
`noNonNullAssertion` error rule.

## Measured 2026-10-08 (R-436), on master `c89eb0c7`

**1.9.4, today:** 912 files checked; 31 files of format debt, 1 of import-order debt, and 57 lint errors
(`useTemplate` 20, `noUnusedTemplateLiteral` 19, `noNonNullAssertion` 8, `useSingleVarDeclarator` 5,
`noDelete` 4, `noExportsInTest` 1).

**2.5.15, after `biome migrate --write`** (`organizeImports` becomes the `assist` action; `recommended: true`
becomes `preset: "recommended"`; `files.ignore` becomes negated `files.includes`):
- **The churn.** Its safe fixes alone (`biome check --write .`, applied and then reverted) touch **365 files,
  +1,566 / −2,901 lines**. Formatting alone, with `organizeImports` off, is 37 files, mostly the JSON and scratch
  debt 1.9.4 already flags. So **about 330 files are import sort only**: `assist/source/organizeImports` flags 332
  files, where 1.9.4 flags 1, because 2.x orders imports and imported names differently.
- **Error rules that drop out of the recommended set:** `noUnusedTemplateLiteral` (19 hits),
  `useSingleVarDeclarator` (5), `performance/noDelete` (4) and `noExportsInTest` (1); **`useTemplate` drops to
  info** (20). `noNonNullAssertion` stays an error (8 hits, unchanged).
- **New:** `useIterableCallbackReturn` (7 errors), `noUnsafeOptionalChaining` (1 error), and 47 warnings (unused
  imports, variables and parameters; `noTemplateCurlyInString`; `noUselessEscapeInString`;
  `useBiomeIgnoreFolder`).
- **The format hook is unchanged.** `.claude/hooks/biome-touched.ts` runs `bunx biome check --write <file>`, which
  2.x accepts with the same safe-fix meaning. Under 2.x that same command would re-sort the imports of any of the
  ~330 files on its next edit.

**Ruling (orchestrator, 2026-10-08): option 3, stay on 1.9.4.** The upgrade buys nothing functional today.
- Migrating with import sorting off silently weakens import-order enforcement, and needs hand-pinned rule restores
  that we would then maintain.
- A full migration is the repo-wide churn that was ruled out.

The WIP branch was dropped unmerged.

**Reopen when:** a 1.x security issue appears, a 2.x rule is needed, or a Bun or TypeScript change appears that
1.9.4 cannot parse.
