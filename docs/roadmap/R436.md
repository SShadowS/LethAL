`builtin-tier1` that CLAUDE.md already calls noisy.

Gate: `biome migrate`, then `bun run typecheck`, `bun scripts/verify.ts`, and both CI jobs (`check`
on Windows, `unit-linux`) green. Format the touched files only, as CLAUDE.md says, and keep the
