Found by lethal-preproc in the combined DO run c2 (2026-11-21), class C of
`docs/measurements/2026-11-21-combined-do-c2-main.md`. Evidence: `/coord/handoff/combined-do/` (`c2-unexplained.tsv`,
`c2-reconcile.py`, `c2.run.report.json`, perf10c's report under `/coord/handoff/PR-217/`). Mutant codes and numbers only.

**What c2 found.** 21 mutants changed their covering set between perf10c (fork build) and c2 (main-ccd0f823d) with no
reason in the two baselines (every other coverage move, 955, is explained by tests that are green in one baseline only).
- **8 are explained:** M30439-M30446 sit in a table's `OnInsert`. perf10c's runner refused that trigger's coverage
  (`cause: runner-refused`), so LethAL fell back to all 1,680 green tests (`coverageAttribution: all-green`). c2 measures it
  by line (2 tests or none).
- **8 are not:** M6778, M6781, M6782, M6785, M6786, M6789, M6790, M6793, in one procedure of a dispatcher codeunit.
  - In c2 every other mutant of that procedure is covered by the same 7 tests (perf10c: 2; the 5 extra are
    baseline-explained).
  - These 8 are covered by 26. For example, in the block on lines 33-36, M6778 (`empty-block`, enclosing grain, line
    33) and M6781 (`void-method-call`, line 35) have 26, while M6779 (`remove-testfield`, line 34, a statement that runs
    before line 35) has 7.
  - c2 kills them by a test OUTSIDE the 7, and the kill reproduces (`killReproduced`). So either the 7-test sets
    under-report this procedure's reach (and its other mutants' `survived` verdicts were scored against too few
    tests), or the 26-test sets attribute tests that never reached the line.
- **5 are not explained yet either:** M19606-M19610, in another codeunit's loop body (lines 1007-1012). perf10c had no
  covering test (no-coverage); c2 has 2, and kills reproduce. A runner behaviour change that now runs the loop body is
  plausible but not measured.

**Why it matters.** The covering set decides which tests run under a mutant. An under-reported set turns real kills into
`survived`. An over-reported one only costs time, unless a kill comes from state left by another test.

**Next step.** One offline v3 run of the dispatcher's codeunit with per-test coverage rows dumped, comparing a test in
the 7 and a test of the 20 outside it at lines 33-36. Then the same for M19606's two tests on both builds.
