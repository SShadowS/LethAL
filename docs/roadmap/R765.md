**Built 2026-10-25 under coord task R-762 (lever 4).** Design and the per-fact key table:
`/coord/handoff/R-762/lever4.md`; red checks: `/coord/handoff/R-762/cache-red/`.

**What.** `AlRunnerV3Backend.status()` ran the 28-fact contract probe every session (about 10 s). It now stores a FULLY
PASSING result in `.probe-cache-<digest16>.json` beside the pinned build's `.gated` (atomic temp + rename) and replays
it when every key part matches: binary sha256 and version, a hash of the CONTENT of the probe code files (read at run
time, so it cannot be forgotten like a constant; unreadable means no cache), bcVersion, a fingerprint of the packages
folder's `.app` names, sizes and mtimes, alc path and bytes hash, the cache-dir value, the `.gated` record text
(lethalCommit), taskset presence, and Library Assert absence. Never read or written: candidate builds, leg C (it calls
`runV3ContractProbe` directly), any result with a diverged, refused, unlike-bc or unmeasurable fact. A missing key
input, unreadable or corrupt entry runs the probe. `--fresh-probe` and `LETHAL_V3_FRESH_PROBE=1` force a run (and
refresh the entry); the v3 itest sets the variable. Each session prints which path it took, with the key digest.

**BLOCK found by the live proof, fixed.** On the pinned build (edge-dcdf9e821) the cache never engaged: the pin records
`duplicate-key-insert-raises = refused` (#5788), the first rule refused every `refused` fact, so nothing was written
and nothing said why (proof: `/coord/handoff/R-762/cache-proof/proof.md`). Now a result is cacheable when a normal
session accepts it AND every fact passes or equals THIS build's pinned reading (`findV3Pin` + `pinnedFactMatches`,
version AND sha256). A refused, diverged, unlike-bc or unmeasurable fact with no equal pin stays uncacheable; the same
rule runs on read. A result that is not stored says so in the receipt: `not cached: <fact> = <verdict>, not the pinned
reading`. Red checks: `/coord/handoff/R-762/cache-red-block/`.

**Not yet proven live.** The proof is the orchestrator's: gift-card serve wall before and after, the v3 gate on the final head.
