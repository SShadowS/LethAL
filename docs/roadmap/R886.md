Found by coord task R-881 (BC.History on al-runner v3, edge-05d692e5e). Evidence: `/coord/handoff/R-881/` (`r2-*.events.ndjson`,
`result.md`). Related: [[R885]].

**What.** al-runner runs .NET types through a separate process, the sidecar, named with `--dotnet-sidecar <dll>`. Without it, a test
that reaches a .NET type is refused: "dotnet-unavailable: DotNet 'System.TimeZoneInfo' sidecar not built; run 'dotnet publish
tools/dotnet-sidecar ...' and pass --dotnet-sidecar ...". LethAL has no config field for it and never passes the flag.

**How much.** With demo data in the cache ([[R885]]), the CRONUS setup sends ordinary posting and setup paths through .NET time zone
and URI types. Round 2's baselines: PaymentPractices 29 of 36 tests refused (`System.TimeZoneInfo`), BankDeposits all 75 (TimeZoneInfo
56, `System.UriKind` 9, `System.DateTimeOffset` 3, the rest cascades and R-881's SaveAsXml refusal), ServiceDeclaration 54 of 61
directly or by cascade. Without demo data, BankDeposits still had 37: 15 refused on `System.DateTimeOffset` and 22 by cascade.

**What a fix needs.** A config field (for example `alRunnerV3.dotnetSidecar`) passed through to every al-runner process, one-shot and
serve; checked by `doctor`; in the run's cache key if it changes results. Building the sidecar needs a .NET SDK, and its build must
match the al-runner build, so where it comes from (shipped with the gated build, or built by the update script) is a decision to make
first.
