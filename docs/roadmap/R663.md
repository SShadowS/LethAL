usable by 23 Oct midday. Related: [[R589]], [[R662]], [[R664]].

**What.** A fourth instance `bc-demo` on server1 (192.168.2.157, BC on Linux, the same stack as bc1-bc3), with its
own ports. It is never in any lease pool and never used by a gate: it belongs to the talk. An idempotent setup
script (extend `scripts/bc-linux-setup.ts` or a sibling):
- brings it up if needed;
- publishes LethAL Control 1.0.0.23;
- writes the gitignored `examples/gift-card/lethal.config.demo.json`;
- runs `lethal doctor`.

The databases are in memory, so the script is also the demo reset after a reboot. It must work with no network
beyond the laptop itself, because the talk runs network-off. Check RAM headroom on server1 first (34 of 93 GB
used on 22 Oct).

**Built 2026-10-22 (coord task R-663, branch `lethal/r663`).** `scripts/bc-demo-setup.ts`, ports 7348 / 7349 /
7352, outside `SERVERS`, so it takes no lease; `scripts/bc-demo-setup.test.ts` pins that it stays out of
`SERVERS`, `bc-linux-setup.ts`'s lease path and every itest. Details: `docs/gates/servers.md` §"bc-demo".
**Measured 2026-10-22: bc-demo is not up.** Its three ports time out, as unused ports on server1 do, and the
