**What.** [[R570]] refuses a cursor-shaped procedure in another project object when the loop's EXIT calls it (its
condition, or a body exit guard). The usual iterator idiom stores the callee's result in a flag first: the body
assigns `More := X.GetNext()` and the condition reads only `More`. R570 does not follow the flag to the call, so the
callee's sites stay deployed.

**Build (coord task R-572, plan r4, `docs/superpowers/plans/2026-10-20-r572-flag-fed-iterator.md`).** Branch
`lethal/r572`; the rule is `r572LoopRefusals` in `packages/builtin-tier1/src/loop-hazard.ts`, tests in
`r572-flag-fed.test.ts`, red checks in `/coord/handoff/R-572/build.md`. A loop whose exit is fed by another object's
STATEFUL procedure (a flag, a `var` argument, or a call in the exit) refuses the chain and the writers of its value
path (`r572ValueWriters`, a fixpoint). Option D and narrowing (a) skip a loop whose own step forces the exit;
the zero-step refusal (`r572RequireNonZeroStep`) is lifted, by the orchestrator's ruling of 2026-10-21, only where
the step is never anything but a Record or RecordRef `Next(<step>)` step, the measured fact
(`/coord/handoff/R-572/next0-probe.md`: `Next(0)` returns 0 and does not move the cursor), and kept for a step that
is also a counter step or reaches a custom advance. By the same ruling a guard that dominates a call into a refused
procedure in the loop body (`if It.ShouldAdvance() then It.Advance()`) is refused too, its sites and its callees
(reason `r572-guard-writer`, seam `r572GuardWriter`; the census prints `GUARD-WRITER` rows and
`guardWriterSites`). After the re-price: a value-path name resolves to a global only when no parameter or local
shadows it (Item Jnl.-Post Line over-refusal), a flag fed from itself no longer recurses (visited set plus
refusing depth backstops), and `IDENTITY_SCHEME` is 41 (a guard refused as one site renumbers its same-tuple twins).

**Stated limits** (each errs toward deploying):
- A stateless callee fed its own result (`D := X.NextDate(D)`, the CDO NextSendingDate shape) or whose result is
  added into the flag is not refused. `scripts/r572-flag-census.ts` prints such rows as `RE-OPEN SHAPE`: re-open
  this item when one sits in a loop with no other stop.
- Statefulness and the value path are read by name, 4 calls deep; past that a call is UNKNOWN, which counts as
  stateful. Writers are looked for only in the chain's own objects, among the procedures reachable from the chain,
  the loop body and their `Codeunit.Run` steps.
- Event subscribers are not followed, as in R570.
