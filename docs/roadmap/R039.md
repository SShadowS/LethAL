**The batch project copies only `*.al`, so a real app's resources never reach `alc`.** `prepareBatchProject` (`packages/runner/src/orchestrator.ts`) filters `readdir` to `.al` and copies those alone, but `app.json` still names `logo`, and a real project also carries translations (`.xlf`), control add-in bundles, permission XML and report layouts. alc stops at `app.json(13,3): error AL1001: Source file 'Images\Logo.png' could not be found` — before compiling a single line, so the failure is not even attributable to instrumentation. Every fixture is resource-free, which is why this never surfaced. Note the `.al` copy is also FLATTENED to `basename` with a silent `if (exists) continue`, so two same-named files in different folders would drop one without a word; DO happens to have 551 distinct basenames out of 551 files, so the flattening survived here by luck, not design. Measured 2026-07-27 on Continia Document Output.
