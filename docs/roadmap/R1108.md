Filed 2026-11-17 by coord PR-116 (lethal-preproc), from [[R1102]]: on DO, 557 of 868 error verdicts are withheld kills.
A covering test failed under the mutant, and al-runner v3 reported `NotRun ... this failure is not trusted` because an
earlier test of its codeunit was refused. LethAL records each as an `error` with cause `runner-refused`, the same as a
mutant al-runner truly cannot run, so a reader sees errors and a lower score with no reason given.

**The change** (spec `docs/superpowers/specs/2026-11-17-pr116-withheld-kills-in-report.md`): report-only. Verdicts,
causes, failure notes and exit codes are unchanged. It adds:
- `withheldKill` on each such mutant (the withheld failure, and the earlier test when v3 names it);
- the caveat `withheld-kills`, naming the remedy for the run's isolation mode (isolation "auto", measured in R1102);
- a console line beside the score, which gives the count.

(Spec r2 dropped r1's `counts.withheldKills`: a required count would have forced a live regeneration of the committed
sample report.)
