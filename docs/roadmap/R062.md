**`AppMethodIndex` never resolves an extension's method names, so every `tableextension`/`pageextension` procedure falls to object level.** `SYMBOL_ARRAYS` (app-package.ts) listed six object kinds and omitted `TableExtensions`/`PageExtensions`; MEASURED 2026-07-28 by compiling a probe with one of each — the arrays exist, are named exactly that, and carry `Id`/`Name`/`Methods` like the rest, so the data was there all along. Consequence: an extension's coverage missed at member level and landed as an object-level entry — safe, one precision level coarser, and invisible. (Post-R63 the fall-through branch is the object-level emission, not the deleted `findLocalProcedureNames` expansion this entry first cited.) No fixture declares an extension, so nothing gated it either way.
