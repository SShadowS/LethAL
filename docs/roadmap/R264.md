**Measured 2026-09-26 on this machine, `lethal/lane-bugs` at master `bb8e846`.** `bun test
packages/runner/tests/doctor-cli.test.ts packages/runner/tests/al-runner-cache.test.ts` alone, no
other load: 30 fail, every one a 5000 ms timeout, plus 6 unhandled errors between tests. One test
alone (`readAlRunnerCache` "an absent directory is a MEASURED absence") times out too.

**Cause.** `readAlRunnerCache(dir, secondaryDir?)` falls back to `defaultAlRunnerSecondaryCacheDir()`
(`~/.cache/al-runner`) when the caller passes no second root, and walks it with `directoryBytes`
before anything else. The tests pass a fake FIRST root but not a second, and `buildDoctorDeps` in the
doctor tests reaches the same default. On this machine that tree is 5.4 GB in 42,538 files, which
takes longer than bun's 5 s test timeout to walk. So the result depends on the developer's disk, and
the failures had been read as "random load noise".

**Fix direction.** Every test passes an explicit (empty, temp) second root, or the default is
injected through the deps the tests already fake. A test must never walk a real home directory.

Evidence: the failing names in `.superpowers/sdd/2026-09-26-C02-07-agent-contract-and-docs/baseline-test.log`
(scratch), `du -sh ~/.cache/al-runner`, and `readAlRunnerCache` in `packages/runner/src/al-runner-cache.ts`.

`doctor-al-runner.test.ts` fails the same way in the full suite and passes with `--timeout 120000`
(found during C02-07 Task 1), so it belongs to this item too.

**Closed 2026-09-27 (`7e27b0b`, `a3d961f`, `f02a2c1`).** A root `bunfig.toml` preloads
`scripts/test-preload.ts`, which points `USERPROFILE` and `HOME` at a fresh temp dir for every
`bun test` process, and `real-home-guard.test.ts` fails if that redirect is not in force. `doctor`
now takes al-runner's second cache root as an injected option (`alRunnerSecondaryCacheDir`), and
every doctor test goes through one helper that also fakes alc discovery, the alc spawn and the
package cache, so the three files stay fast even from `packages/runner` where the preload does not
load. Evidence: two back-to-back full runs, each after a recorded typecheck and dist cleanup, both
3674 pass / 0 fail / exit 0 / no unhandled errors, 57 s each (the baseline was 3637 / 33 / exit 1,
about 244 s); every seam red-checked (a reverted seam fails on a path mismatch against the fake home,
and with the preload off the original test times out again on the real cache).
