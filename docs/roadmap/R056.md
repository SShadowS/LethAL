**A docs-only commit deleted a fixture test's body, and the tables gate kept passing for days against a stale published test app.** Commit `76dfe48` rewrote a comment inside `InsertDoublesAmountWeak` (`fixtures/sandbox-data-tests`) and removed the procedure's statements and its closing `end;` with it. The project has not compiled since; `alc` reports `AL0104: Syntax error, 'end' expected`. `itest:tables` nevertheless passed every run, because LethAL publishes the TARGET on each run and treats publishing the TEST APP as the user's own workflow — so the gate measured a stale build while the source was broken. **R31 cannot catch this shape**: it fires when the server has no result for a discovered test, and here the server had an OLDER, WORKING build of every test, so nothing it measures diverged. Found 2026-07-27 while doing R36, by compiling the fixture — which nothing in the repo does. The body is restored, the app rebuilt at 1.0.0.1 and republished, and the gate re-verified. **The durable fix is not done**: nothing still compiles the test fixtures, so the next such edit repeats this. Wants an offline `alc` compile of `fixtures/*-tests` in the same place `bun run typecheck` lives, which would have caught it in seconds.
