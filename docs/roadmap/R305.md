**Found by R-297 Task 6 (2026-09-28)**, plan
`docs/superpowers/plans/2026-09-28-R-297-instrumentation-real-corpora.md`, Task 6.

**The shape.** `#if not SYM` / `codeunit N "Name" implements A` / `#else` / the same header with a
different `implements` list / `#endif`, then one shared `{ ... }` body. The parse is
`preproc_split_declaration` directly under `source_file`, not a `codeunit_declaration`.

**What happens.** `generateMutationSet` (`packages/runner/src/orchestrator.ts`) does not recognise
the object kind and records the file in `skipped` with `kinds: "preproc_split_declaration"` and its
site count. It is a NAMED refusal, not a silent loss, and not a throw. But every site in the object
is dropped: on the hand-written repro the twin (one header, no directives) has 9 mutants and the
split has 0 (check b FAILS; checks a, c and d pass, d trivially, because nothing is instrumented).

**Corpus counts** (Task 0's census): sysapp 2 files (`DefaultEmailConnectorv2.Codeunit.al`,
`EmailConnector.Enum.al`; an enum has no sites, so one codeunit loses its sites). Zero in dc, bcf
and BaseApp.

**Why it is not a small fix.** Admitting it needs the object-container rule (`isObjectContainer`,
`objectDeclarationsOf`), the header reader (`objectHeadersOf`), the selector injector and both
coverage indexes to read an object id and name from a split header, with a rule for arms that
disagree. That is several walks, not one condition.

**Closed 2026-10-05 as a ruling: a stated limit, no change** (R-305 census, `/coord/handoff/R-305/measurement.md`, master 8b177557; one census with R298 and R398).
- **How it is handled today.** It is not a refusal. Spec generation finds the sites, then `canCarryMutationSelectorVar` says no, so the file is skipped and its sites dropped. That is why no `instrumentation-refused` row appears for it.
- **Measured** over 249 `app.json` projects (fixtures, examples, the unit fixtures, CDO at 5f2a71d, and 203 BaseApp corpus projects):
  - BaseApp: 5 files hold a split header, and 2 of them have sites (`EmailOutlookAPIClient.Codeunit.al`, 571; `EDocumentNoIntegration.Codeunit.al`, 22). **593 sites lost, 0.026%** of BaseApp's 2,267,656 deployed sites.
  - Every other corpus: 0.
- **Why no change.** Admitting the shape needs several walks taught a split header (above) for a quarter of a per-mille of one corpus. If a project shows it in bulk, re-run the census before reopening.
