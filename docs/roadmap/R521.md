**Filed 2026-10-08 by the [[R500]] build** (plan r3 `/coord/reviews/R-500-plan/plan.r3.md`, shape 2). A plausible
hang that is NOT refused.

**What.** R500's one-hop rule finds a callee through the receiver's declared type (`declaredType`: `Record`,
`Codeunit`, `Interface`) or a record the engine binds (`resolveReceiverTable`). A call through a `RecordRef`, a
`Variant`, a `FieldRef`, or a parameter or return value whose type this lookup cannot read is not followed, so
the procedure it reaches in another object is still mutated. Three more receiver shapes are not followed either
(the R-500 build review, `/coord/reviews/R-500/opus-build.md`, F2): an array element (`Post[1].Step()`, whose
receiver is a subscript, not an identifier); a `Report` or `Page` typed receiver (`objectsOfType` maps only
codeunits, records and interfaces); and an implementer whose `implements` names a namespace-qualified interface,
which the grammar parses into an `ERROR` node, so the implementer is not found.

**To close.** Count the untyped receivers called from open report-item code on BC.History, CDO, DC and DO; read
a sample; then refuse their possible targets (all implementers or tables) or close it with a ruling.
