**Found by** alrunner (2026-11-24, relayed by the orchestrator after coord PR-415). #8861, #8862 and #8871 (FormatRegion
da-DK, fr-FR, sv-SE) were BC-on-Linux culture data (ICU). Windows BC (NLS) matches al-runner, so they were not al-runner bugs.
Closing them is the owner's call (a GitHub comment). Recorded by coord PR-417.

**The rule.** A culture-dependent BC answer is recorded as "measured on Linux BC <build>", and is never filed upstream as an
al-runner bug unless Windows BC gives the same answer. Culture-dependent means: Format, FormatRegion, a report language, dates
and times, decimals, digit grouping, month and day names, sort order and collation. Answers that do not depend on culture are
unaffected: refusals, whether an error is raised, conversions, row counts. The rule is written into:
- the `al-probe` skill;
- `scripts/refusal-family.ts`'s header;
- each family's `bcMeasured` record. `linuxBcCultureCells` lists a family's Linux culture cells, and `--join` prints them.
