Found by coord task R-908 (2026-11-10). Evidence: `/coord/handoff/R-908/`. Related: [[R69]], [[R908]], [[R910]].

**What.** `describeTestPageUnsupported` (`testpage-unsupported.ts`) names a page refusal by the text `CreateNavTestService()`, seen only on Windows containers. On Linux BC (`bc1`-`bc5`) the same event reads
`Unexpected CLR exception thrown.: System.NotSupportedException: Specified method is not supported.` with no .NET frame; the first AL frame is at the page call. Measured on `bc5`: 156 helper-reach tests and 3 direct pilots, every top frame at a page-opening call.
So on Linux such a test is reported as an unexplained failure, and the mutants it alone covers lose the explanation.

**Not every `NotSupportedException` is a page.** Matching the message alone would claim unrelated CLR failures. The recogniser must confirm that the top AL frame is a page call.

**To build (coord R-909).** Recognise the shape only when the top frame resolves to a page-opening call in source LethAL has (test app, target). A frame in dependency code, whose source LethAL does not have, stays unnamed.
