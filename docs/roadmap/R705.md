**Filed 2026-10-24 by R-586b (lethal-bugs)**, evidence the failed alpha.5 receipt
`/work/tools/al-runner-v3/failed/v3.0.0-alpha.5@6eddda0bc744b5397dc11c5edc34fc841d065e47/gate.log` ("C: serve-keep-reasons
= diverged | http: MOVED no row Codeunit50670.HttpGet; commit: MOVED no row …; … no-callee: MOVED no row
Codeunit50674.DoesNotCompile") and [[R586]]'s r15 pre-commitment. R635 records the same cause.

**What.** The warn fact `serve-keep-reasons` (R612, `serveKeepReasons` in `packages/runner/src/al-runner-v3-contract.ts`)
runs ONE `serve` request over five invented tests. Codeunit 50674 (`DoesNotCompile`, `NoSuchProcedure(1)`) is in the same
tests app (`SERVE_TESTS_AL`) and does not compile. Since upstream's #5602 fix (alpha.4, edge, alpha.5), v3 runs no test
in a request whose apps do not compile, so NO row comes back, for any of the five. alpha.3 (before #5602's fix) reads
`matches`; alpha.4, edge and alpha.5 read "no row" for all five. The fact says nothing about those builds' keep reasons.

It is not an upstream difference: v3 is right to run nothing.

**Why it matters.** The fact is a warn, so it changes no gate outcome. But K, the only leg that exercises the serve path,
is skipped on candidate builds, so nothing else measures a candidate's serve path. Until this is fixed, "a moved keep
reason only makes the daemon close" is unproven for every build after alpha.3. A K / serve measurement on alpha.5 is a
prerequisite of admitting it (R-586c).

**To close.** One of:
- Move no-callee into its own `serve` request (own tests folder), so the other four stay compilable. The no-callee case
  then reads `matches` on an old build and "no row" on a #5602-fixed build, and the fact must say which.
- Drop no-callee and its `V3_SERVE_SAFE_REFUSALS` entry (a #5602-fixed build cannot produce that row at all).
- Either way, re-measure the other four on alpha.5: the http text and the cascade case have moved one-shot (the
  localhost call is a plain fail; `refusal-cascade` is gone), so the `http` and `cascade` entries need new pins or
  removal, each by a delta.

Needs its own pre-commitment (leg C's fact set and its expected readings move).
