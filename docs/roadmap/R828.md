Everything nested in that body joins the chain, and each branch repeats the root's text: the same fold as [[R827]], on a smaller
scale.

chain is still 26 to 66 and the emitted size 146 to 916 KB. Details: `/coord/handoff/R-825/r827-impact.md`.

at it after R827, and only if a measurement says it still matters.
