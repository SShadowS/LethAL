**Found 2026-10-05 by the orchestrator's opus merge review of R-294** (merged 281efeca).

R-294 stops typing a name that falls through to globals in implicit-`with` contexts (a page or
pageextension with `SourceTable`, a codeunit's `OnRun` under `TableNo`, report dataitems and request
pages), because a record field can shadow the global there. It finds the property with `hasProperty`
in `packages/engine/src/semantic/types.ts`, which reads `declarationMembers()` (`tree-walks.ts`),
direct members only. A `SourceTable` or `TableNo` wrapped in a member-level `#if` is therefore missed,
the object reads as having none, and its globals are typed again: the unsafe direction (a swap that
`alc` rejects, the R295 wrong-mutant class).

REASONED, not parsed or compiled; expected rare. **To close:** measure first (count such objects on
BaseApp and CDO); if any exist, also look inside member-level `preproc_conditional` nodes, in any
arm, and pin it with a red-checked test (a `SourceTable` under `#if` must block the global's type). If
there are none, close as a ruling with the count.

Also noted, no action: the reportextension request-page branch (`p.parent?.parent`) has no test, and
is moot today because `enclosingObjectScopeKey` gives reportextension no scope.

**Closed 2026-10-05 as a ruling: zero objects have the shape, so no change** (R-450 measurement, master f5bc0833).
- **Method.** A line scan of every `.al` file that counts a `SourceTable` or `TableNo` property line only when it sits inside a `#if` block opened AFTER the object's header, that is, inside the object body: the member-level shape this item names. A `#if` wrapping the whole object is excluded; that is R343's shape. A synthetic control page with `SourceTable` under a member-level `#if X` is found by the same scan.
- **Measured:**

  | Corpus | `.al` files | With `SourceTable`/`TableNo` | Member-level under `#if` |
  |---|---|---|---|
  | BaseApp corpus (BC.History) | 17,451 | 4,146 | **0** |
  | CDO at 5f2a71d | 677 | 181 | **0** |
  | `fixtures/` | 76 | 3 | 0 |
  | `examples/` | 11 | 0 | 0 |
  | unit fixtures | 27 | 0 | 0 |

- **The whole-object cases.** A first, unrefined scan also counted 23 BaseApp files whose `SourceTable` or `TableNo` sits inside a `#if` wrapping the WHOLE object (for example `BookingItems.Page.al` under `#if not CLEAN28`, and the PEPPOL export codeunits under `#if not CLEAN26`). These are not this shape: the symbol table leaves a wrapped object unindexed (R343), so typed operators emit nothing inside it, and no global can be typed there.
- **Limit.** Reopen if a project puts `SourceTable` or `TableNo` under a member-level `#if`; the fix is then the one described above (`hasProperty` also looks inside member-level `preproc_conditional` nodes, in any arm).
