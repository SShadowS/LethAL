**Found 2026-10-21** by the Opus build review of [[R586]] (`/coord/handoff/R-586/review-build-opus.md`, Minor 7).

**What.** The v3 backend tags a survivor whose codeunit holds a test v3 refused at baseline with
`[v3-refused-test-nearby]` in `failureNote`. The set of refused tests (`baselineRefused` in
`AlRunnerV3Backend`) is filled only by a LIVE baseline call. A session that reuses a baseline snapshot, or a
`--resume`, never runs that call, so its survivors carry no note.

**Effect.** The verdicts are right; only the note is missing, so a reader of such a report is not told that a
refused test sat next to the survivor.

**To close.** Record the refused tests with the baseline snapshot (or derive them from the snapshot's `error`
rows with the refusal cause), and refill `baselineRefused` on reuse. A unit test: a reused snapshot with a
refused test gives the survivor the note.
