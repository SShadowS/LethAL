**Filed 2026-10-23 by lethal-bugs during R-670** (orchestrator ruling: its own item, not folded into R-670).

**What was measured.** R-670 rebuilt the pinned fixture-symbols tar
(`/work/lethal/.kraken-local/fixture-symbols-26f680ae9671.tar`) and extracted it into a fresh worktree.
- `bun run compile:fixtures` then printed OK for the 21 projects the tar covers.
- It SKIPPED four, with "no .alpackages (symbols are gitignored; download them first)": `fixtures/sandbox-names`,
  `fixtures/sandbox-names-tests`, `fixtures/sandbox-wrapped` and `fixtures/sandbox-wrapped-tests`.
- Neither the old tar (`bdf460e2…`) nor the new one has ever had a folder for them.
- **`bun scripts/compile-fixtures.ts --require-symbol-sets` FAILS today on `sandbox-wrapped`**: "declares symbol sets
  but has no .alpackages, and --require-symbol-sets refuses a skip".

**Why it matters.**
- CLAUDE.md step 4 makes `compile:fixtures` the only offline compile of the fixtures (R56), and a fresh worktree's
  only symbol source is the tar. So a change to the names or wrapped AL fixtures cannot be compile-checked offline in
  a fresh worktree.
- The gates `itest:bcdev-names` and `itest:bcdev-wrapped` compile those projects through the server's symbol cache, so
  they still run. A broken fixture there is found only by a live gate, which is the R56 failure mode.

**To close.**
1. Add those four projects' `.alpackages` (Microsoft symbols, plus their LethAL dependency copies) to the tar, using
   `scripts/build-fixture-symbols-tar.sh` (R670).
2. Extend the committed manifest. R670's drift test then covers them.
3. Re-pin the sha. This follows R614's re-pin procedure, and the v3 gate needs `--regate`.

Alternatively, have `compile:fixtures` fall back to the shared server symbol cache
(`/coord/cache/bc-symbols/<server>/…`) where the tar has no folder, if that cache holds what those projects need.

`fixtures/sandbox-codefree` and `fixtures/sandbox-codefree-tests` (R-579) are also not in the fixture-symbols tar, so `compile:fixtures` skips them in a fresh worktree until the tar is rebuilt (`scripts/build-fixture-symbols-tar.sh`).

Evidence: R-670's `compile:fixtures` run; R670 (`docs/roadmap/R670.md`); R614; R56.
