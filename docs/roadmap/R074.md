**BLOCKS WIRING `routedTransport`: routed survivors discard the attestation, and the identity gate is vacuous without it.** `runOneBatchMethod` returns `attested` (`batch-transport.ts:180`); `callRouted` (`orchestrator.ts:336-342`) never reads it; the routed `record(...)` passes `guardObserved: undefined` (`orchestrator.ts:628-629`). `report.ts:565` documents `guardObserved === false` as "DECISIVE and damning for a survivor" while ABSENT means "not measured". Worse, `ControlState.Codeunit.al:190-192` sets `ObservedIdentityMismatch` ONLY inside the `ObservedAny := true` branch, so `batch-transport.ts:165`'s fail-closed `identityMismatch !== false` check passes trivially when no guard ever fired — nothing compared to nothing, this project's signature bug. Failing sequence: mutant M is object-attributed to routed test T; T passes on client-services without ever reaching M's site; `attested=false`, `identityMismatch=false` → M recorded **`survived`**, counted in `mutationScore`, and EXCLUDED from the `UNEXERCISED SURVIVORS` callout (`report.ts:1246`) because `guardObserved` is absent rather than false. A false survive. Filed, not fixed — do not implement without a design pass; blocks any production code constructing `routedTransport`.
