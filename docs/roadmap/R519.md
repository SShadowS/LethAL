**Priority.** Filed 2026-10-08 by the R517 build, from the R-517 measurements and the adversarial
review of its plan. Performance first; it also narrows two lost-kill shapes [[R517]] leaves open.
Not measured.

**What.** al-runner's server now reads per-request `test` and `excludeTests` (al-runner source at
43f7617, `docs/server-mode.md` §"Request fields"). LethAL still sends one whole-suite `runTests`
per activation, and the module header of `packages/runner/src/al-runner-server.ts` still says the
server has no per-test selection ("measured on 2.11.0"): that comment is stale. A per-test (or
per-covering-set) request would:
- make each test's `durationMs` its own rather than the whole suite's wall clock, so budgets stop
  being over-stated by the suite and the compile;
- cost a mutant only its covering tests;
- confine a hang to the one test that hung: today a timeout ends al-runner's run, so every test
  after it has no row and is scored `error` (R517's M3 note names the hung test), and each
  timeout restarts the daemon (R517 D4c) at a cold compile.

Also, on R517's C1 path (a `runTests` past its deadline), `close()` may signal only al-runner's
re-exec parent, so the running child finishes its run before it reads `shutdown`. It cannot feed
stale lines to the new daemon (a new process, new pipes), but it costs CPU while it runs.
Unmeasured.

**Evidence.** `/coord/handoff/R-517/measure.md` §"What the source says" (the request fields, the
refusal of an unknown field) and finding 5 (no row after a timeout). `ensureServerSuite` and
`runViaServer` in `packages/runner/src/al-runner-backend.ts` (one suite per activation, its wall
clock as every test's duration).

**Proposed close.** Measure first: does `test` select exactly (or by substring, as one-shot's
`--test` does, R488), does a selected run reuse the warm compile, and what does a covering-set
request cost against a whole-suite one on a real app. Then decide; fix the stale header either way.

**To close.** The measurement recorded, the header corrected, and if adopted, `itest:alrunner`
unchanged per mutant on every `--server` leg.
