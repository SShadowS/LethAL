**A resumed run's phase clocks did not add up, and the report hid it.** `mutantsMs` summed EVERY outcome's `durationMs`, including verdicts `--resume` CARRIED from a prior run — time this run never spent. Measured on a resumed Document Output sweep: **2200.4 s of "mutants" reported inside a 2109.7 s run**, with `overhead` clamped to `Math.max(0, ...)` so the contradiction showed as a plausible 0.0 s rather than as the negative number that would have exposed it. These timings exist to extrapolate what a bigger run will COST (R45/R44 both turn on them), so a carried duration is exactly the thing that must not be in them.
