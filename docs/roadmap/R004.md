**Two instrumented projects cannot share one BC container** — a direct consequence of R3: publishing a second one fails with *"The application object of type 'CodeUnit' with the ID '79197' is defined in multiple apps"*. Multi-project users hit this immediately. Closed by fixing R3. Live-verified on Cronus281: `fixtures/sandbox-app` instrumented+published with default ids (score unchanged: 3 killed/10 survived/3 no-coverage) and `fixtures/sandbox-data` instrumented+published with distinct custom ids (79309/79308/79307, score 3 killed/2 survived/2 no-coverage) — both apps simultaneously `IsInstalled: True` on the same container, no AL0297/id-collision error.
