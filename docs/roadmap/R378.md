**Found by the R-214 lane (lethal-preproc), 2026-10-01.** Plan: `docs/superpowers/plans/2026-09-29-R-214-symbol-aware-site-enumeration.md`. Pre-commitment: `docs/superpowers/specs/2026-09-29-r214-precommitment.md`.

**What happens.** Some analyses read a whole member, not a site: the write-transaction tag and the hang tag. They read the text and tree of the member including arms the build compiles out, so a compiled-out `Commit` or loop can tag a member the build never runs that way. R214 drops sites in such arms but did not touch these analyses.

**What would close it.** Make each analysis skip nodes in an inactive range (the ranges are already computed by `evaluateArms`), then add a repro per analysis.
