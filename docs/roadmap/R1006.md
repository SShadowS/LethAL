Coord task R-994, from the 2026-11-14 review of how we find bugs (`/coord/handoff/R-994/bug-finding-review.md`, proposal 1).
Related: [[R956]] (the license), [[R960]] (the serve fallback), [[R996]] (R-975's re-sweep, whose method this reuses).

**What happened.** About 12 h of corpus windows were void, each detectable in the first minutes: DO window 1 ran 4 h 40 min with
every test refused for no license; two R-984 serve windows fell back to one-shot; R-969 ran mutants on five projects with no green
baseline test. Avalara's fresh R-986 run spent 4 h before its serve warm-up fallback was visible in the report.

**Fix.** `scripts/triage-baseline.ts` runs `lethal run --only <files>` (the whole baseline, a few files' mutants, `--budget-s 300`)
through `scripts/heavy-slot.sh`, retrying only on exit 75, then reads the store's baseline rows and the report. It stops by name with
its own exit code: 10 no-baseline, 11 fallback (`al-runner-v3-serve-default-fallback*`), 12 no-license (al-runner's "with no license
file loaded"), 13 uniform-refusal, 14 zero-green, 15 fallback-unchecked; 0 is `TRIAGE GO`. Without `--only`, a dry run picks the
smallest codeunit files (skipping upgrade and install codeunits) up to 100 mutants or 8 files. The `measurement-campaign` skill now
says every al-runner-v3 corpus window starts with it.

**Found while building it.** The first version picked the single smallest file. On Avalara that was a page extension whose 2
mutants no test covered, so serve never ran and the triage said GO while the window's real fallback stayed hidden. Hence stop 15 (no
mutant reached a test: the fallback check proved nothing) and the codeunit pick. On Service Declaration the two smallest codeunits
were uncovered too (0 of 23, 0 of 30), hence several files.

**Measured** (2026-11-14, al-runner edge-a184cfc79, `/coord/handoff/R-994/smoke-*`): Service Declaration `TRIAGE GO` (56 of 61
green) in 5 min; Avalara `STOP fallback` (exit 11) in 7 min on one codeunit and again in about 9 min on the final four-codeunit
pick (one warm-up request each). Each rule is red-checked by reverting it alone
(`scripts/triage-baseline.test.ts`).

**Not done.** The review's proposals 2 to 5 (a refusal ledger, repros as a regression set, differential runs, generators); a
bcdev variant (the stops read al-runner-v3 caveats and texts).
