Found by PR-10 ([[R1027]]). Evidence: `/coord/handoff/PR-10/guided/triage/` (triage store, edge-5a58a0f16).

The #8038 flip lets 84 Guided Experience tests run. 14 of them now fail on an assertion, all in `Checklist Facade Test`
(codeunit 132604):
- `TestInsert{ApplicationFeature,AssistedSetup,DuplicateAssistedSetup,DuplicateLearn,DuplicateManualSetup,Learn,ManualSetup,Tour}ChecklistItemWithProfiles`
  and `TestUpdate{AssistedSetup,LearnSetup,ManualSetup}ChecklistItemWithProfiles`: "The checklist item (role) table should
  contain exactly one record", expected 1, actual 0.
- `TestUpdateProfilesFor{AssistedSetup,Learn,ManualSetup}ChecklistItem`: "should contain two records", expected 2, actual 0.

Every test that uses profiles fails. Its twin that uses users (`...WithUsers`, `TestUpdateUsersFor...`) passes. Microsoft
ships these tests green, so this is probably an al-runner difference from BC in how profiles are read. This has not been
measured on BC.

**To close:** reduce it to an invented repro, check BC's answer, then file it upstream (or show it is by design, citing
al-runner's own policy) and add a regression entry. Until then, these 14 tests kill nothing in Guided Experience, and
LethAL's figures for that module are low by whatever they would kill.
