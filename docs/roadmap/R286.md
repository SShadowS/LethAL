**Found by the issue #6 cross-check** (`docs/measurements/2026-09-27-gh06-grammar-crosscheck.md`, cluster C3).
A third container missing from the hand-kept list [[R217]] is about, after `asserterror_statement.body`
([[R216]]) and `preproc_conditional_statement` ([[R214]]).

**What happens.** `with Bin do Stamp(Number);` puts the call in the `body` field of a
`with_statement`. The AL compiler treats that call as a statement (an `InvocationExpression` whose
parent is an `ExpressionStatement`). `SINGLE_STATEMENT_SLOTS` in
`packages/engine/src/ast/tree-walks.ts` lists the `if` branches, a `case_branch` body and the
`while`, `for` and `foreach` bodies, and not `with_statement.body`. So `isStatementSlot` answers
false, and every operator gated on statement position (`void-method-call`, `remove-assignment`) skips
the site. tree-sitter-al shapes the construct correctly; the gap is LethAL's.

**Minimal reproduction** (hand-written, not corpus source), `scripts/lib/al-kind-mapping-with-body.al`:
```al
codeunit 50003 "With Body Probe"
{
    procedure Tag(var Bin: Record "Integer")
    begin
        with Bin do
            Stamp(Number);
        if Bin.Number > 0 then
            with Bin do
                Stamp(Number);
    end;

    local procedure Stamp(Value: Integer)
    begin
    end;
}
```
Harness output: call probe compiler-only at 122 and 208. The six audited kinds agree.

**Measured.** DC/Cloud (sha256 dcad155c4ecdb38e): 8 compiler-only call-probe sites, all in
`Modules/Approvals/Codeunits/CDCApprovalManagement.Codeunit.al`, at offsets 19114, 22211, 25726,
30082, 99105, 100071, 106819, 136893. That is app code, not test code, so these are sites a real run
loses. Zero in the other six corpora. The assignment probe found no `with` body in any corpus.

**What would close it.** Add `with_statement.body` to `SINGLE_STATEMENT_SLOTS` and measure what it
admits, the R161 way. Better, [[R217]]'s option 1 or 2, so the next missing container fails a check
instead of waiting for this audit.

**Reproduce.** `bun scripts/probe-grammar-crosscheck.ts scripts/lib/al-kind-mapping-with-body.al`
