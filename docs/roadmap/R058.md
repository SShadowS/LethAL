**Collect coverage on the FENCED path, and delete the dual-runner asymmetry entirely.** Today the hub exists solely because it is the only source of per-procedure coverage, and that is the whole reason the baseline runs somewhere the mutants never do (R55). AL's Code Coverage Mgt. can be started and stopped from the control app around the test invocation inside `RunMutant` and returned in the payload — one runner, one behaviour, no green-set/verdict split. Costs an AL change plus a protocol version bump (and therefore a control-app republish everywhere, cf. R28). Would subsume R55 and shrink R31/R35's whole disguise class. Raised by external review; feasibility NOT established — "measured infeasible" is an acceptable outcome, silence is not.
