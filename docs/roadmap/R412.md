**Found by the first Linux run of the unit suite (kraken-move Task 6, 2026-10-03).** Three tests
only work because the host is Windows:

- `writeCaptures (orchestrator ruling A: partial and full TestPage answer bytes) > a write failure is recorded, never thrown` (`scripts/r236-baseline-probe/probe.test.ts`) writes under `Q:/r236-no-such-drive/`. On Linux that is a RELATIVE path, so the write succeeds and leaves a `Q:` directory in the repository. Evidence: `error: expect(received).toBeDefined()` / `Received: undefined`, and `?? Q:/` in the clone's `git status`.
- `resolveRecordsDir — symlink/junction bypass refused (fix round 2, Defect 1) > an existing junction inside the repo that redirects outside is refused, not silently followed` (`packages/runner/tests/campaign-manifest.test.ts`) removes its link with `rmdirSync`, which fails on a Linux symlink, so the link stays in `docs/campaign/`; and its stale-link check uses `existsSync`, which follows the dangling link and says false. Evidence: `EEXIST: file already exists, symlink ... -> '/w/LethAL/docs/campaign/__test_junction__'`.
- `defaultAlToolPaths > sorts versions numerically across digit boundaries (9 vs 10)` and `> picks newest version with complex multi-segment comparison` (`packages/runner/tests/publisher.test.ts`) build a `bin/win32/alc.exe` layout but let the platform default to the host. Evidence: `error: Received value must be an array type, or both received and expected values must be strings.` (the result is `undefined`).

**To close.** Force the failure in a way every host has (a path under a regular file), remove a link
by the host's rule after checking it with `lstat`, and pass `"win32"` where the test builds a Windows
layout.
