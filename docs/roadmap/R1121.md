Found by coord PR-68 (lethal-code) and classified by PR-137 (lethal-preproc), 2026-11-18, on `bc4` (BC 29 W1 on Linux).
Evidence (private, DO source stays under `/coord`): `/coord/handoff/PR-68/changed-v1/report.json`, `/coord/handoff/PR-68/v3-vs-bc-gap.md`
and `/coord/handoff/PR-137/result.md`. Related: [[R908]] (the same limit, for tests that fail at BASELINE), [[R227]].

**What happens.**
- In PR-68's changed arm (80 mutants of Continia Document Output 30, `--changed-since`), BC killed 22 and al-runner v3 killed 1.
- **11 of BC's 22 kills** carry the killing failure "The report could not be created as a Pdf document ... RDLC report rendering is
  not implemented on Linux BC" (the Linux BC build stubs out the Windows reporting service).
- **Why:** the mutants (in the service posting send path) route a document to direct processing, which renders a report. The test
  fails on the platform's stub, not on an assertion. On v3, 10 of the 11 killers pass with the asserted outcome, so the mutant
  survives there.
- Of the other 11 BC kills, 1 is also killed on v3, and 10 look real (another failure text); their killers are refused at v3's
  baseline.

**Why it matters.** Every BC gate server (`bc1`-`bc4`) and `bc5` runs BC on Linux. On any suite whose code paths can reach a report
render, a mutant that turns rendering on reads as killed: the score goes up, and the user is told the suite caught it. R908 noted
the baseline side (19 of BankDeposits' 75 tests red); the mutant side is silent, since a baseline-green test that fails under the
mutant is an ordinary kill.

**Possible fix.**
1. Classify a kill whose failure text is the Linux RDLC stub as a platform failure: not a kill. Report it apart, as an
   environment-limited outcome with its own caveat, like a refusal.
2. Name the limit in the report and in `docs/gates/servers.md`: on Linux BC, a mutant that reaches a report render cannot be scored.

To close: (1) with a red test from a recorded failure text, and a re-score of PR-68's changed arm that moves exactly those 11 out
of killed.
