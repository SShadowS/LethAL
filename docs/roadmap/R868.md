**Filed 2026-11-08 by lethal-bugs (coord task R-869).** Related: [[R153]], [[R840]].

**What was missing.** `skills/lethal-mutation-testing/SKILL.md` existed, but only as "drop it into your agent". It had no restore step and no recovery when a step fails, and it still named the retired `al-runner` backend. `agent-contract.test.ts` checked its flags against the shared flag table, not which subcommand owns a flag, nor the subcommand names.

**What landed.**
- The skill in the order doctor, dry run, scoped run, read, restore, with what to do when each fails: doctor checks by name, `clear-quarantine`, `force-reset-lease`, `clear-ceiling`, exit `1`, `3` and `4`, and the restore procedure, quoting the line the run prints.
- Two ways to install it, in the README: one file into `~/.claude/skills/lethal-mutation-testing/`, or the Claude Code plugin (`.claude-plugin/plugin.json` and `marketplace.json` at the repository root; `/plugin marketplace add SShadowS/LethAL`, `/plugin install lethal@lethal`). `claude plugin validate` passes; the installed plugin loads the one skill and nothing else.
- `packages/runner/tests/r869-skill-install.test.ts` parses every command the skill shows with LethAL's own argument parser, checks every subcommand against `--help`'s USAGE and every doctor check against `doctor.ts`, applies the toolbox's frontmatter schema (bc-dev-mcp `skill-frontmatter.ts`: kebab-case `name`, non-empty `description`), pins the manifests to the skill folder and `package.json`'s version, and refuses a hooks, agents, commands or MCP file at the repository root, which would ship to every user of the plugin.

**Proof.** A walk in an empty home (`/coord/handoff/R-869/walk.md`): both install routes from a fresh clone, then every command of the skill in order on the gift-card example with `al-runner-v3`, each exit `0`. Red checks: 15 cases, each red on its test.

**Not done.** The bc-dev-mcp side of #26 (SEP-2640 `skills/list`, `skill://` resources) is for an MCP server; LethAL is a CLI, so the issue itself asks for a file. Restore on a BC server was not walked: no server in the walk.
