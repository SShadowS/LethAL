Found by coord PR-347 (lethal-preproc, 2026-11-23), in the BC check of the flip's effect on current master. Evidence:
`/coord/handoff/PR-347/bc68874/` (`rule.md`, written before the run; `compare.txt`; `compare.tsv`), arm A of PR-344's DO
re-check (`/coord/handoff/PR-344/recheck/`), c3's `unsupportedTests` (`/coord/handoff/PR-357/c3/report.json`).
Related: [[R1160]], [[R1156]], PR-297, PR-250, [[R1197]].

**What happens.**
- On current master (PR-365 in), the tail route fires only in DO codeunit 68874. Its cut is for the refusal
  `Report.SaveAs as Pdf of report "Standard Statement"`.
- Arm A (the flag on) reads 68874's 54 cut mutants as 7 killed and 47 survived.
- On BC (bcdev on bc4), the 7 kills are all confirmed, 4 by the same test and 3 by another. Of the 47 survivors, 32 are
  confirmed, 6 are `error` on BC (not judgeable), and **9 are killed on BC**, all 9 by
  `DueDateStatement_NegativeBalance_WithoutDoNotSendFlag_ShouldCreateStatement`.
- That test is in c3's `unsupportedTests`: al-runner refuses it at baseline (it creates a statement: SaveAs as Pdf). So v3
  can never run the killer, and has no coverage for it.
- With the flag off, the PR-250 cut scores these mutants `error`, an honest "not measured". With the flag on, the tail route
  runs only the stable green tests, sees them pass, and reads `survived`.

**Why it matters.** A false survivor understates the suite, which is the direction a user is least likely to question.
v3 cannot tell which survivors a refused test would have killed, so every tail survivor in a codeunit cut for a refusal is
at risk: here 9 of 47 (19%). PR-302's 755 recovered survivors (all four codeunits, on the older build) were never BC-checked,
so they carry the same risk.

**To decide (orchestrator, owner).**
- **(a)** In a codeunit cut for a refusal, tail SURVIVORS keep the PR-250 `error`; tail KILLS stay (they are confirmed real).
  On 68874 this keeps the 7 kills and returns the 47 survivors to `error`.
- **(b)** Keep `survived`, with an explicit per-mutant caveat: "survived; a test of this codeunit refused at baseline was not
  run".
- **(c)** Rule it a known limit of v3 (as for any test refused at baseline) and say so in the report.
- PR-347 (the default flip) waits on this.
