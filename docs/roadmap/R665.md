**Filed 2026-10-22 by lethal-bugs during R-658**, from its plan r2's delta review
(`/coord/handoff/R-658/review-plan-r2-delta.md`, "to file separately").

**What.** With `--stop-hung-sessions`, a mutant run that overruns gets `StopHungRun`.
- `TryStopHungRun` tombstones the op itself: `Op Kind none`, `Last Completed Op Seq := OpSeq`.
- If BC then sends no AL-stop 408 within the grace, the verdict is `in-flight-unknown` with `stopState confirmed`.
- `LeaseSession.reconcileLostAck` reads the tombstone as `completed`.
- `runFenced` returns `cause: "stop-outcome-unconfirmed"`, and the mutant covering path in `orchestrator.ts` (the
  `step.cause === "stop-outcome-unconfirmed"` branch) treats that as no verdict and writes no quarantine.
- The run goes on scheduling on that server, and the control-app lease reads clean, while the stopped session may
  still be alive.

R658 quarantines this same shape at the cold confirm (its plan r2, I1, with D4's condition). The mutant path keeps
the old behaviour.

**Why it is not R658's.** It is safe for verdicts: no kill or survive is minted. It is behind the opt-in flag, and it
needs a stop that BC acknowledges without ever answering the held request, which no measurement has shown. bc3 (R658's
probe) answered every stop with a 408 in about 75 ms.

**To close.** Decide whether this path should quarantine as the confirm now does (`quarantineInFlight` with the
tombstone sentence), with a red-checked test for each direction (`confirmed`/`unknown` quarantines; a `refused` stop
that was retried and reads completed does not).

**Built (R-665, offline, branch `lethal/r665`).** The plan is `/coord/handoff/R-665/plan-r1.md`, as amended by its
deep review `/coord/handoff/R-665/review-plan-r1-deep.md` (the review wins).
- **The change.** In `classifyNonVerdictStep`'s `stop-outcome-unconfirmed` branch, a lost answer after an unrefused
  stop now always calls `quarantineInFlight`, with cause `stranded` and a `STRANDED_NOTE_PREFIX` note, so `--resume`
  skips it and `--retry-stranded` re-runs it. One branch covers the single and grouped covering loops and
  `reproduceKill`.
  - `completed`: the note and the quarantine detail carry R658's `tombstoneSentence`.
  - `not-started`: no tombstone text. They name the real risk: the attempt was never claimed when the marker was
    read, the stop was sent and its answer was lost, the original may still arrive, and nothing was re-dispatched.
    This also covers the off-by-one op counter, which would otherwise surface on the next mutant as a lease loss
    nobody caused.
- **It also closes a false-kill door (class 1).** After a `completed` read the next mutant used to run beside a
  possibly live stopped session that shares the database, so that mutant's failing test could score it killed. The
  session now stops instead. Over-quarantine is the safe direction, at the cost of a recycle.
- **`stop-outcome-unconfirmed`** is now produced only by `runFencedMany`'s malformed / run-error renames: a group
  answer that arrived but could not be used after an unrefused stop. Its interpretation in `report.ts` says so.
- **Tests** (`orchestrator.test.ts`): "R-204b 6/7" (single and grouped × `confirmed`, `unknown`, `pending`, `issued`)
  and the two "R-204b retry" tests rewritten to assert `stranded`, a `test-run` quarantine record, the dispatch
  count, and that M0003 is never activated or scored; a `not-started` twin (single and grouped) and a
  `reproduceKill` case added. Red-checked: the old branch turns all 13 red; a `completed`-only condition turns the
  twins red; tombstone text on `not-started` turns them red. Logs: `/coord/handoff/R-665/red-unit/`.
- **R198 kept:** a lost answer on this branch that also carries `abortSession` (an identity disagreement or a missing
  route) still names it and aborts the session, as the generic strand does. Red-checked by its own test.
- **itest:hang:** R582's F3 rule ("a `stop-outcome-unconfirmed` seen live is a gate failure to re-run once") no longer
  applies to a lost answer. That now ends `stranded` with a quarantine record, which the gate treats as a STOP.
