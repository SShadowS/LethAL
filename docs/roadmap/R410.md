**Found by the first Linux run of the unit suite (kraken-move Task 6, 2026-10-03).** A
`SessionReport` records each mutant's `file` with the separator of the machine that ran it. Both
committed first-party reports were made on Windows, so they hold `src\GiftCard.Table.al`.
`firstPartyVerdict` in `scripts/redact-campaign-report.ts` joins that onto the project directory
with POSIX `path` on Linux, where a backslash is an ordinary file-name character, so the file is
not found and the report is called "not first-party". `--check` then FAILS on a clean committed
report on any Linux machine or CI job.

Failing tests (`scripts/redact-campaign-report.test.ts`):
- `redact-campaign-report > every first-party exemption is MECHANICALLY first-party, not just claimed`
- `redact-campaign-report > R350: --check PASSES both committed first-party reports, and write mode refuses them`
- `redact-campaign-report > R350: an allowlisted report whose mutant files fall OUTSIDE its project is not exempt`

Evidence line from the capture:

```
error: /w/LethAL/docs/campaign/2026-08-16-gift-card/rehearsal.report.json: allowlisted as first-party (examples/gift-card) but mutates file(s) outside it: src\GiftCard.Table.al, src\GiftCardMgt.Codeunit.al. Not first-party, so it is not exempt.
```

**To close.** Read a report's `file` with either separator before resolving it.
