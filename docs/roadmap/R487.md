**Found 2026-10-06 while building [[R484]]** (plan
`docs/superpowers/plans/2026-10-06-R-484-report-dataitem-loops.md`, sol reviews r1 to r5).

**What.** R484 treats an open `Integer` report data item as a loop. It refuses a value-operator write
when the item's Break, Quit or Error guards read the target, or when the item's own `SetRange` or
`SetFilter` bounds read it. These shapes are not seen. Each is a known exclusion, and none is shown
safe:

1. **An exit behind a call.** In `if Done then Fail()`, `Fail` raises an error, but the call is not
   read as an exit. R446 has the same blind spot.
2. **An indirect feed.** Report guards get no R480 closure. In `I += 1; Done := I > 3; if Done then
   CurrReport.Break()`, the `Done` write is refused, but the `I` write is not.
3. **Items over ordinary tables.** They end when their records end. A trigger that inserts into the
   temporary set it walks can keep that set growing.
4. **Other places.** `Date` items (4 on BaseApp); writes in procedures a trigger calls;
   reportextension `modify(...)` triggers, because the base report is not read; an XMLport
   `tableelement` over `Integer`.
5. **A bound set through another record.** In `Src.SetRange(Number, 1, N);
   Src.CopyFilter(Number, D.Number)`, the item is open, but writes to `N` are not refused.
6. **Condition-side mutants of a data-item Break guard** (`remove-not`, `negate-guard`,
   `conditional-boundary`). R196 has the same exclusion.
7. **An unqualified `Number := X;` in the item's own trigger.** It moves the `Integer` cursor. It
   is an assignment, not a call or a name, so the mention scan does not count it, and a bound
   certificate still holds.
8. **A reportextension `modify(D)` trigger that resets or widens the filter on D.** The mention scan
   reads only the report object that holds the item, so a filter change made from an extension is
   not seen.

**Measure first.** Count each shape on BaseApp, CDO, DC and DO with the R-484 identity-keyed dumps
(`/coord/handoff/R-484/survey.md` names the scripts). Read a sample by hand. Then refuse the shape,
or close it with a ruling.
