Coord PR-54 (2026-11-16). Spec: `docs/superpowers/specs/2026-11-16-pr54-keep-census.md`. Evidence: `/coord/handoff/PR-54/`
(census.md, classes.tsv, coverage.tsv, do-saving.tsv). Related: [[R1060]], [[R1070]] (PR-47 and PR-53, the single measurements).

**Tool.** `scripts/keep-census.ts` adds R-967's state, setter and reader objects to each generator family's app and to the
upstream repros, puts the standard writes before each refused call, and drives a serve daemon per refusal class. It requires:
- every refuser to refuse;
- every kept reader to equal the control;
- `engineKept` on each reader request.
The reader cannot see writes that test isolation resets, so CLEAN means nothing observable crossed requests.

**Measured:**
- 75 classes: 74 CLEAN, 0 NOT CLEAN, 1 NOT MEASURED (u8028's refusal also refuses the reader).
- Coverage: of the 272 open or unexamined ledger texts, 72 map to a measured class and 200 are corpus-only (no invented refuser
  yet).
- DO t1-t8, 389 mutant-phase refusal closes:
  - (a) today's keep-list plus the clean classes would have kept 279 (about 14.8k s summed over the windows);
  - (b) inverting the keep-list would have kept all 389 (about 22.9k s).
