Found in DO window t7 (lethal-bugs, 2026-11-16; `/coord/handoff/R-984/`), filed by coord PR-53 on the orchestrator's ruling (not
built). Related: [[R830]], [[R1050]].

**What.** A procedure clears the target rows (`Target.SetFilter...(...); Target.DeleteAll();`), filters a source record and copies
each source row into the target table, which is the same table. Removing the target's filter call (`lethal.void-method-call`)
makes `DeleteAll` and the copy run over the whole table. The `FindSet ... repeat ... Insert ... until Next() = 0` loop then meets
the rows it inserts and never runs out. It timed out in t7 (stop evidence `v3-cpu-stop`).

**Why not built.** Whether the loop ends depends on the data and on the source and target being the same table under a changed
filter. That is beyond the loop-exit analysis R196/R830/R1050 do. A rule that refused every filter call before a loop over the
same table would refuse many sites that cannot hang.

**Safety net today.** A v3 run stops it at the CPU limit (PR-43: no second run). A bcdev run needs `--stop-hung-sessions` and the
zero-timeout v3 check first (PR-34's rule).

**Measured and closed by ruling (coord PR-230, lethal-code, 2026-11-19).** Evidence: `/coord/handoff/R1069/` (`result.md`,
`census-r1069.ts`, `do.json`, `bc.json`; names and counts only).
- **The census, by parse** (LethAL's parser, `resolveVarRef`, `voidMethodCall.targets`; no grep). It counts copy loops
  (`X.Find… repeat … Y.Insert … until X.Next()`) with X and Y on the same table, a call before them that
  `lethal.void-method-call` targets, and a `Y.DeleteAll()`. That is the R1069 shape:
  - **DO: 8 sites**, out of 17 non-temporary same-table copy loops;
  - **BC.History: 60 sites** (44 strict), out of 376.
  - Unresolved receivers make the counts a lower bound for those sites. The sanity check passes: `CopyAttachmentsTo` is
    found.
- **What hung:**
  - y3 (43,511 DO mutants) had 7 `timeout-killed`, and y2 the same 7. **Only one has this shape: M13125**, the site this
    item was filed from. The other six are other shapes.
  - At DO's 8 sites, y3's void-method-call mutants otherwise ended 2 killed, 2 survived and 1 no-coverage.
- **The ruling:** a static rule would refuse 8 DO and about 60 corpus sites to stop one measured hang, and most of them end.
  The safety net above already catches the one that hangs. Revisit if a run's timeouts show this shape at a second site.
