**Filed 2026-10-25 by lethal-bugs during [[R745]].** Related: [[R745]], [[R45]].

**What.** `lethal verify` re-discovers the whole test suite. It never honoured `--tests-only` and does not honour
`--exclude-test` (which [[R745]] added to `lethal run` only). Both flags are refused on `verify` by name, so nothing is
ignored silently.

**Effect.** After a run that left tests out, `verify` runs those tests again. A test that `run` excluded counts as "new"
there, and only a genuine kill by it is reported. A user who excluded a test because it cannot run (a stale third-party
library, say) will see it run in `verify` and fail there.

**The gap.** `verify` has no way to carry the run's exclusion set, so a verification of a narrowed run is not a
verification of the same suite. A fix would read the run's recorded `excludedTests` and `testsOnly` (both are stored in
the report) and apply them, or take the same flags and say so in its report.

**Evidence.** [[R745]] plan, decision "verify". No measurement: found by reading `verify`'s test discovery.
