**Found by the R-254 probe** (`scripts/r254-probe/README.md`, section "(b) al-runner, measured"; plan in `/coord/handoff/R-254/plan.md`).

## What

With `al-runner v2.12.0-main.c39ad5de` (BC 28.5.54151.55132), a test that calls Base Application's
codeunit 9990 `Code Coverage Mgt.` makes a `reportextension` "not exist" for that test and for every
LATER test in the same al-runner process. `--isolation test` does not help.

This is al-runner's behaviour, not LethAL's. It is **NOT reported upstream.** Whether to report it
outside this repo is the owner's call (orchestrator ruling 2026-10-05).

## Repro

The probe pair is `scripts/r254-probe/target` (a report plus a report extension, ids 91600 to 91609)
and `scripts/r254-probe/tests` (`codeunit 91610 "R254 Probe Tests"`, ids 91610 to 91619). The test that
triggers it is `MeasureReportExtCoverage`: it calls `Code Coverage Mgt.` Start/StopApplicationCoverage
around one report run. The other three tests (`ReachOnly`, `CallExtProcedureDirectly`,
`ReadGlobalsAfterRunModal`) each pass alone.

```bash
al-runner --output-json --isolation test --test Codeunit91610.Rea --auto-provision \
  --coverage --coverage-out cov.xml <copy>/target <copy>/tests --package-cache <symbols dir>
```

Observed: `MeasureReportExtCoverage` fails with `NavALException: You tried to invoke the
ReportExtension object with the ID 91601 from the object R254 Probe Tests. An object with that ID
does not exist ...`. In a run of all four tests, every test after it fails the same way.

## Impact on LethAL

No LethAL fixture calls `Code Coverage Mgt.`, so no gate sees it. Once R-254 lands (report
extensions become mutation carriers), a user project whose tests call `Code Coverage Mgt.` could,
under al-runner, see reportextension-reaching tests fail from that point on, and so have mutants
misjudged (a test failing for this reason would score a kill that no assertion earned). bcdev is not
affected: this was seen only on al-runner.

## Close-out

Re-test on a newer al-runner build (the daily local build, or a new pinned sha). If it still
reproduces, report upstream only if the owner decides to.
