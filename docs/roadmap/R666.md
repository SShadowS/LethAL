**Closing note (2026-10-23, lethal-code).** Measurement: `/coord/handoff/R-666/measure.md`; plan
`/coord/handoff/R-666/plan.r1.md`.
- **The premise was wrong: a stale layout CAN happen on v3, and L1 catches it.** v3 labels a target file's coverage
  by the deployed flat path (`active/LayoutBeta.Codeunit.al`) in the EMITTED line numbers of that batch's text. In
  batch 1, TwiceOfThree hits lines 71, 73 and 79 of the 83-line instrumented file. The source-numbering guess was
  false. Read through batch 0's index, GrowAboveTen's lines 10 to 37 become `Twice` and TwiceOfThree's lines are
  dropped, exactly as `LayoutBeta`'s header comment predicts.
- **Which guard L1 proves: both coverage-index guards together.** `resetLayoutState()` sets `coverageIndex` to
  `undefined`, AND `deploy()` then assigns the new index unconditionally. L-R3 removes both and turns L1 red: 1/M0006
  and 1/M0007 survived, covered by `GrowAboveTen`, 5 / 5 / 0 (`/coord/handoff/R-666/live-LR3.log`).
- **Why R-654 S2's L-R1 and L-R2 stayed green:** each removed only one guard, and the other kept the index fresh.
  L-R1 deleted the reset, but `deploy()` still replaced the index. L-R2 changed the assignment to `??=`, but the reset
  had just cleared the field a few lines earlier in the same `deploy()`, so `??=` always assigned.
- **New offline tests,** each red-checked in both directions:
  - "R666: batch 1's coverage is read through batch 1's layout (one-shot)" (`tests/al-runner-v3-backend.test.ts`).
    It is red with both guards removed, and red with no index assigned. It stays green with either guard removed
    alone, by design.
  - "R666: serve-entries state does not cross a deploy" (`tests/al-runner-v3-entries.test.ts`), for `baselineRows`
    (S1a, S1b) and `union` (S2). S1a and S2 are red when the reset is deleted, or their own field's line. S1b guards
    only the other direction, rows cleared after the baseline (batch 1's own rows overwrite batch 0's, so a deleted
    reset leaves S1b green), and S2 is also red when the union is never filled.
- `docs/gates/alrunner-v3.md` restores L1's purpose. No figure, baseline, leg code or fixture changes.
