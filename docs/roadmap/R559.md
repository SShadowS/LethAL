**Filed 2026-10-09 by the R-551 build** (plan section 10, item 3).

**What.** [[R551]] uses `--test X --test-exact X` on a one-shot al-runner session whose build accepts
the flag (a per-session probe decides). Every other build keeps [[R488]]'s path: exclude each
discovered look-alike by whole name (`useDiscoveredTests`, `siblingsOf`), learn any other sibling from
a result, re-run, and refuse a result that still names another test. Today that fallback is needed:
the container's gate build `43f76177` and the host pin `c39ad5de` refuse `--test-exact` as an unknown
option (exit 2).

**When to do it.** Once every supported build carries the flag (the host's pinned source build and the
container's gate build). Then the exclude list, the learn-and-re-run loop and the probe's fallback
branch can go. What must stay: the refusal of any result naming another test (R551's exact-path
refusal), and R491's duplicate-row refusal. Decide then whether a build without the flag is refused
outright.

**Evidence to carry over:** R488's 14 red tests and R551's B-series in `r551-test-exact-probe.test.ts`
show what each path must refuse; whichever path remains keeps a red test per direction.
