**Found 2026-10-06 by R-492's plan review** (`/coord/handoff/R-492/review-r1.md`, Q1). Pre-existing;
R492 did not change it.

**What.** A run's test-app identity (`test_app_hash`) is the hash of the test app package alone.
Resume, `--skip-known-survivors` and R192 baseline-snapshot reuse match on it. When an env-tool hook
also publishes a DEPENDENCY of the test app (`publishApps`) and that dependency changes between two
runs while the test app does not, both runs are proven and match, so verdicts and a baseline carry
across a changed dependency. Only the digests' dependency fingerprint (R-371) records the change.

**To close.** Include the dependency fingerprint (or the hook-published apps' hashes) in the identity
the three consumers compare, or refuse when the recorded digests' dependency parts differ. Measure
first how often a hook republishes a dependency without the test app.
