**Filed 2026-10-01 from R387, plan section 2b.** R387 made `alRunner.coverage` reachable from the
config and guarded it, but kept it OFF by default, because turning it on moves verdicts. Without
coverage every mutant runs every green test, so an unreached mutant reads `survived`; with it, the
same mutant reads `no-coverage`. The advisory line R387 added names `coverage` on every al-runner run
until this lands.

**What it needs, in order:**
1. **R383 re-measured on al-runner 2.12.0.** Upstream closed #3713 (coverage lost after a file's first
   object) on 2026-09-10. Measured 2026-10-02: that object loss is gone on v2.12.0, but the live
   R383 check found a second defect (a later object's lines come back in a mixed
   source/instrumented frame), so R383 closed by ruling with the whole-run multi-object refusal
   RESTORED: a project with any file declaring more than one object, of any kind, runs with
   coverage `"none"` (`withAlRunnerCoverageGuard`, `cli.ts`). Re-admission is R407. The guard also
   turns coverage off for any file holding a `#if`-wrapped object (R298 pending R300). Measured
   prevalence of the multi-object half: one file on Continia Document Output (`CDOPermissions.al`),
   none on DC, System Application, Business Foundation or BaseApp (`R383.md`). The default is only
   worth flipping once it is known how many real projects these guards turn it off for.
2. **A pre-commitment, before the flip.** On `fixtures/sandbox-app`, `SandboxPricing`'s 4 mutants move
   from `survived` to `no-coverage`, nothing else moves, and the CLI goes from 3 / 16 / 0 to 3 / 12 / 4,
   matching the R220 pre-commitment
   (`docs/superpowers/specs/2026-09-09-r220-alrunner-coverage-precommitment.md`) and leg A of
   `itest:alrunner`.
3. **The CLI-default leg re-frozen.** R387's leg (`packages/runner/itest/cli-default-leg.ts`,
   pre-committed in `docs/superpowers/specs/2026-10-01-r387-cli-default-leg-precommitment.md`) pins
   3 / 16 / 0; the flip needs a new pre-commitment, the baseline deleted and recorded once under R332.
