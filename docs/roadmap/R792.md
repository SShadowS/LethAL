**The plan:** `docs/superpowers/specs/2026-10-25-a2-alc-overlap.md`. It folds in one spec-adversary review: three
BLOCKs and three FIXes, all addressed.

**In one paragraph.**
- On v3 only (a backend capability, first attempts, one worker, no resume, no TranslationFile), `deploy()` returns
  with the proof's byte fields bound and alc still running on copies of the batch and the test dir.
- The orchestrator scores the batch with a journaled store and emitter. When alc resolves:
  - **passed, and no answer tainted by alc's CPU:** the journal is replayed and the batch continues live;
  - **alc rejected:** the journal is discarded, the orchestrator and backend checkpoints are restored, and today's
    alc path (R461, bisection, R734) runs with the same error object;
  - **any other join error:** aborts as today;
  - **a tainted, refused or copy-changing window:** re-runs the batch sequentially on the same proved deploy.
- At most the alc time is saved: about 6 s on D1 at 6aa7700c (arithmetic, not measured).

**Taint rate, measured (coord task R-794, 2026-10-25, no product change).** Evidence in `/coord/handoff/R-794/`
(`contend.py`, `run.sh`, `analyse.py`, `runs/`).
- **Method.** Each subject (gift card, D1) ran 5 times plain and 5 times contended, alternating, in one heavy slot,
  21:16-21:22Z, at load 5-10. The build was `current` edge-a157b2d34 at master 6f63e707.
  - "Contended" means one hand-started alc compile of the same project, started when the run entered its baseline:
    what A2 would overlap. It compiled a scratch copy, so the CDO checkout stays clean.
  - Every progress line was stamped on arrival, so each answer could be placed inside or outside alc's window.
- **Result: 0 of 10 contended runs tainted.** In every contended run:
  - no verdict differed from the plain runs, inside or outside the window, and no killing test either (63 D1 mutants,
    60 gift-card mutants; none varied across the plain runs);
  - no new warning code appeared;
  - the baseline result was identical;
  - every run exited 0.
- **Window coverage.**
  - On D1 the hand alc took 7.5-9.9 s and overlapped the whole baseline plus the prefetch and live serve requests. The
    `mutant-scored` events arrive after the batched answers, so "no difference anywhere" is the measure used.
  - On the gift card (alc 0.7-1.0 s) every answer fell inside the window.
- **Contention cost** (report timings, medians):
  - D1: baseline 2.98 to 3.23 s, mutant loop 8.0 to 9.2 s, per-mutant median 3.8 to 4.5 s. All far below the 180 s
    budget floor, and no verdict moved.
  - Gift card: loop 0.4 to 0.5 s.

**Recommendation: BUILD A2 after the talk, as a second step after A1 lands.**
- The taint rate is no obstacle: 0/10, with no verdict move even under full overlap.
- The gain over A1 is real but modest on a single-batch slice: about 2-3 s of D1's 23 s.
- It grows with the number of batches, because every batch pays its alc again. A whole-project run of many batches
  saves its alc time per batch, where A1 saves only its baseline.
- Its cost is the largest change in the plan: the shared orchestrator move, journaling, checkpoints, and BC legs.
- So: land A1 first. Then measure one multi-batch run (several CDO batches) with A1, and build A2 only if alc there is
  still more than about 15% of the wall. Otherwise drop it.
