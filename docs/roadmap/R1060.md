Filed and closed by coord PR-47 (2026-11-16). Spec: `docs/superpowers/specs/2026-11-16-pr47-t6-gotokey-keep-and-resume-warnings.md`
(addendum 1). Evidence: `/coord/handoff/R-984/` (t5/t6 events), `/coord/handoff/PR-47/` (reduction and keep measurement).

**Cause (no merged change).**
- t6 reached a part of DO that t5 never ran: t5's budget ended inside it.
- Those mutants' covering tests share a codeunit with a test that is refused at baseline, identically in both windows, by
  `GoToKey on a list that opened on the last row of its descending view, with more rows above the rows it holds than a window
  (not pinned)`.
- That refusal was not on `V3_SERVE_SAFE_REFUSALS`. R1004/R998 leave such a test out of mutant entries only at the tail of its
  codeunit's order, and this one sits mid-order.
- So each mutant request lost its daemon: 64 of t6's 96 refusal closes, each a restart and a warm-up of about 37 s.
- Separately, PR-37 changed the emitted AL, so no stored baseline matched t6's batch. That reuse miss printed nothing.

**Fix.**
- The refusal was reduced to an invented shape (from the pinned build's source: a modal list descending in a secondary key, with
  OnAfterGetRecord and OnAfterGetCurrRecord, more than two windows of rows, a GoToKey in the handler). It was measured CLEAN with
  R-967's kit and joins the keep-list for exactly that text, with a leg C case.
- Upstream: #8172 (the shape, invented repro).
- `resume-baseline-not-reused` now also names two cases: the resumed run stored this batch's baseline under another instrumented
  tree (the emitted AL changed), and a stored baseline that lacks some of the session's tests. Other misses stay silent as before
  (spec addendum 2: `itest:lend`'s RL leg pins its warnings).

**Not changed.** Leaving a mid-order refused test out of mutant entries (it would change the state later tests start from).
R987's per-window entries cap is R1058.

**To confirm.** At the next DO window (t7): this family closes no daemon in a mutant request, and the per-mutant comparison with
t6 shows no difference (a BLOCK otherwise).
