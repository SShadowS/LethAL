Found by coord task R-982 (2026-11-14), Permission Sets' mutant run on edge-736fc7677 after its test library was rebuilt
([[R946]]). Each refusal costs a mutant its verdict (`error`, not scored, R586 §5).

**What.**
- **Metadata Permission and a whole-object-type grant.** Reading the Metadata Permission rows of a permission set that grants
  `table * = X` is refused ("grants a whole object type (not listed row by row)"). An unfiltered read meets the platform's own
  `BaseSystemPermissionSet`, so any read without a `Role ID` filter is refused. Met by 1 mutant (`remove-setrange` in Permission Set
  Copy Impl., `CopyPermissionSetByClone`).
- **XMLport: a table element row skipped after its child rows.** A temporary table element whose `OnBeforeInsertRecord` calls
  `currXMLport.Skip()` while child table elements were already read is refused ("the row of table element ... stored before its child
  rows is gone after them (not pinned)"). Met by 2 mutants (`negate-guard` on the `Get` guard in `Import Permission Sets`).

Both reduced to invented apps that alc builds (exit 0) and al-runner refuses; neither run on a BC server.

**Filed:** https://github.com/aldevtools/BusinessCentral.AL.Runner/issues/8032. Repros `/coord/handoff/R-982/repro-wildcard`,
`/coord/handoff/R-982/repro-xmlskip`.
