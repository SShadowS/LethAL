**Filed 2026-10-22 by lethal-orchestrator.**

**What.** `.github/workflows/ci.yml` runs only on `push` and `pull_request`. On 2026-10-22, GitHub Actions was
degraded from about 17:00Z. Pushes to `lethal/r649` and `lethal/r653` started no run, even after empty commits
and a new branch. The only route was to wait and push again. `release.yml` already has `workflow_dispatch`.

**To close.** Add `workflow_dispatch:` to `ci.yml`, with no inputs, so `gh workflow run ci.yml --ref <branch>`
starts the same two jobs on a branch head. Add one sentence to the runbook's CI rule: if no run appears 10
minutes after a push, dispatch one. Small: a CI-only change that cannot change a verdict.
