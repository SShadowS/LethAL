**Found by R-286.** [[R217]]'s pin lists every place tree-sitter-al 4.4.1 can put a statement and
makes each one be classified. These eight entries had no roadmap item and no support. None is in
`SINGLE_STATEMENT_SLOTS` or in a statement list, so a statement there is not a site: `void-method-call`
and `remove-assignment` skip it. The pin records each as `NOT_A_SLOT` (`unsupported`) pointing here.

| container.field | note |
| --- | --- |
| `preproc_guarded_statement.children` | Expression statements (for example `Foo();`) between a `#if` guard and the `if` header it guards. The allowed types hold no `*_statement` kind, so the pin names it explicitly. |
| `preproc_guarded_statement.then_branch` | The statement the guarded `if` governs. |
| `preproc_split_case_branch.body` | Body of a case arm split by `#if`. Sibling of the supported `preproc_split_case_extended.body` ([[R285]]). |
| `preproc_split_code_block_end.children` | Statements before a split `end`. |
| `preproc_split_code_block_over_endif.children` | Statements in a block that straddles `#endif`. |
| `preproc_split_else_begin_over_endif.children` | Statements after an `else begin` split over `#endif`. |
| `preproc_split_if_begin_else.children` | Statements in a split `begin ... end else` block. |
| `preproc_split_if_then_begin_else_shared.children` | Statements in the shared part of a split `if ... then begin ... else`. |

Not measured. No corpus count, no reproduction, and no check of which of these are real losses
versus shapes that never carry an executable statement: that is the first thing to do. `preproc_split_case_end_branch.body`
is a related container and is already named by [[R214]].

**What would close it.** Per container: read the shape in `grammar.js`, write a repro, count it on
the corpora, then either admit it (a slot entry, or a new placement rule like [[R304]]'s) or rule it out.
Moving a container out of `NOT_A_SLOT` in `tree-walks.ts` is what the pin then asks for.

**Ruling, 2026-10-06 (R-304b, one census with R304 and R293).** Closed as a stated limit. Counted
per project under its own `app.json` symbols (`/coord/handoff/R-304b/tools/census.ts`; [[R304]]'s
ruling has the table): 0 statements sit in any of these eight containers, active or compiled out, in
BC.History (519 projects, 1,168 files with directives), DC, DO, CDO and every fixture. Nothing is
lost today, so nothing is admitted; each container stays `NOT_A_SLOT` (`unsupported`) in the pin.
Reopen with a repro if a project carries one.
