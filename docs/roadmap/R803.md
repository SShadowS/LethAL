**Result (R-803, 2026-11-05): no defect guard is provably dead, so none is retired, and no verdict or figure moves.**
The inventory has 29 rows: `/coord/handoff/R-803/inventory.md`. Only text changed.

One check is unreachable from the CLI, and it stays on purpose: the backend constructor's `selectorMode === "resource"`
refusal. `validateAlRunnerV3Config` refuses that key first and `buildBackend` never passes it, so only direct
construction reaches it (a unit test, and gate leg S3). The inventory had it as LIVE; the build review corrected that.
It is a scope limit rather than a defect guard, it fails closed, it costs nothing, and retiring it means rewriting a
pre-committed gate leg for no gain.

Three things above turned out wrong:
- **"All nine defect facts read gone" is eight.** `codeunit-runs-whole` (#5611) reads `defect-present` on every build,
  alpha.7 included, so everything keyed on it stays.
- **"That costs speed or coverage, never a verdict" is false as a general claim.** It holds for the serve allow list,
  the probe cache and the pin text. Relaxing these others would move a verdict towards fail-open: the virtual-clock
  timeout guard (#5793), the timeout-after-refusal guard (#5776), the refusal marker anywhere (R675), `RUNNER_REFUSAL`,
  the `unlike-bc` refusal and the dependency-skip refusal (#5749). They stay.
- **The commit entry in `V3_SERVE_SAFE_REFUSALS` does not cost anything.** The list is an ALLOW list that keeps the
  daemon warm: removing an entry only closes the daemon more often. It fails closed and costs nothing on alpha.7,
  where the probed Commit shape produces no refusal (other shapes are not measured), so it stays.

Why nothing tied to an older build can go: the backend does not refuse older builds. `checkGated` accepts any binary
whose own `.gated` names its version and sha256, and `alRunnerV3.path` is a config key, so a user can point at
alpha.5 or an edge build. Only `current` cannot move backwards (R723). The per-build relaxations that were possible
were already done: the Sleep rule, #5798's dotted names, the #5788 probe-cache clause and leg T's rows.

Leg C's facts stay, so a build that brings a defect back is caught. `gone` is a reading of one probe, not proof that a
refusal is impossible, which is another reason to keep the fail-closed guards.
