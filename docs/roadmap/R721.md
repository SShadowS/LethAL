**Found by the opus review of coord task R-327b (2026-10-24), reproduced.** Same root as [[R720]]'s hang finding,
different shape.

**The shape.** An object-level `var` section declaring a global inside a `#if`:

```al
codeunit 50100 "Repro"
{
    var
        Total: Integer;
#if not CLEAN27
        Extra: Integer;
#else
        Extra: Decimal;
#endif

    procedure Q(): Integer
    begin
        Extra := 0;
        while Extra < 5 do
            Extra := Extra + 1;
        exit(Total);
    end;
}
```

The symbol table does not collect `Extra` into the globals: it is inside a `preproc_conditional_var`, which [[R468]]
and [[R364]]/[[R369]] already record as unread. So `resolveVarRef` returns null for `Extra` in the DIRECT procedure
`Q`. R196's hang check (`classifyHangCapable`) declined on that null, and `remove-assignment` was emitted on
`Extra := Extra + 1`. That mutant loops forever. R164's hazard: a hang-capable mutant deployed with no refusal and no
tag.

**Why it was missed.** R364/R369 ruled on the WRONG-TIER rows these declarations cause (they compile and are
misattributed). Nobody recorded the hang result.

**Fixed with [[R720]] (coord task R-327b, `a6a1a022` and `bc0f9a8f`).** R196's hang check now matches a loop write
by NAME when its target, or a member target's receiver, does not resolve and the engine's three-state lookup
(`declarationStateAt`) says "unknown" rather than provably absent. The match covers the enclosing loops' exit
conditions and any enclosing `for`'s control variable. The same rule covers R302's every-arm-ambiguous names.
- **Pinned by:**
  - `packages/builtin-tier1/tests/r720-unknown-hang.test.ts` (the conditional-global `while` and `for` cases, and a
    member target whose receiver is a `#if` global record), red-checked;
  - the sweep shapes `w5_var_cond_global_loop` (7 -> 6 specs: the `remove-assignment` on `Extra := Extra + 1` is
    gone) and `w7_for_control_unknown`.
- **Reach: 0 deployed mutants change in any corpus** (fixtures, DC, BC.History). See R720's reach, which covers both
  items.
- Proven offline only (R164): no hang-capable site enters a gate other than `itest:hang`.
