**Filed 2026-10-08 by the [[R500]] build** (plan r3 `/coord/reviews/R-500-plan/plan.r3.md`, shape 2). A plausible
hang that is NOT refused.

**What.** R500 refuses the subscribers of an event that open report-item code raises, and of an event a refused
one-hop callee raises (the PEPPOL Management `OnFindNext*` shape). An event raised from a subscriber, or from
anything two or more hops away, is not followed, so its subscribers are still mutated. A subscriber that sets a
`var` result the item's exit reads (the r1 hang) is the same risk there.

**To close.** Count the second-level events with production code; refuse their subscribers or close it with a
ruling. Pair it with [[R520]] (callees beyond one hop).
