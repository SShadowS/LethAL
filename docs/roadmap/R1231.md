**Filed 2026-11-26 by lethal-preproc, from coord PR-461 (ruling by lethal-orchestrator).**

**Why it is not built.** [[R826]]'s ladder (PR-460, bc2, BC 28.4 W1 Linux) measured that one call's time grows with the
guards it runs: a method of 12,507 guards was cut at the 300 s request ceiling. PR-461 refuses a file whose largest
method holds more than 4,800 guards, on bcdev, by name. Splitting such a file's mutants across batches would let the run
go on, but no known project needs it: no gate fixture, DO or DC file has such a method (largest DO file 1,580 guards; one DC
file has 5,626 guards with its largest method at 557). Evidence: `/coord/handoff/PR-461/moves/`.

**Trigger.** The first real project that hits the refusal.

**The checklist (the spec-adversary's review of the split, `/coord/handoff/PR-461/adversary-r1.md`).** A split puts one
file in several batches, which nothing today does:
1. The quarantine suspect (`largeMethodSuspect`) matches batches by path and quotes the unsplit size: key it per batch,
   from each piece's own figures.
2. `tallyGaps` throws `GapGroupingError` when one gap block spans batches, so `lethal explain` refuses every split run; and
   `verify`, which tallies one batch, could see half a block. Tally run-wide with a per-member batch index.
3. Read G from the plan, cross-checked against the deduped count (as PR-461 does), never from text.
4. Cut the DEDUPED specs, never the raw ones: a dedup pair cut apart strands the loser and fails R374's ordinal check
   mid-run, after earlier batches published.
5. Ids move: `<batchIndex>/<mutantCode>` is per batch (`assignMutantIds`); only the identity ordinal is run-wide. Compare
   a split run on the identity key, and say that codes move.
6. Guard `writeInstrumentedProject` against one path twice in one batch (it keys by path and would silently lose mutants).
7. Pin piece order (R197's `orderCoveringTests` reads it, so `killingTest` can move).
Also: cut at the smaller of 4,800 and `--max-guards-per-batch`; fix `assertUnderCeiling`'s text; keep the dry run's batch
count equal to the run's; emit a notice only when something splits.

**The proof it needs.** A test-only split on al-runner v3, which runs the AL, with per-mutant verdicts equal to the
unsplit run on a fixture where a chain straddles the cut. A fake backend checks bookkeeping only.

**Not measured either.** Guards spread over several methods that one test runs (see R826): a per-method split does not
bound guards per call.
