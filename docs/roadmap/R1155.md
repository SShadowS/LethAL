Found by coord PR-249 (lethal-bugs, 2026-11-20), from al-runner's PERF-17 finding: edge-4ebfe7913, the `current` of the y2 and y3 DO
runs, answered a `Record` parameter passed by value (no `var`) as if the copy kept the caller's filters. That is wrong on BC in the
measured shapes (BC hands the copy no filters; edge counted 2 rows where BC counts 3). Upstream main now refuses the shapes no probe
measured (`Record.SetFilter(): a record handed by value whose view the probe did not measure`) and runs the measured ones on an
assumption it flags (`by-value-table-proc-other-table`, a table procedure taking another table's record).

**Measured on the private DO corpus (the counts only; the labelled list stays outside the repo):**
- **Suspect tests, from upstream main 9835579c6's own baseline** (one-shot `--junit`) and PERF-10's store:
  - R: 4 tests main refuses with the by-value text (1 at baseline, 3 under mutants);
  - F: 13 tests main runs through `by-value-table-proc-other-table`.
- **y3 mutants covered by a suspect test: 2,204 of 43,511.**
  - 83 kills came from a suspect test.
  - 134 survivors have only suspect covering tests.
  - 1,375 survivors have some.
  - 584 kills came from another test, so they stand.
  - 28 are other verdicts.
- **A parse bound** (the repo's AL parser: procedures with a by-value Record parameter that read its view) finds 6 procedures,
  with 42 mutants inside them and 566 mutants reached by their tests. It does not model the table-procedure shape F runs through,
  so it is a lower bound on the code, not on the tests.
- **LethAL's own gate fixtures:** 127 AL files, 2 by-value Record parameters, none reading its view, so no gate leg exercises the
  shape.

**Why not fixed here:** the verdicts come from the build, not LethAL. Moving `current` to upstream main (PR-255) replaces the wrong
guess: unmeasured shapes refuse (scored as not-measured by PR-250's cut and the refusal rules), and measured ones run as BC does,
flagged until the corpus pins them (corpus PR 1430, 1451). Until then a DO verdict from edge-4ebfe7913 that a suspect test decided is
not trusted. Related: R1149 (the other known loss on that path).
