**Filed 2026-10-21 by coord task R-583** (lethal-code), from phase 1 of the bc-server addendum.

**What happened.** `itest:agreement` ran on bc2 under master 209360d8 and refused before scoring anything, with
`AssertionError: the config's selectorIds (what verify reads) must equal the full runs' SELECTOR_IDS (R261)`.
- The config holds the defaults, 79199/79198/79197. The gate wants 79547/79548/79549.
- `scripts/bc-linux-setup.ts` (R589) writes no `selectorIds` field into `sandbox-harden`'s
  `lethal.config.<server>.json`.
- Log: `/coord/handoff/R-583/gates/p1-agreement-bc2.log`.

This is an environment refusal, and it is the safe direction: no verdict was produced.

**To close.** The setup script writes the `selectorIds` that the agreement gate requires into the sandbox-harden
config, with a unit test red-checked in each direction. Then re-run the setup on the bc servers and run
`itest:agreement`.
