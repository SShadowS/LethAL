**Found by R-729** (2026-10-24), the second `scripts/r315-dc-compile.ts` run on DC master c895a7d `Cloud`, after
[[R729]]'s two syntax shapes were fixed and the 7 UserControls' missing script files were stubbed. alc reached
binding and reported **1 x AL0122** ("Cannot implicitly convert type 'Text' to 'Char'") in `CDCAIField.Table.al`
(emitted line 525, mutant M62941 of that run; original line 107). The un-instrumented control compiles with 0
errors, so the error is LethAL's.

**The shape.** An assignment to one element of a `Text` variable (`T[i] := <one-character literal>`). A
one-character text literal converts implicitly to `Char`, so the original compiles. The operator
`lethal.toggle-blank-string` replaces the literal with the empty text literal, which is a `Text` and does not
convert to `Char`. The mutant is not a valid AL program, so alc refuses the whole artifact.

**What a real run does.** The same as any batch that does not compile (see R729's "Real-run behaviour today"): the
batch is bisected, and if another culprit exists (here, [[R732]]) the bisection reports "not attributable to a single
mutant" and every mutant in the batch scores `error`.

**Fix direction.** Skip the site when the assignment target is an indexed element of a `Text` (the semantic layer
knows the target's declared type), or, if the type is not known, when the target is a subscript expression. Test:
a fixture with this shape, in the R402 sweep and as a unit test, red before the fix; then re-run
`scripts/r315-dc-compile.ts`.

## Done (b4bb3759)

**Cause.** `toggle-blank-string` had no type check, and a subscript `T[1]` has no type in the type table.
**Fix.** The blanking direction is refused when the literal is ONE character (`''''` is one), it is the right side of
an assignment, and the target's type is `Char` or unknown (fail closed, as `swap-additive` does). Operator version
1.1.0, `requiresSemantic` now `type-info`, `symbol-table`. A record member target is exempt. The `''` to `'x'`
direction is untouched.
**Offline alc probes (2026-10-24, invented AL).** `Ch := ''` and `T[1] := ''` are AL0122. `Ch = ''`, `T[1] = ''`,
`'' = Ch`, in an `if` and in a `case true of` label, compile, so comparisons are unchanged (pinned by a test). A table
field declared `Char` is AL0156, so a record member is never a Char.
**Cost, measured** (`corpus-snapshot diff`, fixtures: identical; DC: 100 `toggle-blank-string` tuples removed of
181,449 specs in `Cloud` and `Test`, 0.06 percent, 23 in `Cloud`, 1 in `Cloud/Modules/Purchase Contracts/Base`, 76 in `Test`). Kept as a plain
fail-closed refusal: the loss is small.
**Tests.** `packages/builtin-tier1/tests/r731-char-blank.test.ts`, red per direction (refusal removed: 8 red;
refuse every assignment: 4 red; no record exemption: 1; comparison refused: 1; no length check: 1). R402 sweep shape
`x1_char_element`: on master the artifact fails AL0122, now compiles in all four builds (11 specs to 8).
