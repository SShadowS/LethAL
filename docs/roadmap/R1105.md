Found by PR-109's Opus build review (lethal-code, 2026-11-17). R173 ruled `lethal.remove-not` on a `while not S.EOS` exit safe
because "EOS is false at the start". [[R1104]] covers the first way that fails: S was read before the loop. The second way:
- **The case.** S is opened over an EMPTY stream, for example a BLOB field with no value.
- **What happens.** EOS is then true at the start, so the mutated loop (`while S.EOS do ... S.ReadText(T)`) runs, and reading
  at the end never moves it.
- **In DO.** One site has a loop over such a stream with no pre-read, `GetErrorMessage` (in DO's queue-entry table). t13
  scored it `error`, so it was not measured as a hang.

**To close.** Measure, as PR-44 and PR-109 did, whether a static shape exists that tells "the stream may be empty" apart (for
example a guard `if not X.HasValue then exit` before the open) at PR-37's bar. Otherwise record that R173's ruling stands only for
streams that are known not to be empty.

**Measured (coord PR-110, lethal-code, 2026-11-17; `/coord/handoff/PR-110/measure.md`).**
- **The candidate.** A static rule cannot see whether a stream is empty at run time, so the only candidate refuses every
  remaining `remove-not` on a `while not S.EOS` exit (InStream S) that [[R1104]] does not.
- **The runs.** The before and after dry-runs on master 06bc6805 removed:
  - in the corpus (72 BC.History modules), 2 sites: `WriteToXMLDocument` in businesschart (survived), with the stream filled
    just before in the same procedure; and `GetFormulaText` in sustainability (error), with a `HasValue` guard before the
    loop;
  - in DO, 1 site: `GetErrorMessage` (t13 error). Its blob can be empty (`CalcFields` is conditional, with no `HasValue`), but
    it did not hang;
  - in the fixtures, 0 sites.
- **The rate.** 0 hangs in 3 scored sites lost, against the bar of 1 per 8. Not built.

So R173's ruling stands for these loops. An empty-stream hang, if one occurs, is caught at run time by the mutant stop (R954)
and bounded by PR-108's walk cap. Pre-commitment: `docs/superpowers/specs/2026-11-17-pr110-eos-empty-stream.md` (P1 held, P2
held in direction with 2 corpus sites, P3 held).
