**Found by the R-429 measurement (lethal-preproc), 2026-10-04.** Evidence: `/coord/handoff/R-429/measurement.md` (summarised in R429).

**What happens.** `buildTypeTable` (`packages/engine/src/semantic/types.ts`) gets every type through the symbol table. Since R-405a the symbol table reads a member-level `#if` by arm. At the positions below, the type table answers `null` in EVERY build, by design (R302, R330: refusing is the safe side, because a wrong type makes `swap-call-arguments` or `swap-additive` emit AL that alc rejects):
- `#if` inside a global `var` body (`preproc_conditional_var`), including procedures that a global var section swallows;
- `#if` inside a procedure's `var` section, or around a parameter (the `ambiguous` list);
- a split header whose arms disagree on a type;
- a field inside `preproc_conditional_fields` (`indexFields` reads direct `field_declaration`s only).

At each of them, `swap-call-arguments` and `swap-additive` refuse sites that alc compiles. Mutants are lost; no verdict is wrong. R429's measurement saw 6 such lost sites across the committed fixtures and unit fixtures (p13 `Wrapped`, which is R343's shape, and r364 `t1`/`t2`) and none typed wrongly in 71 project-by-symbol-set runs.

**Not this item:** an object wrapped whole in `#if` is R343.

**What would close it.** Type each position by arm with R-405a's rules: an active arm's declaration is typed; an inactive one is absent; an undecided file keeps `null`. Then measure the gained sites against alc's compiled text (R429's `oracle-diff.ts` method) and the identity-key diff on every fixture, because newly typed sites admit new mutants and can move same-tuple ordinals.

**Closed 2026-10-04 as a ruling: a stated limit, the loss is negligible** (R-432 measurement, `/coord/handoff/R-432/measurement.md`, branch at master fd1c532d).
- **Method.** R429's oracle method (blank the inactive arms to get the text alc compiles), applied to the two typed operators. A site counts as lost when the operator's typing condition passes on the compiled text but fails on the arm-aware type table: a same-type identifier pair for `swap-call-arguments`, numeric operands for `swap-additive`. Each lost site was classified by shape and read by hand. It is an upper bound: it tests the typing condition, not the whole operator.
- **Coverage.** 63 project-by-symbol-set runs:
  - every `fixtures/` and `examples/` project under its gate sets;
  - every r214 unit fixture under each symbol its directives name;
  - r364 `t1`/`t2`/`t3` under `[]` and `[RSYM]`;
  - the CDO copy at 5f2a71d (its five `app.json` projects, plus Cloud under its one symbol).

  The one undecided unit fixture is skipped by design.
- **Lost sites per shape:**
  - `#if` in a global var body: **1** (r364 `t2-swap-args` under `[RSYM]`, a unit fixture built to hit it);
  - `#if` around locals or parameters: **0**;
  - fields in `#if`: **0**;
  - disagreeing split header: **0**.

  The whole-object shape (R343, reported apart) loses 1 more (r214 p13 `Wrapped`).
- **As a fraction:** 1 of 55 typed mutants on the committed and unit fixtures (2 of 55 with R343's), and **0 of 871** on CDO (761 `swap-call-arguments` + 110 `swap-additive`, of about 56,000 deployed). No site was typed where the compiled text says it should be refused.
- **Why it stays as it is.** The positions keep answering `null` (refuse), which R302/R330 chose because a wrong type makes these operators emit AL that alc rejects. Typing them by arm would recover about one mutant per fixture set measured and none on a real project, at the cost of an identity-key diff and possibly a scheme bump.
- **Limit of the evidence.** CDO holds only one `#if` (inside a code block), so no project that uses `#if` heavily around declarations has been measured. If one is, re-run the measurement with the R-432 scripts (scratch `lost.ts`, adapted from R429's `oracle-diff.ts`) before reopening.
