**Found by the R-429 measurement (lethal-preproc), 2026-10-04.** Evidence: `/coord/handoff/R-429/measurement.md` (summarised in R429).

**What happens.** `buildTypeTable` (`packages/engine/src/semantic/types.ts`) gets every type through the symbol table. Since R-405a the symbol table reads a member-level `#if` by arm. At the positions below, the type table answers `null` in EVERY build, by design (R302, R330: refusing is the safe side, because a wrong type makes `swap-call-arguments` or `swap-additive` emit AL that alc rejects):
- `#if` inside a global `var` body (`preproc_conditional_var`), including procedures that a global var section swallows;
- `#if` inside a procedure's `var` section, or around a parameter (the `ambiguous` list);
- a split header whose arms disagree on a type;
- a field inside `preproc_conditional_fields` (`indexFields` reads direct `field_declaration`s only).

At each of them, `swap-call-arguments` and `swap-additive` refuse sites that alc compiles. Mutants are lost; no verdict is wrong. R429's measurement saw 6 such lost sites across the committed fixtures and unit fixtures (p13 `Wrapped`, which is R343's shape, and r364 `t1`/`t2`) and none typed wrongly in 71 project-by-symbol-set runs.

**Not this item:** an object wrapped whole in `#if` is R343.

**What would close it.** Type each position by arm with R-405a's rules: an active arm's declaration is typed; an inactive one is absent; an undecided file keeps `null`. Then measure the gained sites against alc's compiled text (R429's `oracle-diff.ts` method) and the identity-key diff on every fixture, because newly typed sites admit new mutants and can move same-tuple ordinals.
