Found by PR-91's spec-adversary (reading v3's source) and measured by lethal-preproc on edge-4ebfe7913 (2026-11-16), with an
invented app (`/coord/handoff/PR-91/probe/`, `probe.ts` and `carry.ts`). One serve daemon ran:

**Excluded tests still run.** A codeunit of 10 tests, each burning CPU:

| entry | rows | `testsMs` |
|---|---|---|
| all 10 tests | 10 | 124-140 ms |
| 8 tests in `excludeTests` | 2 | 104-143 ms |
| 8 in `excludeTests`, plus `runSelectedOnly: true` on the request | 2 | 24-32 ms |

In v3's `run.rs`, `run_only` is set only by `runSelectedOnly` or by a selection of exactly one method (#7207). Otherwise every
`[Test]` of the codeunit runs, and the entry's rows are filtered afterwards.

**A `runSelectedOnly` prefix gives the full run's first rows.** A codeunit whose OnRun sets state, and whose tests carry a
global forward:
- full run: `C01 pass, C02 102, C03 103, C04 104`;
- prefix of 2 tests: `C01 pass, C02 102`;
- prefix of 3 tests: `C01, C02 102, C03 103`.

A selection with a GAP really skips the missing test: C01 and C03 run, and C03 then sees 102. So only a prefix is sound.

**Consequences:**
- **R1030 (PR-20, L4):** the mutant entry's cut after its last covering test (`cutAfterLastCovering`) only hides the tail's
  rows; v3 still runs the tail. The rate R1030 reports for DO window t4 (17.0 s to 4.0 s per newly scored covered mutant)
  came from that window as a whole, which also carried L1 (R1041: 0 restarts from the kept refusal families, t3 had 33). It
  cannot come from L4 skipping tests. L4's verdict safety is unaffected: rows are only hidden.
- **The lever:** send `runSelectedOnly: true` with the cut entries, so the tail stops running. By the prefix result above,
  and PR-20's own rule that state only flows forward, that is sound for prefixes only. It is coord PR-94 (lethal-code).
  On t10, mutant entries reach 71% into their codeunit (23.4 of 33.0 tests).
- **PR-91's sentinel proof** is built on `runSelectedOnly` for the same reason
  (`docs/superpowers/specs/2026-11-16-pr91-sentinel-restart-proof.md`).
- **PR-92's lever-3 measurement** fits: narrowed entries saved nothing, because the narrowing only hid rows.
