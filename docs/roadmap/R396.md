**Filed 2026-10-01 at the owner's request, after R-387 landed (7ecf6945).** R-387 made `--server`
and the resource selector the al-runner defaults. The only end-to-end figure is on the 2-file
fixture: `lethal run` on `sandbox-app` took 233.3 s with the old defaults and 40.9 s with the new,
identical per mutant (R-387 submit note). On a real app the only figures are per mutant and older:
R222 measured 69.3 s per mutant (server, static selector) against 24.9 s (server, resource) on the
553-file Continia Document Output, and that "old" side already used `--server`, so it understates
the gain over the true old default (one-shot, static).

**What to measure.** On one real app (Continia Document Output, or another with a real suite), run
`lethal run --backend al-runner` twice on the same commit: once with the old defaults set
explicitly (`serverMode: false`, `selectorMode: "static"`), once with the new defaults. Record:
- wall time per run, and per mutant;
- compile count and time (the old path recompiles per mutant);
- `bun scripts/report-diff.ts old.json new.json`, which must print IDENTICAL; any difference is a
  finding, not noise.

Optionally a third run with `coverage: "al-runner"`, to size R394 (coverage on by default) on a real
suite rather than the fixture, where it cost nothing extra (40.6 s against 40.9 s).

**Constraints.** al-runner is one session at a time on this machine (R345). A report from a real
project carries its source, so redact it before committing (`scripts/redact-campaign-report.ts`).
Use the `measurement-campaign` skill and pre-commit the expectation (IDENTICAL verdicts).

**Closed 2026-10-04.** Measured in the kraken container on Continia Document Output at `5f2a71d`
(not the current product). Verdicts are IDENTICAL, 63 against 63, with the same covering tests and
the same `killingTest` for every mutant. Wall time fell 2.84x (9828 s to 3461 s), but the other
sessions on the machine added load noise, so treat the ratio as rough. Whether the `--server` path
sends the whole test directory is UNDETERMINED, because the new run's per-mutant times overlap.
Compile count and time were NOT measured: al-runner's stderr never reaches the run log. Evidence:
`docs/campaign/2026-10-02-r396/manifest.md` and the three redacted reports beside it.
