Found by coord task R-902 (EU 3-Party Trade Purchase on v3, 2026-11-10). Evidence: `/coord/handoff/R-902/eu3.report.json`,
`eu3.stderr.txt`. Related: [[R906]] (one cause of coverage off), [[R904]] (the same reporting shape for missing test data).

**What.** `v3CoverageMode` turns coverage off for the whole run when the project holds an `#if` wrapper shape the coverage index has
no rule for. It tells the user through one `console.warn` (`al-runner-v3-coverage-off`). That warning is not a report caveat, and the
console summary does not repeat it.

**Effect, measured.** EU 3-Party Trade Purchase's report has caveats `declarative-sites-dropped` and `kills-without-assertion` only,
and shows 149 survived, 0 no-coverage. A reader takes "survived" to mean a test reached the mutant and missed it. With coverage off,
it also includes mutants no test reached (57 in that app). R906 removes this one cause; any other unadmitted wrapper shape still
reaches this path.

**To do.** Add a `Caveat` for a run whose coverage was turned off, with the files named, and make the score's banner say so. A new
`Caveat` ripples (`CAVEAT_INTERPRETATIONS`, the counts in `interpretation.test.ts` and `report.test.ts`, the schema files), so it is
not done inside R-902.
