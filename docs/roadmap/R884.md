Found by coord task R-881 (BC.History on al-runner v3). Evidence: `/coord/handoff/R-881/` (`dry-bd.txt`, `bd.stdout.txt`).

**What.** On BankDeposits the dry run printed 2228 sites and 2080 deployed mutants, and nothing else about exclusions. The real run then
said "100 hang-refused site(s) in 4 file(s) not mutated". The dry run's counts already left those sites out, so its numbers were right,
but a reader had no way to know that 100 sites in two reports and two codeunits would never be measured. The dry run already names
the files it cannot instrument ("not instrumented: ...") and the declarative sites it drops; the hang-refused ones were the gap.

**Fix.** `printDryRun` prints a `hang-refused:` block after the "not instrumented" one: the total, the file count, and each file with
its kinds and site count, the same rows the report's `HANG-REFUSED SITES` line counts. Tests in `r447-hang-refused.test.ts`, one per
direction: a refused loop step prints the block with its file, and a project with none prints no block.
