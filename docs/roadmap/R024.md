**The env-tool bcdev-key collision check is opt-in.** `validateEnvToolConfig`'s `bcdevDeclaredKeys` parameter defaults to a no-op when omitted, so a future second caller that forgets it silently loses the "two sources for one value" guard. `resolveEnvToolSession` is the only caller today and does supply it. Make the parameter required. Evidence: `packages/runner/src/env-tool.ts`, commit `967554c`.
