**A STRANDED mutant records no `cause`, so every consumer keyed on `MutantOutcome.cause` is blind to exactly the case R91 measured.** `orchestrator.ts`'s in-flight-unknown branch (the `quarantineInFlight` at ~3687) writes a rich `failureNote` — `STRANDED_NOTE_PREFIX`, the budget, and the `--mutant-timeout-ms` / `--resume` advice — and then `break`s, never reaching the `cause = "deadline-exceeded"` assignment ~45 lines below in a different branch. So the outcome ships with `cause: undefined`. Measured on real campaign data: all three `error` verdicts in `rung1.run2-partial` carry `cause: undefined`. Consequence, found while building `lethal explain` (subsystem B, Task 4): the projection's R91 prescription — *"stranded error, not a verdict — re-run with `--mutant-timeout-ms` raised"* — is keyed on `cause`, which is the correct machine value to key on, and it can therefore NEVER FIRE for a strand. That is this project's signature shape: machinery that runs, reports success, and measures nothing. The prose the operator needs exists, but only inside a free-text `failureNote` that no consumer can key on without regexing prose — which the explain contract explicitly forbids. **Decided: a dedicated `"stranded"` member, not a reuse of `deadline-exceeded`.** The two mean different things — `deadline-exceeded` means a backend told us the run was over, so the container is clean; a strand means we do not know, which is exactly why it quarantines a tier and a deadline does not. Both want the same first move (raise `--mutant-timeout-ms`, `--resume`), and only one of them can also promise the tier is fine. It is two lines, not one: the covering run and the kill-confirmation rerun both write the strand note, and a cause on only one of them would have made the two disagree. It was deliberately NOT done under subsystem B, because it changes what a run RECORDS and belongs with its own red-check. Acceptance: an explain projection over a report containing a strand must emit the R91 prescription — the property it cannot have today. Filed 2026-08-06.
