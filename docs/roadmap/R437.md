**Found 2026-10-04, running `bun update` for the kraken no-pinning change.** `bun outdated` shows
`typescript` 5.9.3 current, 5.9.3 within range, 7.0.2 latest. 7.0 is the native (Go) compiler, so
`tsc --build`, project references and the `exactOptionalPropertyTypes`/strictness behaviour must be
re-verified rather than assumed. The kraken tooling repo already runs TypeScript 7.

Evidence: `bun outdated` output on branch `lethal/kraken-corpora` (commit "bun update: in-range
updates"). The update to 5.9 also surfaced TS2589 and TS7022 in two test files (fixed there), a
sign that checker changes reach this code base.

Gate: bump the range, then `bun run typecheck` (`tsc --build --force`) clean on every package,
`bun scripts/verify.ts`, and both CI jobs (`check` on Windows, `unit-linux`) green. Fix type errors
by annotation, not by loosening `tsconfig` strictness.
