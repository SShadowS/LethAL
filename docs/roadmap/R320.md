**Found by the RUST-03 S2 freeze review (2026-09-28)**, `H:/lethal-coord/reviews/RUST-03-S2/review-r1.md`
(Important finding), on merge `21c718a`.

**What breaks.** Only `softprops/action-gh-release` is pinned to a commit SHA (`3bb12739`, v2.6.2).
Every other action in `.github/workflows/release.yml` and `.github/workflows/ci.yml` is referenced by
a tag that its owner can move: `actions/checkout@v4`, `oven-sh/setup-bun@v2`, the Rust toolchain
setup, `actions/upload-artifact` and `actions/download-artifact`, `azure/login@v2` and
`azure/artifact-signing-action@v2`. A moved tag changes the code that handles release artifacts, and
in the `build` job the code that holds the signing OIDC token, with no edit to this repository. Most
of these tags predate RUST-03; S2 added the Rust and artifact actions.

**What would close it.** Pin every `uses:` in both workflows to a full commit SHA with the version in a
trailing comment, add a test (or a `native-notices`-style `--check` script) that fails on any `uses:`
not pinned to 40 hex characters, and prove it with a green CI run and a green `release.yml` dispatch
trial (publish skipped).
