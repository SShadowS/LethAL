The mutant is correctly reported as survived — the fixture genuinely does not catch it — but the fixture is supposed to be built so a broken operator fails, and this is the project's signature "test passes for the wrong reason" shape sitting inside the very fixture that exists to catch it. Asserting the error text would make M0034 killable and move the frozen baseline to 64/9/2. Evidence: R32 verification, 2026-07-27.
