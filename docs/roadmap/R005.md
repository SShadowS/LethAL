**The report does not say how much of the project was skipped.** Object kinds the selector var cannot be injected into (page, report, query, xmlport) are dropped at spec generation with a stderr warning only, so a page-heavy project can get a confident-looking score computed over a small fraction of its code. Wants an explicit "N files not instrumented" field on the report itself.
