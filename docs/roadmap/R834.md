## Recommended first batch: #35, #41, #33, #42
All four are cheap in the same way: no new typing, no new hang rule, no new emit path, and each covers a different bug class
(clauses, offsets, environment, argument order). Each clears R13's 36-site floor in CDO, DO and DC. Sampled equivalents: 0, 1, 0, 3.

Next batch: #36 (condition-to-true is the biggest gain, but 6-13% more mutants and a `continue`/`break` refusal) and #38
(Decimal-only). Refuse #32 and #40 by the bar, and record why next to R159.

**Shipping a batch moves every gate's figures.** Each new site in a gate project is a new mutant, so baselines, identity keys and
the pages under `docs/gates/` must be pre-committed and re-recorded (R332). The repo fixtures hold sites for #35 (4) and #41 (32),
none for #33 or #42 until each issue's live-fixture cases are added. The batch adds about 0.7-1.7% to the corpus totals.
