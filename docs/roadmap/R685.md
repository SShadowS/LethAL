**Filed 2026-10-23 by lethal-bugs during R-431**, by the orchestrator's ruling (R684, option a). This is a
precision item, not a safety one: the fallback is the safe direction.

**What.** `passesTestApp` (`packages/runner/src/testpage-scan.ts`) falls back on any test-app object reference handed
to a call the walk does not follow: `Page::"X"`, `Report::"X"`, `Database::"X"`, `Codeunit::"X"`. The rule exists
because external code could run the object's code. But a bare reference is an integer id. Code holding only an id can
run or open the object, and nothing else: it cannot call one of its procedures. What such a run executes is the
object's triggers, which `foldObject` (or, for a codeunit, the R-371 id fold) already puts in the digest. So folding
the object would be as safe as falling back, and far narrower.

**Why it matters now.** Since [[R684]] a test-app object that reached code names by id is folded, and its code is
walked. When that code hands its own reference out, the whole digest falls back. Measured
(`/coord/handoff/R-431/digest-diff-bch/`, all 176 BC.History test apps, 48,809 tests):
- every extra fallback is in System Application Test / Guided Experience, where 2 → 104 tests are on the fallback;
- a subscriber there names `Page::"Assisted Setup Wizard"`, and the page's `OnAction` hands that reference to the
  external `GuidedExperience.CompleteAssistedSetup`;
- because the subscriber fold is in every test's digest, every test of the app falls back.

**To close.** Narrowing loosens a safety rule, so measure first, then review:
1. List which argument shapes are a bare id: an object reference, or its literal. A variable typed as the object
   (`Page "X"`, `Report "X"`, a codeunit variable, a record) is NOT one, because it carries more than an id (a record
   carries data and its triggers; a codeunit variable can call procedures). Those keep the fallback.
2. For a bare id handed out, fold the object (`foldObject`, or the codeunit id fold) instead of falling back.
3. Prove it never drops a dependency, as [[R430]] requires: digest every test of the affected apps before and after,
   and for each test that leaves the fallback, show that an edit to the folded object moves its digest and an edit to
   unreached code does not. Red tests in both directions.
4. Re-measure the 176 BC.History apps, plus CDO, DC and DO: the fallback count before and after.

## Built (on top of R697/R698)

`passesTestApp` (`packages/runner/src/testpage-scan.ts`) no longer falls back for an `int` literal, nor for a `ref`
of kind codeunit, page, report, xmlport, query or database (`FOLDED_REF_KINDS`): `foldIdTargets` folds every reached
procedure's `idRefs`, qualified names included (R698). `argHolds` no longer falls back for a plain-name variable
whose every test-app-holding type is `Codeunit X` or `Interface I`: `builtinHolds` folds it (`foldEntryUnit`,
`foldInterface`, including the dependency `extends` chain through `unknownAncestry`). Kept on the fallback: `this`,
a record, a page/report/xmlport/query variable, an array or collection element, any `#if` mix with a non-plain type,
and `traceParam`'s own int/ref fallbacks (an unreached caller's `Codeunit::X` into a traced Variant parameter).
`Enum::"E"` yields no argument fact, so it never fell back. Tests: describe "R685" in `test-digest.test.ts`; red
checks in `/coord/handoff/R-685/redcheck.md`.

**Measured** (`/coord/handoff/R-685/measure/`, before = master e749fb9a with R700/R701, after = this branch; every
test's digest in 179 test apps, 53,936 tests): 17,115 digests change; on the fallback 45,847 before, 29,030 after
(16,817 tests leave it; no app's count rises). Guided Experience 104 → 0; CDO 7 → 1; DO 106 → 3; DC 1,854 unchanged;
BaseApp apps whose only closure reason was a handed-out reference leave it whole (for example Tests-Reverse 198 → 0).

**The dropped-dependency check** (`/coord/handoff/R-685/dropcheck2.ts`): for each test that leaves the fallback, the
test-app objects named in the reached text but not folded. It flags 5,347 tests in 15 apps; every flag was traced to
a benign pattern by edit experiments (`/coord/handoff/R-685/drop-triage.md`: a name shared with another object, a
library only called directly, an id in a string, an enum value number, ...). The one real drop it led to, Install and
Upgrade codeunits in no digest, was older than this item and was closed first as [[R700]].
