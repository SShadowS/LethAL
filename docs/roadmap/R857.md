Measured in [[R856]]: `/coord/handoff/R-856/day/result.md`. A test that calls `WorkDate(D)` leaves `D` set for the tests after it in the same codeunit on al-runner v3, which sends a whole codeunit. bcdev runs one test method per call, so the date is gone on BC. A verdict can differ for a test that reads a date after an earlier test set it.

Upstream #7207 records the single-method side of the difference.

The `sandbox-dates` fixture does not exercise this: each test that sets a date sits alone in its codeunit. The limit is named in the header of `packages/builtin-tier2/src/swap-workdate-today.ts`.

Close this when v3 and bcdev agree on a date set by an earlier test, or when a gate pins the difference.
