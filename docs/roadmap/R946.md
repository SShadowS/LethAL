**What.**
- **#7853** (https://github.com/aldevtools/BusinessCentral.AL.Runner/issues/7853): `Microsoft_System.app`'s manifest grants
  some apps its internals (`InternalsVisibleTo`); alc honours it, al-runner does not. Guided Experience subscribes to the internal
  event `"System Action Triggers".GetRoleCenterBannerPartID`, so al-runner refuses to compile it (AL0161) and none of its 104
  tests runs. Reduced to an invented app with the granted identity; alc builds it, al-runner does not. Grants between ordinary apps
  (source or package) work.
- **#7854** (https://github.com/aldevtools/BusinessCentral.AL.Runner/issues/7854): an XMLport import into a Guid field is refused
  (Permission Sets, 7 tests; reduced), and more refusals by test name: a permission denial on a system table, tenant permission
  rows, a column of platform table `Expanded Permission`, the OpenSSL-backed RSA decrypt, a .NET Integer stored into Char, and
  others; plus fails not reduced.

Neither invented app was run on a BC server.

**To close.** Both fixed upstream, and Guided Experience and Permission Sets re-run on v3: their baselines green enough to score.
