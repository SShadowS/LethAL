**Update 2026-10-23 (R654).** The warning lived in the .NET al-runner's branch of `runFromCli`, which R654 S3
(35f3c67f) deleted. `--backend al-runner-v3` now ignores an `envTool` section without a word again. Filed as
[[R674]]; this item stays closed, since its fix did land for the backend it named.
