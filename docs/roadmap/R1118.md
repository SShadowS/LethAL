Found by coord PR-67 (lethal-code, 2026-11-17), the DO pilot; friction log item 10; the measured sizes are in [[R826]]'s PR-67 data
point.

**What happened.** On one real codeunit the bcdev `--dry-run` printed the `large-method` note (one emitted method of 23,878 KB,
chain 462). The note suggests leaving out `empty-block` and 10 more operators (11 in all, plus 2 opt-in ones), one
`--exclude-operator` each, or narrowing with `--only`. Following it one step at a time:
- without `empty-block`: still 18,111 KB;
- nine `--lines` slices of 8 to 194 sites: still 3,426-8,737 KB each (a fold inside one procedure shrinks only guard by guard);
- all 11 listed operators left out together: no note (707 mutants).

A user has to find this by a dry run per attempt.

**Possible fix.**
- The dry run already builds the fold. Print, for each listed operator, the largest method with that operator left out, and the
  size with all of them left out; or name the procedure whose fold is the large one.
- Say plainly that `--lines` narrows mutants, but a fold inside one procedure only shrinks guard by guard, so leaving out the
  listed operators together is the lever.
- **Update the note's own claims.** It says "this size is not measured" and names a stack overflow. Since [[R826]]'s PR-67 data
  point, a 23.9 MB method IS measured on BC 29 (Linux): its publish is refused with `System.OutOfMemoryException` while emitting
  the codeunit, and the tier stays up. The note can say that, for that build and platform only.

Related: [[R826]], [[R827]].

**Done (coord PR-157, lethal-code, 2026-11-18).** In `large-fold.ts`, for a file already over the 512 KB figure:
- **The figures:** `largeMethodOf` emits it again with each listed root operator this file uses left out (`FOLD_ROOT_OPERATORS`, the
  warning's list), and once with all of them out. Each figure is the real emitted text's largest method.
- **The note:**
  - prints those figures per file;
  - says that `--lines` narrows mutants but a fold inside one procedure shrinks only guard by guard;
  - names the measured BC 29 for Linux refusal (R826's PR-67 data point), and keeps "not measured" for other builds.
- **Cost:** the extra compiles happen only for the few files already that large.
- **Test:** `r826-large-fold.test.ts`, "R1118: each listed operator's figure, and the all-out one, match a real emit without them".
  - Each figure equals an independent `generateMutationSet` with that operator left out, emitted and measured. The all-out figure is
    under 512 KB.
  - Red checks: the figures computed with the wrong operator set; the savings text blanked.
  - A small method still prints no note (the existing test).
- **Docs:** `docs/using-lethal-from-an-agent.md`.
