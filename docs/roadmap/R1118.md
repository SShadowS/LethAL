Found by coord PR-67 (lethal-code, 2026-11-17), the DO pilot; friction log item 10; the measured sizes are in [[R826]]'s PR-67 data
point.

**What happened.** On one real codeunit the bcdev `--dry-run` printed the `large-method` note (one emitted method of 23,878 KB,
chain 462). The note suggests leaving out `empty-block` and 11 more operators, one `--exclude-operator` each, or narrowing with
`--only`. Following it one step at a time:
- without `empty-block`: still 18,111 KB;
- nine `--lines` slices of 8 to 194 sites: still 3,426-8,737 KB each (a fold inside one procedure shrinks only guard by guard);
- all 11 listed operators left out together: no note (707 mutants).

A user has to find this by a dry run per attempt.

**Possible fix.**
- The dry run already builds the fold. Print, for each listed operator, the largest method with that operator left out, and the
  size with all of them left out; or name the procedure whose fold is the large one.
- Say plainly that `--lines` narrows mutants, but a fold inside one procedure only shrinks guard by guard, so leaving out the
  listed operators together is the lever.
