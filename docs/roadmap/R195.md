**Measured.** The config template named `CRONUS Danmark A/S`; the hosted sandbox has
`CRONUS UK Ltd.` and `My Company`. `doctor` reported `control-version` and `lease` both FAILED with
BC's *"The company "CRONUS Danmark A/S" does not exist"*, which is right but was the third failure
the operator read that morning, after `envId` and the control app, each found one run at a time.

**Fix.** A `company` check that lists `/api/v2.0/companies` (the operator did exactly this by hand)
and fails with the configured name and the names that exist, placed before the checks that need a
company. It joins the pinned check list in `doctor`'s tests and the agent contract.
