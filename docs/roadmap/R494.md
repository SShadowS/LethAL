**Found 2026-10-06 by R-485's plan review** (`/coord/handoff/R-485/review-r1.md`, pre-existing, not
caused by R485).

**What.** An object whose HEADER is split by `#if` (`preproc_split_declaration`, one header per arm,
one shared body) is not in `SymbolTable.objects` (`OBJECT_KIND_BY_NODE` has no entry for it), not in
`tableExtensions` (`parseExtensionHeader` matches only `tableextension_declaration`), and not in
`unindexedObjects` (which collects only the declarations inside a `preproc_conditional_object`). R-485
measured the `#if`-wrapped case: a split-header tableextension of the table inside a wrapper drops
`run-trigger-forced` on master too. So `projectObserves` cannot see a split-header tableextension or
codeunit at all, and a tag such an observer should keep is dropped: the UNSAFE direction.

**How common.** 3 split-header codeunit or tableextension headers in BC.History (none in BaseApp),
0 in DC, DO and CDO (R-485 review count).

**To close.** Read a split declaration in `projectObserves` (every arm's `base_object`, every arm's
subscribers), or fall back to the any-table text rule for it. A red-going test: a split-header
tableextension of the table (top-level, and inside a wrapper) keeps `run-trigger-forced`.
