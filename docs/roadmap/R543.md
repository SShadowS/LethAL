**Priority.** Filed 2026-10-09 by the R534 build (plan r2, roadmap item 7; review F3). Never a
false kill: a whole session lost to one mutant.

**What.** When al-runner cannot instantiate a test codeunit, or a codeunit-level subscriber fails,
it writes an `error` row under its OWN name (`<ctor>`, `<OnBeforeCodeunitRun>`), not the requested
test's (read from its source at 43f7617). LethAL then finds no row for the requested test:
one-shot returns `pre-dispatch-rejected` ("al-runner output has no test named ..."), `runOnce`
re-sends it, and the second miss aborts the session under spec §11. [[R534]] kept this path a §11
abort on purpose (a missing row with no hang); it is an ANSWER, though, so it should be a
per-mutant `runner-test-error` like the others.

**Evidence.** `/coord/handoff/R-534/review-plan-opus.md` F3; `/coord/handoff/R-534/measure.md`
"What the source says"; the missing-row branch of `AlRunnerBackend.run` in
`packages/runner/src/al-runner-backend.ts`.

**To close.** Measure both rows (names, status, message) on the current build. Recognise a row named
`<ctor>` or `<OnBefore...>` as the requested test's answer and score it `runner-test-error`; keep
every other missing row a §11 abort. Tests per direction, red-checked.

**v2 retired (R654); re-measure on v3.** `AlRunnerBackend.run` and the `<ctor>` / `<OnBeforeCodeunitRun>` rows
belong to the .NET al-runner, deleted in R654 S3 (35f3c67f). Whether the Rust al-runner writes rows under such names,
and what LethAL's v3 decoder does with them, is not measured.

**Closed 2026-10-23 by ruling (coord task R-537, lethal-code): the shape does not exist on v3.** By the upstream
source (93415c0, `al-testrun/src/runtime/run.rs`), every codeunit-level outcome (a refused or failing `OnRun`, a
refused isolation mode, a company-open refusal) is written to every test of the codeunit under that test's OWN name;
no path writes a row named `<ctor>`, `<OnBefore...>` or anything but a test. Measured offline on alpha.2 (91253f2d6)
and edge (57f1e4f98): a test codeunit whose `OnRun` raises gives one `notRun` row per test, named
`Codeunit50981.AfterThrowingOnRun` and so on, which LethAL scores `error (runner-refused)` like any refusal. 0 of
8,275 v3 kills carry `<ctor>` or `<OnBefore`. Evidence: `/coord/handoff/R-537/measure.md`. The same codeunit on
bcdev does stop a session, through a different path: [[R684]].
