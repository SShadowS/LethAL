Found by lethal-code, 2026-11-11 (coord R-914, Withholding Tax on al-runner v3). Related: [[R761]], [[R763]], [[R782]], [[R916]].

**What happened.** Withholding Tax's test app has 71 tests; 2 sit in codeunit `ERM WHT G/L Account`. Its name holds `/`, which
`V3_SERVE_PROVEN_NAME_SHAPES.codeunit` does not allow (R763 proved `/` for METHOD names only), so the serve-entries default fell back
to one-shot for all 71 tests. The warning read `unproven-test-name-shape: ERM WHT G/L Account.CheckWHTPostingSetup, ERM WHT G/L
Account.ShowDetailsWhereUsedWHTPostingSetup (name shapes not yet measured under serve-entries; "." in a method name is upstream
#5798)`: both method names are plain, there is no "." in either, and nothing says the codeunit name is the unproven part.

**Invented repro.** A test codeunit named `Tax A/B Tests` with one plain test method: the default v3 run warns
`al-runner-v3-serve-default-fallback` and runs one-shot.

**Wanted.** (1) The warning names which part is unproven (codeunit or method) and the character. (2) Prove the codeunit-name shapes
that R763 proved for methods (`/`, `-`, `&`, `(`, `)` and the others), with a fixture leg like N1S, and widen the codeunit pattern.
(3) Ask, with R916: should one odd name cost every test the serve speed-up, or only that codeunit's calls?
(4) The report never says the session ran one-shot: `al-runner-v3-serve-default-fallback` (this pre-flight fallback) is a warning
only, while the warm-up one (`-warmup`) is a caveat. Withholding Tax's report carries no trace of it; only stderr does.

**Progress (coord R-919, 2026-11-11): (1) and (2) are done; (3) and (4) stay open.**
- (1) The warning now names the part and the character, for example `codeunit "Tax Ø Tests" ("Ø")` or `method "Colon:Step"
  (":")` (`unprovenNamePart`).
- (2) Measured with an invented test app (`/coord/handoff/R-919/names/`, not a fixture) over a copy of `sandbox-names`' target.
  Seven test codeunits: `Names A/B Tests`, `Names A-B Tests`, `Names (A) Tests`, `Names A&B Tests`, `Names Blåbær Tests`,
  `7Digit Names Tests` and a plain one. Serve-entries and one-shot gave the same verdict and killing test for all 48 mutants. The
  codeunit pattern now admits these characters (`/`, `-`, `&`, `(`, `)`, `å`, `æ`, a leading digit) in any order after a letter or
  digit, so it also admits mixes not measured one by one (a trailing `-`, `//`). A name that starts with `-`, `(`, `/` or `&`, or
  holds a character not measured (`Ø`, `:`, `'`), still falls back to one-shot. The serve transport does not send the codeunit
  name (it appears only in messages and in this check), so the looser admission is low risk.
