**Why this family.** After families 1-9 and R1046, the largest open issue under R1036's count (PR-32's `causes.txt`) without a
generator is #8038, one key: "a permission denial (read permission on object type 0 id 2000000157) whose error is not pinned yet
(a FlowField over a system table)", 133 standing sightings. Guided Experience has 87 of them, and upstream fixed its shape since. The
other 46 are in Extension Management and R-982's module 31. #7833 (122, Edit in Excel's Dictionary`2 members) and #7836 (120, one
report property) come next.

**What was built.** `scripts/refusal-family.ts` family `pubapp-flowfield` (BC-check number 11, target OnPrem, depends on
Microsoft's Permissions Mock), 30 cells:
- 14 reads that touch Published Application's FlowFields over system tables (Tenant Visible and PerTenant Or Installed look up NAV
  App Extra, Installed checks Installed Application): filters, CalcFields, IsEmpty and Count on Published Application, and an app
  table's own FlowFields over it (lookup, exist, count, a lookup of Tenant Visible);
- each under a set that grants Published Application R and one that grants only the app's table, plus a FindFirst by ID as
  the control.
A test pins the sets, the order (an app-table cell applies its set before its own Insert), and that each read touches a FlowField.
It goes red when the item-only set also grants Published Application, or when an Item cell's set comes after its Insert.

**The first BC run found a defect in the app.** The ten app-table cells inserted their row before `PermissionsMock.Set`. On BC a
codeunit without TestPermissions runs Restrictive, so the Insert was refused and those cells said nothing. The fix applies the set
first; the re-run answered them. The difference behind it is R1048 (#8160).

**Measured.**
- **edge-5a58a0f16:** 5 pass, 25 refused.
- **BC** (lethal-bugs, bc2, BC 28.4 W1 on Linux, Permissions Mock installed, through LethAL's web-service path, since the dev
  endpoint's runner ignores the mock; `ws-run/result.md`), with Published Application R:
  - The NAV App Extra FlowFields need no grant of their own, in a filter, in CalcFields or in an app table's FlowField. 8 cells

  - Installed: a filter on it passes, but `CalcFields(Installed)` fails with `Sorry, the current permissions prevented the action.

  read, the control included, and `... IndirectRead ...` for an app table's FlowField. BC never names NAV App Extra. al-runner
  refuses all 15.
