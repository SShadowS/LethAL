**Filed 2026-10-24 by R-702 (lethal-preproc)**, evidence `/coord/handoff/R-702/measure-gap2.md` and
`results-run3.tsv` (bc2 probe `scripts/r702-probe/`, run 3, leg T3o). An over-refusal: the safe direction, but a
measured cost.

**What.** [[R696]] counts the walked variable's OWN `Insert` as a mover (`self` in `r696Movers`). On bc2, a walk whose
own variable inserts a higher-key row visited 1 row and ended, at N = 3, 60 and 1000, on permanent and temporary
tables alike: the own Insert moves R's own cursor to the new row, as the own Modify does.

**To close.** Narrowing it LOOSENS a refusal, so before any change: measure the specs it would return by parse (as
R-696's cost scripts did), review a sample for a remaining hang path (an own Insert followed by a cursor reset, a
`Find` inside the loop), and get a ruling. R's own `Rename` and `ModifyAll` were not probed; they stay refused on a
walk not declared temporary (on a declared-temporary walk [[R702]]'s rule refuses only through a sharer).

**Closed 2026-10-24 by ruling (orchestrator), measured by R-717 (lethal-preproc)**, evidence
`/coord/handoff/R-717/measure.md` and `r718-read.md`.

- **The gain:** dropping R's own Insert from R696's movers gives back 85 BaseApp specs (0.01%) and 19 DC specs (0.01%),
  and none in DO or CDO, from 11 own-Insert sites in 7 files.
- **Why it is kept:** the probe measured only an Insert AHEAD of the cursor in the walk's direction. Of the 11 sites,
  5 insert BEHIND it: 2 upward walks insert a lower key, and 3 downward (`Next(-1)`) walks insert a higher one. 5
  re-insert the same key, and 1 walks a different variable. Read by hand, none looks like it could run forever, but
  the loosening would rest on that unprobed insert-behind case, and 0.01% does not pay for a probe.
- **To reopen:** a bc2 probe leg (an own Insert behind the cursor, in upward and downward walks) under a
  pre-commitment.
