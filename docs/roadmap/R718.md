**What.** [[R696]] counts the walked variable's OWN `Insert` as a mover (`self` in `r696Movers`). On bc2, a walk whose
own variable inserts a higher-key row visited 1 row and ended, at N = 3, 60 and 1000, on permanent and temporary
tables alike: the own Insert moves R's own cursor to the new row, as the own Modify does.

**To close.** Narrowing it LOOSENS a refusal, so before any change: measure the specs it would return by parse (as
R-696's cost scripts did), review a sample for a remaining hang path (an own Insert followed by a cursor reset, a
`Find` inside the loop), and get a ruling. R's own `Rename` and `ModifyAll` were not probed; they stay refused on a
walk not declared temporary (on a declared-temporary walk [[R702]]'s rule refuses only through a sharer).
