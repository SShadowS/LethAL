**Filed 2026-10-08 by the [[R500]] build** (plan r3 `/coord/reviews/R-500-plan/plan.r3.md`, shape 2). A plausible
hang that is NOT refused.

**What.** R500's one-hop rule matches a typed receiver against the project's object declarations
(`projectObjects` in `loop-hazard.ts`, from `objectDeclarationsOf`). A codeunit or table whose header is split by
`#if` (`ctx.symbols.splitObjects`) or that sits in an `ERROR` node (`unparsedObjects`) is not among them, so a call
into it from open report-item code is not followed and its procedures are still mutated. Shape 7 already counts
such a reportextension as extending every report; callee objects get no such treatment.

**To close.** Count the split and unparsed objects that open-item code calls into on every corpus; refuse their
named procedures or close it with a ruling.
