Found by the opus plan review of R-861's `var` fix, by reading the code. Related: [[R855]], [[R316]], [[R313]].

**What.** A trigger whose header and var section are both split by `#if` used to give ERROR nodes, and R313 refused it. For example:

```al
#if C
    trigger OnRun()
    var K: Integer;
#else
    trigger OnRun()
    var M: Integer;
#endif
    begin
        ...
    end;
```

Since 4.6.0 (#32) it parses as `preproc_split_trigger_preamble`. `isProcedureLike` and the trigger check in `injectReachLatches` (`compile-plan.ts`) did not know the new node. So a statement-grain marker in its body walked to no owner, and the whole file was refused (`compile.latch-owner`).

**Measured (2026-11-08, R-877).** Member walks DO reach the form. A unit case (a trigger body with assignments, `if`, calls, a loop, nested blocks, plus one plain procedure) run through `generateMutationSet` and `compileSchemataForFile`: codeunit `OnRun` (with and without `#else`), table `OnInsert`, page `OnAfterGetRecord` and a table field `OnValidate` each gave 10 default-operator sites in the split trigger and 3 in the plain procedure. Before the fix every shape refused the whole file with `compile.latch-owner`. Of the opt-in operators, `condition-true` gave 0 in the trigger and 1 elsewhere, and `blank-argument` matched no site in the fixture. Corpus: 0 files and 0 nodes in `/work/src/DC` (98 of 1,656 `.al` files hold `#if`) and `/work/src/DO` (4 of 814), counted by parse. So the cost was never seen on a real project, and it was never a wrong verdict.

**Fix.** The smaller one: `reachLatchRefusedOwner` (`dispatch-plan.ts`) learns the node and refuses that MEMBER by name, before any header or var section is read. Its mutants stay instrumented and scored; they get no reach marker (`unplaced`, reach `not-decided`, never unreached), and the `reach-latch-refused` warning names the trigger (cause `trigger-preamble`). The rest of the file is instrumented as usual. The per-arm latch (the R316 way) was not built: 0 corpus sites, so the refusal costs nothing measured. Test: `packages/runner/tests/r877-split-trigger-preamble.test.ts`, red both ways (member refused, rest of file instrumented). R316's stale "does not parse" text is corrected (`compile-plan.ts` refusal message, `R316.md`).

**Still open, if a real project hits it.** One latch per arm, every arm's `var` blanked, each arm proved with an offline `alc` compile. File a new item with the file name then.
