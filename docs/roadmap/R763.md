**Filed 2026-10-25 by lethal-preproc, from coord task R-761.** Related: [[R761]], [[R722]], upstream #5798.

**What.** [[R761]] makes serve-entries the default v3 transport only where serve is proven. One of the proven shapes
is the test METHOD name: R-761's inventory found only plain identifiers (`/^[A-Za-z_][A-Za-z0-9_]*$/`) among the tests
that ever ran under serve (D1, S1 and the gift card). So a project with a quoted test method name, for example one
with a space, falls back to one-shot under the default, with the warning `al-runner-v3-serve-default-fallback`
(`unproven-test-name-shape`). It runs correctly, but without the speed-up.

**Why it is unproven.** The only fixture with such names is `fixtures/sandbox-names-tests` (leg N1). Under serve it
stops at its fourth test, `Dot.Step` (#5798, a dotted method name). So its other shapes were never seen under serve:
spaces, `-`, `(`, `)`, `/`, `&`, `å`, `æ` and a leading digit.

**To close.**
- Add a measured leg: N1's project WITHOUT `Dot.Step` (a fixture variant, or a test filter that leaves it out),
  under serve-entries, compared per mutant with `bcdev.names.baseline.json`.
- Pre-commit it first.
- Then widen `V3_SERVE_PROVEN_NAME_SHAPES` to exactly the shapes that leg proves. The dot stays refused until #5798 is
  fixed upstream and N1E reads `held`.

**Done (2026-10-25).** Leg N1S (pre-commitment `docs/superpowers/specs/2026-10-25-r763-n1s-precommitment.md`):
- It runs N1's project with `Dot.Step` cut, one-shot and then serve-entries.
- It compares the two per mutant, not with `bcdev.names.baseline.json`. Cutting a test makes 3 of N1's mutants
  `no-coverage` (only `Dot.Step` covered them), so the frozen table no longer applies.
- It measured 33 / 0 / 3 over 36 on both transports, with 0 differences and warnings `[]`.
- `V3_SERVE_PROVEN_NAME_SHAPES.method` is now `/^[A-Za-z0-9_ ()/&åæ-]+$/`: exactly the characters N1S ran.
- N1S is in `V3_GATE_LEGS`. Tests: `r761-serve-default.test.ts` (both directions, red-checked).
