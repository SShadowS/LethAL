Found by coord R-883: every BC.History app outside BaseApp, instrumented and compiled offline with alc beside an uninstrumented control. An error only in the instrumented build is LethAL's. Evidence: `/coord/handoff/R-883/`. Related: [[R888]] (a fifth, filed on its own).

Each case below is invented AL that reproduces it.

**A. `swap-enum-member` wrote a keyword member unquoted** (2 apps, 12 AL0107/AL0224/AL0104 errors each).
- `enum 50100 "K" { value(0; "and") { } value(1; "or") { } }`.
- `X := "K"::"and"` became `"K"::or`, a syntax error.
- Fix: the replacement is quoted when it is not a plain identifier or is an AL keyword. A plain member stays plain.

**B. `empty-block` rewrote a body that holds only a comment** (2 apps, AL0286/AL0287).
- `[IntegrationEvent(false, false)] procedure OnX() begin // note end;`.
- The mutant's dispatch put code and the reach latch into the event, and an event "can't contain code".
- Fix: `empty-block` refuses a block with no statements. Such a mutant is equivalent anywhere.

**C. `swap-rec-xrec` swapped a field-designating argument** (1 app, AL0166).
- In `OnValidate`, `Rec.Validate(Rec."X", V)` became `Rec.Validate(xRec."X", V)`, or, by swapping the call's receiver, `xRec.Validate(Rec."X", V)`. Either way the field is no longer the receiver's member.
- Fix:
  - refuse the field argument of Validate, TestField, FieldError, SetRange, SetFilter, GetFilter, ModifyAll, FieldNo, FieldCaption and FieldName, and every argument of CalcFields, CalcSums and SetCurrentKey;
  - refuse the receiver of such a call when its field argument is qualified;
  - a value argument, and an unqualified field, stay swappable.

**D. A dot-folder named in app.json `resourceFolders` was not copied into the batch project** (20 apps, AL0863 "The folder '.resources' does not exist").
- `"resourceFolders": [".resources"]`: the batch skipped every path with a dot segment, a rule meant for `.vscode`, `.git` and `.alpackages`.
- Fix: a path under a folder `resourceFolders` names is a resource, dot or not. The R505 source-drift watch reads the same set.

**Effect.** The fixes only refuse sites, or copy a missing folder. The five-set diff against master: fixtures identical; cdo 12, do 13 and dc 34 specs removed, 0 tuples and 0 ordinals moved.

**Not LethAL's: the remaining "instrumented-only" errors.** In Payment Practices and in Email - Outlook REST API, a 28.1-against-28.6 environment error sits inside a mutated statement. The instrumented copy holds that statement once per branch, so `r315-dc-compile.ts`'s count-based classification calls the extra copies emit. Read them by message.
