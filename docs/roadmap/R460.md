**What.** `flip-boolean-literal`'s `runTriggerTag` tags a forcing `false` -> `true` (R457) only on
a receiver `claimsRecordMethod` claims. An UNRESOLVED receiver is refused there, so its
`ModifyAll(..., false)` / `DeleteAll(false)` / `Modify(false)` / `Delete(false)` / `Insert(false)`
flip is untagged, although `forceCanRaise` itself keeps the tag on an unresolved table. R-364 made
an unresolved receiver keep the SKIP tag (`true` at `ModifyAll`/`DeleteAll`; F9 in
`flip-boolean-literal.test.ts`); the merge of R457 into R-364 deliberately left the forcing
direction as R457 landed it, so that R-364's exact site diff stayed the ruled 11 rows.

**Size.** R457's survey: `DeleteAll(false)` in CDO 32 sites, all unresolved (`docs/roadmap/R457.md`).
BC.History not counted for the unresolved subset.

**What to build.** In the unresolved branch of `runTriggerTag`, return `run-trigger-forced` for a
`false` too (the conservative, over-tag direction R143 and R-452 rule safe). Measure the retagged
rows on BC.History and CDO first, and pre-commit any `itest:tables` `platformArtifactKills` move.

**Closed (c7d06747, R-460).** Built as written: in `runTriggerTag`'s unresolved branch, a `false`
returns `run-trigger-forced` at all five methods, beside R-364's skip tag for a `true`.
`receiverUnresolved` matches the method NAME, so a one-argument `X.Foo(false)` is not swept in by
the `DeleteAll` entry's argument position. Pinned by F10 in `flip-boolean-literal.test.ts`: all
five calls in a caller wrapped whole in `#if` are tagged; the same calls from an indexed caller on
a table with no triggers stay untagged; a codeunit receiver that RESOLVES to a non-record stays
untagged. RED-CHECKED: before the fix F10 fails with all five untagged; "tag every unclaimed
`false`" fails F10's codeunit control and 13 R-457 tests.

**Exact site diff** (`/coord/handoff/R-460/site-diff.md`; master cd63827f vs c7d06747, 235 jobs per
side, 0 failed, 2,248,946 deployed rows on each): ADDED 0, REMOVED 0, keys moved 0, `hang-refused`
unchanged. RETAGGED 45 rows, every one a `flip-boolean-literal` `false` -> `true` going from
untagged to `run-trigger-forced`, with the same span and mutated text: BaseApp history 40 (Modify
21, Insert 10, DeleteAll 5, ModifyAll 3, Delete 1; 17 of them in Subscription Billing), CDO 2 sites
in Cloud (`Page 6175303`, a `DeleteAll` and an `Insert`, identical under `[]` and `[DOSMTP]`),
fixtures 1 (`sandbox-probes`' `LangRefusalRunner`, an `Insert`). `sandbox-data` is unchanged (387
rows), so `itest:tables`' `platformArtifactKills` cannot move. The R457 survey's "32 CDO sites, all
unresolved" did not hold as an unresolved-RECEIVER count: master already tags 196 forced rows in
Cloud alone, where the receiver resolves and the TABLE does not (`forceCanRaise` keeps those).
