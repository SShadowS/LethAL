**Filed by R-497's opus build review (2026-10-09), Minor findings M1 and M4.** Neither can produce a false kill:
coverage only chooses which tests run against a mutant, so a misplaced line moves a mutant between `survived` and
`no-coverage`.

**1. Object kinds beyond codeunits are unmeasured on BC.** [[R497]] admits the one-arm wrapped shape for every
object kind. The R-300b probe and `itest:bcdev-wrapped` are all codeunits. The R-497 census's admitted files in the
real corpora (BaseApp 241 files, 5,987 sites; DC 21 files, 320 sites; script and outputs in
`/coord/handoff/R-497/scratch/`) are mostly tables, pages and their extensions. BC's coverage line numbers are source
positions, so a difference by kind is unlikely, but a one-line shift near a trigger boundary would give a wrong
covering set. To close: add one wrapped table (with a field trigger) and one wrapped page to `sandbox-wrapped`,
pre-committed, or run one more R-300b-style probe round.

**2. `lethal verify` contradicts the run for a wrapped object.** `runNamedMutants` hands no build symbols over, so
verify refuses a wrapped file (fail-closed) with a sentence ending "Its mutants read no-coverage", while the run that
produced the survivor scored it `survived`. To close: hand the build's symbols to verify, or give verify its own
sentence.
