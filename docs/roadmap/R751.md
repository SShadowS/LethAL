**Filed 2026-10-24 by lethal-bugs during R-737.** Related: [[R737]].

**What.** `r737Partial` (in `packages/builtin-tier1/src/loop-hazard.ts`) calls a receiver partial only when one of its
types names no project object (for example a dependency codeunit). A receiver typed two ways where BOTH arms are
project objects, but one arm has no procedure of the called name, still yields a shorter target list that looks
complete. A strict reader (`r570Targets(..., true)`) then trusts the list and may miss the callee on the other arm.

**Reach.** 0 today: R_amb = 0 on every corpus (R737 census), so no test exists and none can be built from real code.

**To close.** Make the test "some type yields no procedures for this member" instead of "some type names no project
object". Add a red test per direction, then re-run the R737 census to confirm the reach.
