**Tier-2 Phase 2 operators** — `RemoveCommit`, `RemoveSetLoadFields` (tagged `likely-equivalent`, scored separately), and `SwapRecXRec`. Spec §5. **`SwapRecXRec` must not be built before its go/no-go experiment runs**: when `Modify(true)` is driven from AL rather than a page, `xRec` may carry the same values as `Rec`, and LethAL drives every test headlessly — if the two do not differ on that path the operator is near-worthless in this execution model, and a recorded "we measured it and it does not work here" is the better outcome. `RemoveCommit` also needs the report to distinguish a genuine kill from BC's "cannot run codeunit in a write transaction" platform artifact.
