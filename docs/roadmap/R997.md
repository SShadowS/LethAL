Found by coord task R-985 (2026-11-14), Guided Experience's re-run on edge-847b1fa5a ([[R946]]).

**What.** Guided Experience Item's extension name and publisher FlowFields look up `"Published Application"` with `"Tenant Visible" =
const(true)`. The tests set `PermissionsMock.Set('Guided Exp Edit')`, whose included sets grant read on `"Published Application"`.
When the lookup finds a row, al-runner refuses: "a permission denial (read permission on object type 0 id 2000000157) whose error is not
pinned yet (a FlowField over a system table)". 2000000157 is `"NAV App Extra"`, which `"Tenant Visible"` itself reads, a table the caller
never names. 84 of the 104 baseline tests are refused, so 2,055 of the 2,593 mutants read `no-coverage`. Microsoft ships these tests as
passing, so BC allows the read.

**Reduced** to an invented app (one table with that FlowField, a permission set granting it and `"Published Application"`, Microsoft's
Permissions Mock): refused when the lookup finds the app's own row; passes when it finds none; both refused (on 2000000206) without the
`"Published Application"` grant. alc builds it. Not run on a BC server.

**Filed:** https://github.com/aldevtools/BusinessCentral.AL.Runner/issues/8038. Repro `/coord/handoff/R-985/repro`.

**To close.** #8038 fixed, the repro passing on `current`, and Guided Experience re-run with its 84 tests in the baseline.
