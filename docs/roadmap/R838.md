**Filed 2026-11-06 by preproc.** Related: [[R830]], [[R196]], [[R179]].

**What.** `empty-block` cedes `while` bodies and leaves `repeat` bodies alone, so it does not empty a loop's own body. It does empty an
arm inside one. In `while not S.EOS do begin if Ok then begin S.ReadText(T); end; end`, emptying the arm deletes the only step, and the
same goes for an assignment step. [[R830]] refuses a statement call and R196 refuses an assignment, but neither asks about a block
holding one. The negated guard of such an arm (`negate-conditional` on `Ok`) is the same question.

**Next.** Count on the corpora. Then refuse a site that contains a refused statement, as `altersBoundCall` does for a bound. Weigh the
guards with the count.
