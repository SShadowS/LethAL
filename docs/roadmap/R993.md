Found by coord task R-981 (2026-11-14), while bisecting why Sales Lines Suggestions' install is still refused ([[R933]]).

**What.** On edge-736fc7677 (and edge-42af5d384), `JsonObject.ReadFromYaml('{"a": 1, "b": 2}')` raises `The data does not
represent valid YAML.`, quoted keys or not. A flow mapping with one entry and a block mapping with two keys read fine. Any JSON object
is a YAML 1.2 flow mapping, and BC documents `[Ok := ] ReadFromYaml`: with the return value used, a failed read gives false; on
al-runner it raises inside `if not ... then` (its `ReadFrom` does return false there). Not run on a BC server.

**Where it matters.** Microsoft's Test Runner reads a `.yaml` dataset's metadata with `if not ReadFromYaml(...) then exit;` (`Test
Inputs Management`), so an AI test dataset in flow style would stop there on v3: a lost test, so mutants it reaches read
`no-coverage`. No corpus test is known to hit it yet: Sales Lines Suggestions' datasets are `.jsonl`, which skip that call.

**Filed:** https://github.com/aldevtools/BusinessCentral.AL.Runner/issues/8027 (invented repro). Evidence `/coord/handoff/R-981/`.

**To close.** #8027 fixed and its repro passing on `current`.
