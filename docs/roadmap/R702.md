**Filed 2026-10-24 by R-696 (lethal-bugs)**, evidence `/coord/handoff/R-696/numbers.md` and `probe/results.md`. A
plausible hang that is NOT refused. Limits of the [[R696]] rule that were accepted, not measured.

**What.** [[R696]] refuses a Next-driven loop whose BODY moves the record it walks (a Rename, a Modify after a key
write, a ModifyAll of a key field, an Insert) through a second variable. It reads only the loop's own procedure:

- **No callee is followed from a Next loop.** A mover, or an insert ahead of the cursor, made inside a procedure the
  loop calls (same object or another) is not seen. 3,134 of the 7,895 production Next loops (40%) pass the walked
  record to a call (`numbers.md`).
- **Temporary walks are skipped.** A walk over a temporary record cannot be moved by a permanent variable, but a
  second variable bound to the SAME temporary table (passed by `var`), and R's own insert into a walked temporary
  table, were not probed.
- **A RecordRef walk (`RR.Next()`) is not read.**
- **A guard in a helper**, and a bound set by a caller, stay outside (the caller-set sort key fails closed, so only
  the guard is lost).

**To close.** Run a callee census: for each Next loop that passes R to a call, read whether the callee moves or inserts
into R's table. Add a temporary-table probe leg (a second variable of the same temporary table; R's own insert into
it) on bc2. Then extend the rule, or close with a ruling.

**Closed 2026-10-24 by R-702 (lethal-preproc)**, evidence `/coord/handoff/R-702/measure.md` (with `measure-gap1.md`,
`measure-gap2.md`, `cost-gap2/`), probe `scripts/r702-probe/`, pre-commitment
`docs/superpowers/specs/2026-10-24-r702-gap2-probe-precommitment.md`.

- **Callees: closed by ruling (orchestrator, 2026-10-24).** By parse, over all four corpora, only 119 Next loops pass R
  to a callee that moves or inserts into R's table (BC.History 110, DC 8, DO 1, CDO 0). 114 of them have no exit in
  their body, and the other 5 hold only an `Error`. Refusing them would cost 1,229 BaseApp specs (0.17%) and 147 DC
  specs (0.07%). In a sample of 10, none had an exit a mutant could delete, and at least 4 were false positives. The
  one plausible hang there is DC's `Clone` shape, filed as [[R717]].
- **Temporary walks: built.** On bc2 (run 3), a temporary walk ran forever when a variable SHARING its rows through
  `X.Copy(R, true)` moved a row's key ahead of the cursor, or inserted a row ahead of it. A by-value copy holds none of
  R's rows, and R's own Modify and Insert ended, so neither is a hazard. The rule `r702Shared` now refuses a
  temporary walk whose own procedure holds such a sharer and a mover through it, as R696 refuses a permanent one.
  Tests: `r702-temp-walks.test.ts`.
- **Found on the way:** R's own Insert is finite on permanent tables too, so R696 over-refuses it: [[R718]].
- **Still out:** RecordRef walks, a guard in a helper, a sharer bound in another procedure or a callee.
