**Found by gpt-6-sol reviewing C02-05 (2026-09-26); not measured live.** `parseVersionConflict`
(`packages/runner/src/app-version.ts`) is an unanchored match on "newer version <v> was already
installed". Two callers treat a match as proof that BC refused the publish, which clears the publish
marker: `isConfirmedTerminalPublishFailure` for the TARGET publish (`packages/runner/src/orchestrator.ts`)
and `decideTestAppOutcome` for the C02-05 test-app publish (`packages/runner/src/test-app-publish.ts`).

**Consequence:** a failure whose text only QUOTES that phrase (a timeout diagnostic that echoes an
earlier message, an app name containing it) would be read as a confirmed refusal, and the marker
cleared over a publish whose dispatch is uncertain. No such text has been observed.

**Fix shape:** accept a refusal only when the message names the app and the version THIS publish
attempted, in BC's sentence shape ("Cannot install the extension <name> by <publisher> <attempted>
because a newer version <v> was already installed"), in one shared helper used by both callers.
Negative tests with the phrase quoted inside a timeout message, and with a different app's name.

**Closed (9842500f).** `confirmedDowngradeRefusal` (`packages/runner/src/app-version.ts`) accepts a
refusal only when the text holds BC's whole sentence, "Cannot install the extension <name> by
<publisher> <attempted> because a newer version <v> was already installed.", with the three fields
escaped. The pattern is the MEASURED wording: the Cronus281 sample of 2026-07-19 quoted in
`docs/superpowers/specs/2026-07-19-layer-5a-deployment-identity-design.md`, and the 2026-07-20
stale-publish probes in `fixtures/README.md`, whose Probe B also shows BC wrapping the sentence
("Publishing failed due to '...'"), so the match is not anchored to the start. Both callers use it:
`isConfirmedTerminalPublishFailure` takes the target's identity from app.json plus the minted
version, and for a hook publish reads the identity an `EnvToolError` carries
(`EnvToolPublisher.publishFile` reads it from the package); `decideTestAppOutcome` takes the
`CompiledTestApp`. Negative tests: the phrase quoted in a timeout, another app name, publisher and
attempted version, for both callers; each red-checked against the old unanchored match.
`parseVersionConflict` is unchanged and still drives the orchestrator's one-shot re-stamp retry.
