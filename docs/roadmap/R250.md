**Found by gpt-6-sol reviewing C02-05 (2026-09-26); not measured live.** `parseVersionConflict`
(`packages/runner/src/app-version.ts`) is an unanchored match on "newer version <v> was already
installed". Two callers treat a match as proof that BC refused the publish, which clears the publish
marker: `isConfirmedTerminalPublishFailure` for the TARGET publish (`packages/runner/src/orchestrator.ts`)
and `decideTestAppOutcome` for the C02-05 test-app publish (`packages/runner/src/test-app-publish.ts`).

**Consequence:** a failure whose text only QUOTES that phrase (a timeout diagnostic that echoes an
earlier message, an app name containing it) would be read as a confirmed refusal, and the marker
cleared over a publish whose dispatch is uncertain. No such text has been observed.

**Fix shape:** accept a refusal only when the message names the app and the version THIS publish
attempted, in BC's sentence shape ("Cannot install the extension <name> by <publisher> <attempted>
because a newer version <v> was already installed"), in one shared helper used by both callers.
Negative tests with the phrase quoted inside a timeout message, and with a different app's name.
