**Found by the issue #6 cross-check** (`docs/measurements/2026-09-27-gh06-grammar-crosscheck.md`, cluster C1b).
This is the tree-sitter-only half of the grammar defect in [[R283]]: the same 34 BaseApp sites, seen
from the other side.

**What happens.** tree-sitter-al 4.3.0 splits `asserterror Buckets[1].Delete(true);` into
`asserterror Buckets` and a separate statement `[1].Delete(true)`, with no ERROR or MISSING node.
That fragment is a `call_expression` in statement position, so it is an OVER-CLAIM: a site the
compiler does not agree exists (the compiler's call starts at `Buckets`, not at `[`).

**Minimal reproduction** (hand-written, not corpus source), `scripts/lib/al-kind-mapping-asserterror-index.al`:
```al
codeunit 50001 "Indexed Receiver Probe"
{
    procedure Run()
    var
        Buckets: array[3] of Record "Integer";
    begin
        asserterror Buckets[1].Delete(true);
        asserterror Buckets[2].Validate(Number, Buckets[1].Number);
        Buckets[3].Delete(true);
    end;
}
```
Harness output: tree-sitter-only `call_expression` [154,170] and [199,238], and the call probe
tree-sitter-only at 154 and 199.

**Measured.** BaseApp (sha256 2afad2aa60b13958): 34 tree-sitter-only `call_expression` sites and 34
tree-sitter-only call-probe sites, all under `BaseApp/Test`. Zero in the other six corpora.

**The pipeline check: the over-claim SURVIVES.** `bun scripts/census-fixture-mutants.ts` on the
reproduction plants, with no DISPLACED or NOT-CARRIER mark:
- line 7: `lethal.void-method-call`, before-text `[1].Delete(true)`, deleted. Exact match with the
  tree-sitter-only site [154,170].
- line 8: `lethal.void-method-call`, before-text `[2].Validate(Number, Buckets[1].Number)`, deleted.
  Exact match with [199,238].

The other census lines on those lines do not match: `flip-boolean-literal` on `true` (a literal
inside the site, not the site), and `empty-block` on line 6 (the whole body, a different span).

**Open: what BC does with the mutant.** Deleting the fragment leaves `asserterror Buckets;`. Whether
`alc` rejects that, or it compiles and gets scored, was NOT measured. If it compiles, the mutant is
a real edit to code the compiler reads differently, and its verdict means nothing.

**Cost today: low.** All 34 sites are in test code, and `asserterror` is test-only across
Microsoft's published source ([[R216]]). LethAL mutates the target app, not its tests.

**What would close it.** The grammar fix (tree-sitter-al #26) closes both halves. Before that, measure the compile
of `asserterror Buckets;` with `alc`, which decides whether this is a deployed wrong mutant or a
compile refusal.

**Reproduce.** `bun scripts/probe-grammar-crosscheck.ts scripts/lib/al-kind-mapping-asserterror-index.al`,
then copy that file alone into an empty directory and run `bun scripts/census-fixture-mutants.ts <dir>`
(it takes a directory).

## Closed 2026-09-27: fixed by tree-sitter-al 4.4.1 (#26, upstream `209d038`)

Vendored at `50e98d1` (tree-sitter-al 4.4.1, released asset, sha256
`cd6e347e...d085ed099`). `asserterror`'s body node is now a statement, so
`asserterror Buckets[1].Delete(true);` is one call on the indexed receiver instead of splitting
into `asserterror Buckets` plus a fragment statement `[1].Delete(true)`.

Measured (`docs/measurements/2026-09-27-gh06-grammar-crosscheck.md` section 10, run 003; TSAL-441
Task 6): BaseApp's tree-sitter-only `call_expression` and call-probe records both go 34 -> 0
(cluster C1b). The pipeline check (`census-fixture-mutants.ts` on
`scripts/lib/al-kind-mapping-asserterror-index.al` alone) no longer plants a `[1].Delete(true)` /
`[2].Validate(...)` fragment mutant: under 4.4.1 it plants 4 real mutants on the file's actual
statements instead, and no row's before-text starts with `[` (TSAL-441 Task 6, section 10.1).

The 34 phantom `lethal.void-method-call` rows left the BaseApp/Test census entirely (TSAL-441
Task 3, Step 7): they were never real mutants, so this is 34 dead sites leaving the census, not a
coverage loss. The open question about whether `alc` accepts the fragment's leftover
`asserterror Buckets;` is moot: that mutant no longer exists, so it was not measured and does not
need to be.
