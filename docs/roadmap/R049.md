**`lethal --help` does not exist, and it is the first command a new user runs.** `parseCliConfig` (`packages/runner/src/cli.ts`) drives `node:util`'s `parseArgs` in strict mode with no `help` or `version` option, so `--help` exits 1 with a raw `TypeError: Unknown option '--help'` and a stack trace into the bundled binary. A bare `lethal` is better (`unknown subcommand: got none, expected one of: run, clear-quarantine, force-reset-lease`) but names no flags. Now user-visible rather than internal: `v0.1.0-alpha.1` ships a downloadable binary whose only discovery surface is `fixtures/README.md`, which a downloader does not have. There is no `--version` either, so a bug report cannot state which build it came from — the version exists only in the release filename. Evidence: measured 2026-07-27 against `build/lethal-0.1.0-alpha.1-windows-x64.exe`; `docs/releasing.md` §"Known gaps in the distribution path".
