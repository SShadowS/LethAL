Found by the owner (2026-11-12, "do them all now"; coord R-935). Related: [[R593]], [[R935]], [[R928]], [[R924]].

**What.** `corpus-snapshot.ts diff bch` dumps every one of BC.History's 519 projects on the branch, about an hour, even when the
change can only move XMLport sites (R928's moved 3). And each BC.History task rebuilt the per-app source trees and package pools
of earlier tasks, because cleanup deleted them (R-928's and R-932's System Application module pools among them).

**Built (coord R-935).**
- `diff <set> --shape <name>` narrows the diff to the projects holding a named AL shape. The first shape is `xmlport`: 46 of 519
  BC.History projects. The scan uses the dumper's own file walk and `.al` filter, keeps every project found on one side only,
  and selects a project it cannot list cleanly. Every diff now prints a `scope:` line: full, narrowed by `--projects`, or narrowed
  by `--shape`. `fixtures` refuses `--shape`.
- **Proven a superset** on both known diffs: R919's 13 and R928's 3 changed projects are all selected (a test that reads the real
  corpus in the container; skipped where the corpus is missing).
- **Not built: an `auto` mode from changed paths.** No generation file is limited to one shape (`loop-hazard.ts` judges every loop,
  and an operator edit can match new syntax), so mapping changed paths to fewer projects can miss one. The shape is the change
  author's claim, named per change. Asked of the owner: coord question `q-20261112T095730-e0c324e4`; design note
  `docs/superpowers/specs/2026-11-12-r935-narrowed-identity-diff.md`.
- `scripts/corpus-build-cache.ts`: a shared, read-only cache at `/coord/cache/corpus-builds/<name>@<corpus HEAD>+<probing key>/`.
  `put` copies (links followed), writes a manifest of every file's size and sha256, seals the tree read-only and renames it
  into place, so an entry is whole or absent. An existing entry is refused, and so is a folder with no manifest (half-written).
  `path` prints a checked entry; `check` hashes every file. `lane.md`'s cleanup step never deletes the cache.
- **Filled:** 18 entries, 635 MB: the per-app trees of R-913, R-914, R-924, R-925, R-925-prep, R-927, R-928 and R-932,
  R-925's built dependencies and its eight package folders (alc-built with the Windows BC 28.4 probing path), and the base
  package pool R-881 built. The System Application module pool joins when R-933's rebuild runs.
