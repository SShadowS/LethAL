**Method (pre-committed).** For each of the 16 projects where PR-05 freed tests:
1. A discovery run narrowed to the freed tests' files (one operator) finds the files they cover.
2. A scoring run with every test, mutants from those files only.
3. A per-mutant comparison with the project's earlier run, by identity key (scheme 48), on the mutants both scored. Allowed:
   survived/no-coverage -> killed. Anything else is a BLOCK.

All on edge-a184cfc79. R-982's configs pin edge-736fc7677, so those runs were re-run pinned (amendment 2).

**Result.**
- **26 allowed moves in 5 projects.** 20 were killed by a freed test (Late Payment Prediction 15, Digital Vouchers 4, Email
  Logging 1). Service Declaration (3) and PayPal (3) gained through other tests.
- **The prediction ("gain" for 11 projects)** held for 5 of the 10 measurable ones; "no gain" held for 5 of 5. Freed is not the
  same as passing: Sales Line Suggestions' 35 freed tests all fail.
- **BLOCKs, all explained, none a lost kill.**
  - 59 survived -> no-coverage on triggers in five projects. The old references attributed them by the object-level trigger
    fallback. The coverage-"none" ground truth killed none of them.
  - 13 no-coverage -> survived: newly covered by a freed test that kills nothing.
  - 1 error -> survived: the reference's refusal (#7834) is gone.
- **Not measurable.** Sustainability's reference covered one file the freed tests do not reach. R-915's four apps (the 122
  Subscription Billing tests) have no sources left.
