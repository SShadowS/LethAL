Coord task PR-13 (2026-11-15). Evidence: `/coord/handoff/PR-13/` (`run/out.txt`, `run/report.json`, `run/no-provider.txt`,
`comment-7415.md`, `platform-tables.py`). Related: [[R1013]] (the refusal ledger, where this refusal is the largest open group).

**Why this family.** The refusal ledger's largest open group is #7775/#7415, "store error platform table <x> (N) has no provider",
3,054 sightings in LethAL's corpus runs, nearly all on `Api Web Service`.

**What was built.**
- `scripts/refusal-family-platform-tables.json`: the 214 non-temporary tables of al-runner's System app 28.4 (id and name).
- `scripts/refusal-family.ts` family `platform-table-read`: two cells per table, `IsEmpty` and `FindFirst` on a fresh record.
- `classOf` folds every "platform table '<name>' (<id>) <reason>" text into one class per reason, and strips the `store error `
  prefix and a leading read verb before classing the rest.

**Result on edge-5a58a0f16** (428 cells): 170 pass, 3 fail with BC's own error (the Agent tables: "Agents are temporarily
unavailable"), 255 refused. 239 of the refused cells, over 120 tables, are the known no-provider class. The other 16 are ten
one-table classes, each saying the table's rows are not pinned (Power BI Blob, Power BI Default Selection, Company, API Webhook
Entity, Application Object Metadata, Expanded Permission, License Permission, Media, Metadata Permission, Page Action). BC's answer
for all of them is inferred, not measured: a read of a platform table returns on BC.

**Upstream.** The sweep and the 120 tables are posted on #7415:
https://github.com/aldevtools/BusinessCentral.AL.Runner/issues/7415#issuecomment-6892548959. The one-table classes are listed in the
same comment; none is filed on its own, since each is al-runner saying the rows are not pinned, not a wrong answer.

**Regression set.** `scripts/upstream-repros/u7415-platform-no-provider`: plain `IsEmpty` reads of Api Web Service, Tenant Media
Set, Object Metadata, Performance Profile Scheduler and All Control Fields, expected to pass. On edge-5a58a0f16 all five are still
refused (94 tests in the set: 0 flipped, 0 regressed).
