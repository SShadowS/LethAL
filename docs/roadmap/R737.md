**Filed 2026-10-24 by lethal-preproc during R-725** (opus review, probe P3). Related: [[R725]], [[R720]], [[R521]].

**What.** `declaredType`'s text fallback looks for a declaration only directly under `var_section`/`var_body`. It never
descends into preprocessor nodes. So a CALLEE receiver declared inside a var-section `#if`, or every-arm-ambiguous
(for example `Cap: Codeunit "X"` in both arms), gets no type. `callTargets` and `r570Targets` then return nothing, so
no R570/R572 row is built, and R500 shape 2 and `r696CalleeInserts` do not follow the call either. Measured on R-725's
R572 fixture with `Cap` in those two forms: the stateful callee is NOT refused. A swallowed member is refused,
through R725's own fix.

R521's ruling classes (RecordRef, Variant, parameter, array element, Report/Page, interface) do not include
`#if`-declared receivers, so this is not already ruled.

**To close.** Either let the text fallback descend preprocessor nodes inside var sections, reading every arm (a
receiver typed differently per arm is then "unknown", so all its targets are followed, or it refuses), or rule it with
a measured reach. `declaredType` is a private function of `packages/builtin-tier1/src/loop-hazard.ts`, but every hang
reader there uses it, so measure the cost by parse on all four corpora first.
