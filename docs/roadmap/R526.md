**Filed 2026-10-08 by the [[R500]] build** (plan r3 `/coord/reviews/R-500-plan/plan.r3.md`, adversary r2 finding 4d).
A plausible hang that is NOT refused.

**What.** For an `Interface X` receiver, R500 refuses every project codeunit whose `implements` clause names X
(`objectsOfType` in `loop-hazard.ts`). A codeunit that implements an interface B which `extends` X can be the object
behind that receiver too, and it is not refused.

**To close.** Follow `extends` transitively when collecting implementers, measure the change, and land it or
close it with a ruling.
