**Scope.** 61 open ledger causes carried PR-05's "not re-run" note. One, the #8154 Confirm key, was settled by PR-28 and only
quotes PR-05's note as history, so 60 are in scope.

**Re-runs on edge-5a58a0f16.**
- **23 fresh baselines** reach every cause with a refused test. The cleaned apps run from R-986's recreated copies of the same
  BC.History source.
- **Quality Management and Shopify** (R-915, cleaned, never recreated) were rebuilt the same way, and cached:
  - corpus build cache `bch-r915-qm-shop-trees` (the source trees);
  - `bch-qm-testlib` (the Quality Management app and its test library, built from source with R-982's `build-libs.ts`).
- **Three old configs failed and were replaced by PR-39 copies:** Regex, Essential Business Headlines and Guided Experience
  named pools since cleaned, or omitted the environment newer builds require.
- **32 causes were seen only on mutant runs, plus 2 cascades** (a test refused because an earlier one failed; the reader marks
  those only on mutants). For these 34, up to 3 files of their sighted mutants were re-run with `triage-baseline.ts --only`
  (23 runs; every run the time budget cut was re-run with `--budget-s 5400` and finished).
- **The join** (addendum 3): each sighted mutant is matched by file, procedure, operator, `ast_hash` and identity ordinal. A
  mutant counts as running the cause's test again only when its own refusing test now ran (pass or fail) and no row shows the
  cause. The first classification joined by fewer fields and collided; it is replaced. The fixed set did not change; 8 causes
  moved from "not observed" to "still seen".

**States (PR-05's rules), written by `apply.py`:**
- **fixed, 4:** the cause's refused tests or sighted mutants run now and none shows it. The apps a re-score could count them in:
  - a permission denial on an empty dependency table (14 tests, Service Declaration). Read on R-982's pool where the old run
    used R-975's pool-union; the note says so, since the cause is about a dependency app's empty tables;
  - a report's defaultlayout output (#7836/#8080, Bank Deposits; 1 mutant);
  - RecordRef.FindSet on an unopened RecordRef (#7819/#8036, Data Archive and Record Link Management; 3 mutants);
  - RecordRef.GetTable of a Text (#8084, Record Link Management; 2 mutants).
- **open, still seen, 50:** 21 from refused tests, 27 mutant-only, both cascades. Each keeps its issue.
- **open, not observed, 4:** 2 whose refused tests now hit another refusal (the JObject load and the Html SaveAs), 1 mutant-only
  whose mutants now hit another refusal (BinaryReader.BaseStream), 1 whose one sighted mutant was not reached (a RunModal lookup
  with no row).
- **open, no standing sighting, 2.**

**Predictions, scored** (over the 58 with a sighting in scope).
- Main prediction: about a fifth fixed, three fifths still seen, a fifth not observed. Measured: 4 fixed (7%), 50 still seen
  (86%), 4 not observed (7%). Far fewer were fixed than predicted.
- Addendum 1, mutant-only causes: about a third fixed, half still seen. Measured, of 32: 3 fixed, 27 still seen, 2 not observed.
- No by-design cause, as predicted.

**Not done:** re-scoring the stored runs of the four apps with fixed causes (Bank Deposits, Service Declaration, Data Archive,
Record Link Management). Their tests and mutants can now be counted.
