**Filed 2026-10-08 by the [[R500]] build** (plan r3 `/coord/reviews/R-500-plan/plan.r3.md`, adversary r2 finding 4e).
A plausible hang that is NOT refused.

**What.** `Codeunit.Run(Codeunit::X, Rec)` and `Report.Run(...)` start code in another object by id or name, not
through a typed receiver, so R500's one-hop rule does not find the target. Its `OnRun` (or the report's own items)
can write what the calling item's exit reads, and is still mutated.

**To close.** Resolve the literal target of such calls from open report-item code, measure, then refuse the
target's `OnRun` closure or close it with a ruling.
