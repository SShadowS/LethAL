**Filed 2026-10-22 by lethal-bugs during R-599** (plan r3, build step 1; orchestrator ruling on the r2 review's F1).

**What.** `scripts/tsconfig.json` lists the scripts it checks one by one (R119, R120: admitting a script is a
decision, not a glob). Every tracked `.ts` under `scripts/` that is not in its `files` list is never seen by
`bun run typecheck`. `bun test` does not type-check either, so a wrong import, a missing export or a type error in
one of them shows up only when someone runs it. R-599 found `bc-linux-setup.ts`, `bc-republish.ts` (and their tests)
and `r594/cdo-publish.ts` outside, admitted them (0 pre-existing errors), and added its own new modules. What is left:

**The rule:** `git ls-files 'scripts/*.ts' 'scripts/**/*.ts'` minus the `files` of `scripts/tsconfig.json`.
