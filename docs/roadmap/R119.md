**`scripts/` is outside `tsc --build`, so `bun run typecheck` type-checks none of the 21 scripts — including ones that gate real decisions.** Root `tsconfig.json` references only the six `packages/*` projects; `scripts/*.ts` is in no project's `include`, so `tsc --build --force` never sees it. Measured 2026-08-06 while adding `scripts/roadmap-index.ts`: that file compiles clean under the repo's exact strict flags (`bunx tsc --noEmit --strict --exactOptionalPropertyTypes --noUncheckedIndexedAccess --verbatimModuleSyntax scripts/roadmap-index.ts` → exit 0), but nothing in the build loop would have said so, and nothing will say so when it next changes. The exposure is not hypothetical: `scripts/census-swap-call-arguments.ts` and `scripts/census-tier3-candidates.ts` produced the counting-rule numbers that R82 and R13 were decided on, and `scripts/build-binary.ts` builds every released binary — a type error there is a wrong number or a broken release, not a lint nit. Fix: add a `scripts/tsconfig.json` (extending `tsconfig.base.json`, `noEmit` or its own `outDir` outside the repo's `dist` cleanup) and reference it from the root project. **Measure before landing it**: the other 20 scripts have never been checked, so the first run is a survey, not a green light — if it is noisy, admit the scripts one directory at a time rather than weakening the base flags for all of them. Filed 2026-08-06 while migrating the roadmap (R118).
