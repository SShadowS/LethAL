R55's measured direction is hub-red/fence-green, which is safe: verdicts come from the fence, and R37 confirms no false survivor. The REVERSE — a test the hub passes that the fence would fail — is not safe and nothing checks for it. Such a test enters the green set, then fails against every mutant it covers on the verdict path, and each of those reads as a KILL: a false kill, the one error class LethAL otherwise structurally avoids. Note R55's candidate fix does not close this, because it only re-checks tests the hub already failed. Nothing has yet measured whether this direction occurs; the fact that the observed disagreement went the other way on one product is not evidence that it cannot.
