**Filed 2026-11-06 by lethal-bugs.** Related: [[R810]], [[R332]], [[R849]].

**What.** R810's rule, that a record on a pinned build writes only the rows already committed, applies only when `activePin` is set.
`pinnedRecord()` in `al-runner-v3.itest.ts` returns undefined when it is not. alpha.2 has a `.gated` file and no hand pin. So with
`LETHAL_ALRUNNER_V3_PATH` naming that build, the run is not a candidate, nothing refuses it, and `writeBaselineOnce` writes the baseline
unchecked. alpha.2 has a known wrong verdict (upstream #5603), so a record there would freeze it.

Read in the code by the plan review. Not run, and a refusal further on in the backend was not ruled out.

**Next.** Refuse any record whose binary is not `current`, by name, with a red test each way.
