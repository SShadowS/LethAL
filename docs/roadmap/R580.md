**Filed 2026-10-11 by R-394** (`/coord/handoff/R-394/measure.md` §1).

**What.** The al-runner coverage guard (R298/R300, `applyAlRunnerCoverageGuard`) refuses coverage for a project
holding any `#if`-wrapped object of a shape it does not admit. 42 refused files in 12 BC.History projects wrap a
single CODE-FREE object: an enum, interface, permission set, control add-in, dotnet block or enumextension inside
`#if not ...`. Such an object has no lines al-runner reports, so it cannot misplace coverage. Yet each one turns
coverage off for the whole project.
- Together with [[R579]], admitting these would cut BC.History's coverage-off set from 15 projects to 2: BaseApp
  and EU 3-Party Trade Purchase, the only two with code-bearing nested wrappers ([[R535]]).
- CDO, DC and DO are not affected.

**To close.** Admit a wrapped file whose objects are all code-free (`alRunnerAdmitsWrappedFile`). Test each kind.
Re-measure which projects keep coverage on.
