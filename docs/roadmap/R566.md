**Filed 2026-10-10 by R-498's build review.** [[R498]] proves a source-less read-back after the env-tool hook by
byte equality: the served package's SHA-256 must equal the `publishApps` file's. On Cronus28 the dev endpoint
(`altool publishapp`) serves back exactly the published bytes, with and without `.al`
(`/coord/handoff/R-498/measure.md`).

The hook does not publish that way. It publishes through the env tool's own publish command
(`makeEnvToolPublisher` in cli.ts). If that command repackages the file, the served bytes differ and the run stays
unproven. That is safe, but R498 then gains nothing on that route.

**To close (host only).** Publish a source-less test app through the env tool, which is how R-498's V3 package
was made (`/coord/handoff/R-498/scratch/strip498.py`). Read it back with `fetchPublishedAppPackage` and compare
SHA-256 with the file. If they are equal, R498 holds on that route too. If not, record what the tool changes, and
leave such sessions unproven by design.
