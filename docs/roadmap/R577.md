**Filed 2026-10-11 by R-394** (orchestrator's ruling: false-kill class, the next task for lethal-preproc). Evidence:
`/coord/handoff/R-394/measure.md` §3 and `/coord/handoff/R-394/repro-pagecov.md` ("Why the slice evidence fails").

**What happened.** On al-runner `v2.12.0-main.f06ee78c`, `--server` transport with the resource selector:
- **The run:** a `lethal run --backend al-runner` with coverage "none" on BC.History Simplified Bank Statement Import
  (the wizard codeunit plus the import-preview page, 38 mutants). It scored **M0035** (the preview page's
  `OnAfterGetRecord`, `remove-assignment`) as **killed** by the wizard test
  `WizardAllStepsCsvSeparatorSemicolonAndDecimalSeparatorComma`, with an `Assert.AreEqual` failure.
- **The kill was not caused by that mutant:**
  - M0035 run ALONE (`--lines`, the same operator, coverage "none"): **survived**.
  - The whole slice re-run, same flags and scope: 3 killed / 35 survived / 0 no-coverage. It is identical to the
    first run except M0035, which survived.
  - The killing test declares no page handler, so it cannot open that page: an unhandled modal page fails on
    al-runner. The wizard code that opens it has 0 hits.
  - The failure's shape (`Expected:<Comma> ... Actual:< >`) matches the fault of a DIFFERENT mutant, M0005
    (`empty-block` on the upload procedure, `Expected:<Semicolon> ... Actual:< >`): the wizard read no file.

So the run carried another mutant's effect into M0035's run. That is a false kill. The cause is NOT found. The
first guess is state that survives in the `--server` daemon (or the resource selector) from one mutant's run into
the next.

**Why it matters.** A kill must mean that the mutant made a green test fail. This one did not. Nothing in the
report flags it. On a real project it inflates the score and hides a survivor.

**To close.**
1. Reproduce: re-run the slice several times, one-shot vs `--server`, static vs resource selector, and look for
   kills that do not survive a re-run (or a single-mutant run).
2. Find the carried state.
3. Fix or guard it. For example: re-verify every kill by re-running that mutant alone on a fresh transport, or
   reset the daemon between mutants.
4. Measure on the gates.
