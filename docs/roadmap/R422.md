**Found 2026-10-03, preparing R-396 in the kraken (Linux) container.** Continia Document Output at
`5f2a71d` declares `"logo": "Images\\Logo.png"` in `Cloud/app.json`. The file exists
(`Cloud/Images/Logo.png`). The Linux `alc` (AL compiler 18.0.41.45789, under
`ms-dynamics-smb.al-18.0.2732683/bin/linux`) reads the backslash literally and stops before
compiling a line:

```
Cloud/app.json(13,5): error AL1001: Source file 'Images\Logo.png' could not be found
```

Measured offline: the unchanged project gives exit 1 with that single error. A scratch copy whose
only change is `Images/Logo.png` compiles with 0 errors. The Windows `alc` accepts either form, so
every project made on Windows can carry such paths. A real customer project hits this on its
first Linux run, and nothing in LethAL says why.

**Which LethAL paths reach it:**
- **bcdev backend.** `prepareBatchProject` (`packages/runner/src/orchestrator.ts`) copies the
  project's `app.json` (with a minted version) and its resources into each batch folder, then
  compiles that with `alc`. The backslash path is copied unchanged, so every batch fails with
  AL1001. R39 made the logo FILE travel; the PATH in `app.json` is still OS-specific.
- **`compile:fixtures`** (`scripts/compile-fixtures.ts`). Every fixture in this repo is
  resource-free, so it does not hit this today. It would for any fixture that gains a logo or a
  resource path written on Windows.
- **al-runner backend.** Not known yet. al-runner compiles AL itself; whether it reads `app.json`'s
  `logo` (or other resource paths) is being measured by R-396 run (i), which runs on the unpatched
  copy. Record the result here.

Other `app.json` fields that name paths (for example resource folders and translation or layout
references) were not checked and may have the same problem.

**To close.** Decide where to handle it: normalise `\` to `/` in the `app.json` LethAL writes for a
batch (and say so in the report), or refuse up front by name with a message that names the field
and the fix, rather than letting `alc` fail with AL1001. Add a fixture or unit test with a
backslash resource path, red on today's code. Never patch the user's own project in place.
