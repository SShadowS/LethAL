**Filed 2026-10-11 by R-394** (`/coord/handoff/R-394/measure.md` §3, the Essential Business Headlines attempt). A
diagnosability bug: no verdict is wrong, but the user cannot tell why the run failed.

**What.** On BC.History Essential Business Headlines (its `app.json` asks for BC 28.6, and the local al-runner ships
28.5), the `--server` baseline failed before running any test. LethAL reported only "returned: <no tests>". al-runner
had printed the real cause ("BC version selection failed ... minimum 28.6"), but LethAL did not surface it.

**To close.**
1. When a `--server` baseline returns no tests, include the daemon's own error or stderr tail in the error LethAL
   raises, as the one-shot path does for its process output.
2. Pin it with a fake daemon that answers with an error and no tests.

**Closed 2026-10-23 by ruling (R654 S4).** R654 S3 (35f3c67f) deleted the .NET al-runner and its `--server`
baseline. The Rust al-runner needs a `bcVersion` in its config and does not pick a BC version itself.
