**Filed by R-536 (2026-10-09), the remainder of [[R536]] part 1.** [[R497]] admits the one-arm wrapped shape for
every object kind on BC, and [[R536]] measured it live for a codeunit, a table (with a field trigger) and a page: BC
and al-runner number each as they number its unwrapped twin. A wrapped `tableextension` or `pageextension` is admitted
by the same rule, but no gate holds one, and an extension's members (field triggers on base fields, `modify`
triggers, added procedures) are placed through the extension's own object key.

Size: unmeasured. The R-497 census (`/coord/handoff/R-497/scratch/`) counts BaseApp's admitted wrapped files (241,
5,987 sites) without splitting them by object kind.

**To close:** count the admitted wrapped extension files and their sites (BaseApp, DC; the census script plus an
object-kind column); if any have sites, add one wrapped `tableextension` (a `modify` field trigger and a procedure)
and one wrapped `pageextension` with unwrapped twins to `sandbox-wrapped`, pre-committed, as R-536 did; or close as a
ruling if none do.
