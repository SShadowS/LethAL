Found by coord R-898's re-run of R-883's 289 dependency-blocked BC.History apps, now with the BC 28.4 service folder as assembly probing paths (R900). An error only in the instrumented build is LethAL's. Evidence: `/coord/handoff/R-898/hunt/`. Related: [[R889]], [[R883]].

**A. The selector `var` landed between two codeunit properties** (Shopify Connector, `ShpfySuppressAsmWarning.Codeunit.al`: AL0104, AL0107).
- Invented repro: `codeunit 50102 R { Access = Internal; // a note` + `EventSubscriberInstance = Manual; procedure Go() ... }`.
- `injectSelectorVarIntoObject` anchored the `var` before the first member that is not a property, and a comment is a member. So the `var` sat before `EventSubscriberInstance`, which AL rejects.
- Fix: anchor at the first non-property member AFTER the last property. A comment after the properties keeps today's placement, before it.
- The same shape sits in 9 fixture test, probe and answer-key codeunits (`Subtype = Test;`, a comment, `TestPermissions = Disabled;`). No gate instruments those, so their old emission was never compiled. `instrumented-output-golden.json` moved by those 9 hashes only; the mutant counts and `reach-grain-golden.json` did not change.

**B. `toggle-blank-string` blanked a one-character literal compared with a Byte** (System Application Data Compression: AL0175 "Operator '=' cannot be applied to operands of type 'Byte' and 'Text'").
- Invented repro: `H: array[4] of Byte; if H[1] = 'P' then;` became `H[1] = ''`. A one-character literal can be a Char or a Byte; the empty string is Text.
- R731 refused only assignments to a Char, and said "a comparison compiles". That holds for Char, not for Byte.
- Fix: also refuse a one-character literal compared with a Byte, or with an element of a Byte array. A Char or Text comparison, and a longer literal, keep their mutant.

Tests: `compile.test.ts` (two cases) and `r731-char-blank.test.ts` (two cases), each red both ways.
