Found by coord task R-913 (Audit File Export on v3, 2026-11-11). Evidence: `/coord/handoff/R-913/afe.stderr.txt`. Related: R-422
(the same rewrite for `\`), [[R901]].

**What.** Microsoft's Audit File Export names `"logo": "ExtensionLogo.png"`; the file on disk is `extensionlogo.png`. Windows' alc
does not care. The Linux alc stops: `app.json(13,3): error AL1001: Source file 'ExtensionLogo.png' could not be found`. The run
ended in 2 s with no report. Of the corpus apps prepared for R-913, this was the only one; any project written on Windows can hit it.

**Fix.** R-422's rewrite of app.json paths in the copy LethAL compiles (never the user's own file) also fixes letter case: a `logo`,
`screenshots[i]` or `resourceFolders[i]` entry that does not exist as written, but matches exactly one entry case-insensitively
(segment by segment), gets the on-disk spelling, for the target batch and the test app. The `app-json-backslash-path` warning says
which kind of change was made. No match or two matches: left as written.
