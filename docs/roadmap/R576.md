**Filed 2026-10-10 by the R-571 build review** (`/coord/reviews/R-571-build/review-r1.md`, findings F3 and F4;
coord task R-571). Both are UNDER-refusals: a mutant that can hang is deployed. Each was measured by the
reviewer's scratch probe on the built branch.

**(a) The helper's body is not followed.** When a loop calls `Socket.Pop()` in another codeunit, and Pop calls
a procedure of its own codeunit (`Remove()`) that does the `Buf.Delete()`, [[R571]] refuses the call to
`Remove()` and the guard around it. The `Buf.Delete()` inside `Remove()` is still deployed. Deleting it leaves
the set non-empty, so the loop can run for ever.

The SAME-object hop has this gap too, and it is wider there (R-574 plan review, finding 2;
`/coord/reviews/R-574-plan/adversary-r1.md`). With a loop `while not Buf.IsEmpty() do Pop();` and a same-object
`Pop()` that guards with `if not Buf.FindLast() then exit;` and then calls `Remove()`, whose body does the
`Buf.Delete()`, nothing in Pop or Remove is refused: R531's same-object hop does not count a bare helper call as
a consumer, so it finds no consumer in Pop at all. Master has the same gap. [[R574]] (the same-object hop's
early exits) links here: its early-exit rule has nothing to anchor on in this shape until a helper call counts.

**(b) The codeunit's set is matched by global NAME only.** For a call on a codeunit variable that the loop
tests by name, R571 takes the callee codeunit's globals as the loop's set, by name. Two shapes slip through:
- the codeunit works on a REAL table, and Pop deletes through a local record of that table (`Q: Record Buf`),
  not through the global. The local is not matched, so its Delete is deployed;
- a local with the same name as a global shadows it, so the callee's consumers of that local are skipped,
  although the local can read the same real table.

Master has the same gap: before R571 none of these sites were refused at all.

**To close.** (a) Follow one more hop into the callee's own same-object helpers, with their consumers,
guards, early exits and feeds. (b) For a codeunit whose globals hold a real table, also count a local or
parameter record of that same table as the set. Measure the corpus price, per mutant, and say whether any
ordinal moves.
