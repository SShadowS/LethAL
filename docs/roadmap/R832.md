**Filed 2026-11-05 by lethal-bugs, from the "Also" section of SShadowS/LethAL#50.** Related: [[R829]].

**What.** A user who has to skip one operator must name all the others with `--operator`; the reporter named 22 to skip
`remove-assignment`. `--exclude-operator <name>` would make that one flag.

**Next.** A small CLI change. Decide what happens when both flags are given, and refuse an unknown name, as `--operator` does.

## Landed (R-832, 2026-11-06)

`--exclude-operator <name>` (repeatable, also on `--dry-run`) resolves to the operators left in, so the resume fingerprint, the report
and the `operator-narrowed` caveat treat it as that `--operator` scope.
- **Both flags:** refused, because which one wins would be a guess.
- **Unknown name:** refused, naming this flag.
- **An operator with no site here:** not refused. `--operator` refuses that because the run would measure nothing; leaving it out loses
  nothing.
- **Nothing left to run:** refused.

A report still prints its scope as `NARROWED (--operator)` with the full list of names left in: true, but long.
