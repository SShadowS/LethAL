**Filed 2026-10-23 by lethal-code during R-685**, from the plan r2 delta review (not blocking there: R-685 does not
widen it). A false "old" verdict in principle: the unsafe direction.

**What.** In `packages/runner/src/testpage-scan.ts`, `idOwner` and `foldIdTargets` (`foldObjects`, `foldCodeunit`)
compare a literal id by its text. A literal written with leading zeros, `Ext.Foo(01000)`, matches no object, so a
test that hands it to external code is neither folded nor put on the fallback. The platform would run object 1000.
`idRefsIn`'s rule for which literals it keeps (4 or more digits) also reads the text.

**Who hits it.** Not seen in any corpus; AL code writes ids without leading zeros. Reported by review, not measured.

**To close.** Parse a literal as a number before every id lookup (`idOwner`, `foldObjects`, `foldCodeunit`, the
`idRefsIn` length rule, `lowIds`), on both sides. A red test: `01000` handed out, where 1000 is a test-app codeunit,
folds it or falls back exactly as `1000` does.
