**`--resume` picked the most recent unfinished run even when it had recorded NOTHING.** `findResumableRun` selected on `finished_at IS NULL` alone, so an attempt that died before scoring a single mutant shadowed the older run holding real verdicts. Measured live 2026-07-27 recovering the DO sweep: a resume aborted at lease acquisition (R51), and the next `--resume` selected that empty run and reported `RESUMED: 0 verdict(s) carried`. Not silently wrong — the report says so, which is `resumedFrom` doing its job — but useless exactly when recovery matters, and an aborted run is precisely the kind most likely to have recorded nothing.
