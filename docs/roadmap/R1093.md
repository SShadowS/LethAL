Filed 2026-11-16 from PR-89 (lethal-code; spec `docs/superpowers/specs/2026-11-16-pr89-parallel-lanes-on-resume.md`), at the
orchestrator's request.

**What.** PR-89 lets a resumed run use N serve lanes, but the prefetch stays serial on lane 0. In t10 it took 2,270 s of the
mutant phase's 6,992 s (32%). It was kept serial because splitting it changes request packing (R987), and packing used to move
timeout verdicts (R1057).

**Why it may now be safe.** PR-51 (R1057) made the timeout class independent of covering order and packing: a held timeout is
replayed, and a later kill wins. What packing can still move is the killing test (R197's accepted class), and, under a time
budget or R948's memory gate, which mutants are scored before a stop.

**To measure, not assume.** A probe that prefetches per codeunit on N lanes, against today's serial prefetch, on the gift card,
D1 and a scoped DO slice with timeouts and kept refusals. Compare per mutant with `scripts/report-diff.ts`, and report the
prefetch wall time. Watch the memory: N daemons prefetching at once is N concurrent daemon peaks, sized through PR-89's cgroup
lane gate.

**To close.** A pre-committed proof that per-codeunit parallel prefetch leaves every verdict identical, then the change, or a
measured reason why it does not.

**Measured (coord PR-96, lethal-preproc, 2026-11-16; `/coord/handoff/PR-96/result.md`): GO, conditional.**
- **The prefetch blocks every lane.** `runMutantsParallel` prefetches each window whole on lane 0 before any lane scores it.
- **Its size:**
  - 33-45% of DO windows t9-t11 (4,888 / 2,270 / 5,117 s);
  - 72% of lethal-code's 4-lane scoped DO slice (`/coord/handoff/PR-89/m1/`: 1,670 of 2,603 s; only 1 of 4 lanes started).
- **Estimate at N = 3:** ~3,200 s saved on a t11-sized window, ~1,000 s on the slice. Memory caps N at 3.
- **Spec:** `docs/superpowers/specs/2026-11-16-pr96-split-prefetch.md`. Its spec-adversary review r1 is recorded in §0:
  - non-zero proof floors;
  - lane-scoped backend state;
  - a barrier until lane 0's warm-up decides serve;
  - PR-94's per-request flag as a cross-entry state;
  - PR-89's cgroup gate as a prerequisite.
- **Order:** PR-94 first, then PR-89's gate, then r2 of the spec, a pre-commitment and the build.
