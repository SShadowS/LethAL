**Found 2026-09-29 by the owner's question.** `MIN_CONTROL_VERSION` (`packages/runner/src/harness.ts`)
and `extensions/lethal-control/app.json` both say `1.0.0.20`, but CLAUDE.md's live-gate section says
"Control app 1.0.0.19 (GH-24) must be published to every gate container", and the autonomy
runbook states what a container "carries". Nothing checks any of it, and nothing checks that
`app.json` and `MIN_CONTROL_VERSION` agree.

**Fix (owner-approved 2026-09-29, including the CLAUDE.md and `.claude/skills` edits):**
1. One source of truth: a unit test pins `MIN_CONTROL_VERSION` equal to `app.json`'s version.
2. Docs name the source, never the current number ("the version in
   `extensions/lethal-control/app.json`"). HISTORY sentences stay ("only from 1.0.0.17"): they
   do not go stale.
3. A drift test scans CLAUDE.md, README.md, `docs/**/*.md`, `fixtures/README.md` and
   `.claude/skills/**` and fails when a sentence states a current control version as a literal.
4. What a container has INSTALLED is machine state, not repo state: docs point at
   `lethal doctor`, which reads it from the server.
