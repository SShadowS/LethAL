Found while writing PR-70's CI templates (review of 2026-11-16).

**What.**
- `lethal export --help` says "Render the JSON to HTML with 'npx mutation-testing-elements'", and the export's console text
  says the same.
- `npm view mutation-testing-elements bin` (version 3.9.0) shows no `bin`: it is a web-component library, not a command. So
  the advice does not work as written.
- `--help` also says Azure DevOps' PublishMutationReport task reads the interchange schema. The Stryker extension's task
  publishes an HTML report.

**Effect.** In CI, the exported JSON can be kept as an artifact, but not shown as an Azure DevOps build tab or opened as a page,
without an extra step LethAL does not document.

**Possible fix.** A documented way to get the HTML: either a tiny static page that loads the `mutation-testing-elements`
bundle and the JSON (the Stryker html reporter's shape), or an `--format html` that embeds the JSON in such a page. The latter
means shipping or downloading the bundle, which the export's doc comment avoids on purpose, so it needs a decision. In any case,
correct the `--help` and console text.

**To close.** The help text matches what works, and the templates show the report in Azure DevOps.
