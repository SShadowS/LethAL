**Priority.** Filed 2026-10-09 by the R534 build (plan r2, roadmap item 2). A lost kill, never a
false one.

**What.** On `--server` a timeout ends al-runner's suite run, so a test al-runner runs after the
hung one has no row. Since [[R534]] (D4) such a covering test is `runner-test-error` (not re-sent,
no session abort). But LethAL orders a mutant's covering tests itself (R197), and al-runner orders
the suite its own way: when the hung test is ALSO one of this mutant's covering tests, ordered later
by LethAL, the mutant's verdict is already decided by that hang. LethAL could skip ahead to the hung
test and score it, instead of stopping at the first missing row.

**Evidence.** `runViaServer`'s no-row branch in `packages/runner/src/al-runner-backend.ts`;
`/coord/handoff/R-534/measure.md` finding 7; test T6 in `al-runner-backend.test.ts`.

**To close.** When the suite has a `hungTest` and it is in the mutant's covering set, score that
test's row (a timeout, confirmed as usual) rather than the missing one. A session-level test with
two covering tests in the opposite orders, red-checked.
