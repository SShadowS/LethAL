**Found during R307 option (3), the throw-site analysis (2026-10-03). Found by reading the code, not
yet measured on a real file.** Evidence: `/coord/handoff/R-307/option3-throw-sites.md` §"Grain filter
dropped on purpose", and `option3-plan-split-analysis.md` (c1).

The four latch refusals in `injectReachLatches` (`packages/schemata/src/compile.ts`, C1 to C4: the
latch-owner refusal and the three no-anchor refusals) run only for a component that has a
`statement`-grain member (the grain test at the top of `injectReachLatches`'s component loop). Grain comes from `reachGrainOf`, and it depends on which mutants are in the
component: a member is `statement` grain when its resolved statement IS the component root.

R-307's per-file trial runs `instrumentOneFile` once per file, on the full set of that file's
mutants. But the writer later runs it on BATCH SUBSETS (`narrowFilesToSubset` in
`packages/runner/src/orchestrator.ts`, and bisection). With fewer mutants, components differ, so a
member that was `enclosing` grain in the trial can be `statement` grain in a subset. Then a C1-C4
check that the trial never ran can refuse the file at WRITE time, after the dry run reported the
file as fine. Every other refusal site is monotone in the mutant set, so a full-set check covers
every subset; these four are the exception.

Real AL probably never reaches C1-C4 (every statement sits in a member body, and C2/C3 are commented
as unreachable because `placeReach` marks such members `unplaced`). So this is a gap in the proof,
not a measured failure.

**Ruling (orchestrator, 2026-10-03).** Under R307's PLAN/EMIT split, C1-C4 stay in PLAN, so EMIT
still cannot refuse. The subset gap itself is NOT closed by that split and is filed here.

**To close.** Either check C1-C4 without the grain gate (for the owner of every spec's enclosing
statement, which is a superset of every subset), or prove and pin by test that grain cannot move
from `enclosing` to `statement` under narrowing for any AL the parser accepts. Red-check the test
against a subset that flips a member's grain.
