**What happens.** al-runner predefines the symbols `CLEANSCHEMA1` to `CLEANSCHEMA25`, and alc does not. R214 evaluates arms the way alc does, so on al-runner a `#if not CLEANSCHEMA<n>` arm (n up to 25; 35 occurrences in BaseApp) is still generated as a mutant and then compiled out by al-runner.

**Not measured yet.** Measure against the current al-runner first (needs the al-runner go-ahead). If it holds, the effective symbol set for an al-runner run needs those 25 names.
