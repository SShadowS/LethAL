Found by coord task R-913 (PEPPOL on v3, 2026-11-11). Evidence: `/coord/handoff/R-913/peppol.report.json` (`notInstrumented`),
`dry-peppol.txt`. Related: [[R005]] (the report states what was skipped).

**What.** LethAL injects its selector variable only into object kinds that can carry it (codeunit, table, page, report and their
extensions). An XMLport is skipped whole, with its triggers and procedures, and the report says so (`NOT INSTRUMENTED`, R005).
PEPPOL builds its documents in two XMLports:
- `src/Sales/XmlPorts/SalesInvoicePEPPOL30.XmlPort.al`: 552 sites;
- `src/Sales/XmlPorts/SalesCrMemoPEPPOL30.XmlPort.al`: 560 sites.
That is 1,112 of the app's 2,567 sites (43%), more than any one codeunit. The mutated 1,400 come from the other 34 files. A
document-export app keeps much of its logic in XMLport triggers (`OnBeforePassVariable`, `OnAfterGetRecord` and the like).

**To find out.** Whether an XMLport can declare the guard's global variable and procedure as a codeunit does (XMLports have `var`
sections, procedures and triggers), on alc and on al-runner v3; then instrument it, measured on PEPPOL. Until then the report states
the gap, as now.

**Fixed (coord R-919, 2026-11-11).** `xmlport` is a selector carrier. Measured:
- an invented XMLport project (`/coord/handoff/R-919/xp/`): 20 mutants, 18 in the XMLport; control and instrumented builds both
  compile with 0 errors on alc;
- PEPPOL dry run (`dry-peppol-r919.txt`): 40 more mutants deploy (1,440, was 1,400). The other 1,072 XMLport sites are now
  hang-refused by R500's rule for an open `Integer` table element, which was dormant while XMLports could not carry. That is an
  over-refusal, filed as its own item (see R928);
- PEPPOL instrumented compile (`peppol-r315/summary.json`): 1,495 specs, 0 errors;
- PEPPOL's XMLport mutants on v3 (`peppol-xp.report.json`): 40 mutants, 17 killed, 19 survived, 4 no-coverage. They run and are
  covered.
An `#if`-wrapped XMLport is refused on BC by name (`bcWrappedShapeRefusal`) until a gate measures one. `query` is now the only code
kind that cannot carry the selector.
