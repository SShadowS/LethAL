**Filed 2026-10-08 by the [[R500]] build** (plan r3 `/coord/reviews/R-500-plan/plan.r3.md`, adversary r2 finding 4e).
A plausible hang that is NOT refused.

**What.** R500 keys a raised event as `<publisher kind>|<publisher name>|<event>`. An event published inside a
tableextension is keyed with the kind `tableextension` and the extension's name, while its subscribers name
`ObjectType::Table` and the base table, so the two never meet and those subscribers are not refused when open
report-item code raises the event through a record.

## Closed by ruling

R-522 measurement, 2026-10-23 (`/coord/handoff/R-522/measure.md`, section R528): 0 rows in BC.History, CDO, DC and
DO. No open report-item code raises an event published by a tableextension. Stated limit: a project that does so
later is not refused.

**To close (original plan, closed by the ruling above).** Key a tableextension's publishers by the base table, measure, and land it or close it with a ruling.
