**Filed 2026-10-22 by lethal-orchestrator** (owner asked to stop the day's id collisions).
Related: [[R174]].

**What.** `scripts/roadmap-next-id.ts` already checks the working tree, every local and remote branch and every
worktree. But it reads the remote branches as this clone last fetched them. A lane that pushed a new row since
then is invisible, and the script prints its id as free.

**What happened.** On 2026-10-22 two ids collided: R646, and R654. In the R654 case, code's branch had filed one
before master's. Both were taken without the script, but the script alone would also have missed a push it had
not fetched.

**To close.** Make the script run `git fetch --quiet` before it reads the branches. If the fetch fails, refuse
with a named error, rather than printing an id from stale refs; a `--no-fetch` flag can skip the fetch for
offline use, and says so in its output. Test both directions: a fetch failure refuses, and `--no-fetch` prints
its warning. Tests must not touch the network: inject the fetch.
