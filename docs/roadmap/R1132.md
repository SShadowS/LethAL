Coord task PR-179, 2026-11-18. Related: PR-122 (the advisory hook, owner ruling q-20261117T160215-30a6c3a9: advisory first,
count, then propose blocking).

**What happened.**
- A sonnet builder on PR-179 appended two test blocks to `scripts/heavy-slot-class.test.ts` and
  `scripts/pr60-gate-memory.test.ts` with `cat >> file <<EOF`. CLAUDE.md names that exact form as forbidden ("Edit files
  with the Edit and Write tools, never with an inline script").
- The content was intact (a quoted heredoc: template literals unexpanded, no stray lines; checked by lethal-preproc and
  by an Opus review).
- The builder reported the slip itself.

**What the hooks did.**
- `.claude/hooks/no-shell-edits.ts` blocks only `sed` with an in-place flag. That narrow scope is by design (2026-11-13).
- `.claude/hooks/shell-write-advisory.ts` (PR-122) warns and never blocks. It DID catch both writes: log lines 226-227 of
  `/coord/logs/shell-write-advisory.tsv`, 2026-11-18T21:18:33Z.
- **A defect in that log:** both targets are logged as `/work/lethal-wt/lane-preproc/<file>`. The command ran after a `cd`
  into `/work/lethal-wt/pr179/scripts/`, but the hook resolved the relative target against the session's start
  directory, not the command's own `cd`. So the week's counts by path prefix will misplace such writes.

**Proposal (for the owner, at the 2026-11-24 week review of the advisory).**
1. Block, with exit 2, a redirect or `tee` write whose resolved target is a tracked or source path inside a LethAL worktree
   (`*.ts`, `*.al`, `*.json`, `*.md` under `packages/`, `scripts/`, `fixtures/`, `docs/` or `extensions/`). Keep scratch
   places (`/tmp/claude-*`, `/coord/handoff/`) and logs free.
2. Resolve relative targets after a leading `cd <dir> &&` in the same command.
3. Until then, every builder brief states the Edit/Write-only rule explicitly, naming heredocs (orchestrator, 2026-11-18).

**To close.** The owner rules at the week review. If blocking: the hook change with tests (each form both ways), and the
path fix. If not: the ruling recorded here.
