**Low priority. Filed by R-302 run 003 (2026-09-29).** A measured under-generation, in the safe
direction. See [[R330]].

**What is lost.** [[R330]]'s trigger rule makes every name a trigger declares in its own header
unknown to type resolution, so it never takes a global's type. Over all of `BC.History/BaseApp`,
that drops four `swap-additive` mutants in one `OnValidate` trigger of the Service Header table:
`ea7dc9fb05d7b12e86e3962b6dd8b43418865d40b84f10587ff974608eee0039|Service Header|OnValidate|lethal.swap-additive|1`,
and the same with `|1|1`, `|1|2` and `|1|3`.

They were valid. The trigger local and the table's global of the same name are both
`Record "Service Line"`, so the old typing was right by accident, and the swapped expression is a
legal `Decimal` subtraction. They are not in any committed corpus. The plan's addendum 2 pins them.

**Fix direction.** Type a trigger local by its own declaration, but only where that type equals the
global's. That restores these four sites and adds none elsewhere. Resolving trigger locals in
general would ADD sites, which is new scope and would need its own pre-commitment.

## Closed 2026-10-24: already fixed by R340 (coord task R-333, lethal-code)

[[R340]] (`done (e6c71f72)`, identity scheme 37) types a trigger's parameters, plain `var` locals and named return
by their OWN declaration, which is the general form this row called new scope; it still fails closed for a name in
a `#if` region of the header, a trigger that parses with an ERROR, and any name not parsed as a plain parameter,
local or return (`triggerLocalNames`, `triggerHeaderSymbols` in `packages/engine/src/semantic/symbol-table.ts`).
Measured in the cached BaseApp mutant dump for master c03d5356 (which contains e6c71f72):
`/coord/cache/dumps/c03d5356eaa47396a1bfce0d59f99f55d63af9a0/bch/874d934e7cc5c941/13.jsonl` holds all four keys, in
today's key format: `ea7dc9fb05d7b12e86e3962b6dd8b43418865d40b84f10587ff974608eee0039|Service Header|OnValidate|lethal.swap-additive|1|0|`
and the same with `|1|1|`, `|1|2|` and `|1|3|`. The narrower "only where the types equal" rule proposed above is
not built: it would now be a step back. Sizing: `/coord/handoff/R-333/r333-sizing.md`.
