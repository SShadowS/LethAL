**Found by the opus review of coord task R-327b (2026-10-24); not probed.** [[R720]] and [[R721]] showed that
`resolveVarRef` returns null both for a name that is provably undeclared and for one the engine refuses to resolve
("unknown"):
- a member swallowed into the global var section;
- a global declared inside a var-section `#if`;
- an every-arm-ambiguous name (R302).

R720 fixed `classifyHangCapable` by asking `declarationStateAt`, which tells the two apart. Other readers in
`packages/builtin-tier1/src/loop-hazard.ts` still read null as "absent", and their direction is unknown:

1. **The r531 write collectors** (`r531Implicit`, and the two collectors that push a write when `key === ""` or
   `recvs.has("")` and `resolveVarRef(left, ctx) === null`).
   - These take a bare unresolved name to be a field of the implicit `Rec`.
   - Where the name is really an "unknown" local or global, a write to it may be counted as a `Rec` field move, which
     can make a loop look like it advances.
   - Or, through the same mix-up, a real `Rec` move may be missed.
   - Which of the two can decline a hang refusal has not been worked out.
   - The R696 collector built on the same rule has the same question.
2. **R572's var-out flag** (`r572LoopRows`). An argument handed by `var` counts as a loop flag only when
   `resolveVarRef(a, ctx)` finds a declaration of a simple type. An "unknown" flag returns early, so the call is not
   recorded as feeding the loop. That is the decline direction: a loop fed by another object's stateful procedure
   through such a flag may not be refused.

**To close.** For each reader, build the three R720 shapes (scripts/fixtures/r402/w4/w5/w7 are the templates) with the
reader's own loop pattern. See whether a hang-capable site deploys. Where it does, use `declarationStateAt` the way
R720 did (an "unknown" name refuses, or counts by name), test-first, and red-check in each direction. R-327b's corpus
diff found 0 deployed changes for the `classifyHangCapable` fix, so the reach here is likely small, but it is
unmeasured.
