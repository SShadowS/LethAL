**Filed 2026-10-23 by lethal-code during R-685**, from its deep plan review (`/coord/handoff/R-685/review-plan.md`,
B1). A false "old" verdict: the unsafe direction.

**What.** When verify folds a test-app object into a test's digest (`foldObject` → `enterObject` in
`packages/runner/src/testpage-scan.ts`), it walks the object's triggers and its `part` pages, and nothing else. But
running or opening the object also runs code that is named only in its properties:
- a page's `SourceTable`: setting a field through a `TestPage` or a page handler fires the table's field
  `OnValidate`, and `OnInsert` / `OnModify`;
- an action's `RunObject` (a codeunit, page or report);
- a page's `CardPageId`;
- a table's `LookupPageId` and `DrillDownPageId` (BaseApp's Page Management opens them from a RecordRef);
- a report's request page `SourceTable`;
- an xmlport's `tableelement` tables (on import `FieldValidate` defaults to Yes, so field `OnValidate` runs).

**Measured offline** (probes `/coord/handoff/R-685/probe/probe.ts`, `p2.ts`, on master c7686f12; invented objects):
- a test with `TestPage "PP"` that calls `OpenEdit` and `SetValue`: an edit of PP's SourceTable `OnValidate`, or of
  the `OnRun` of PP's action `RunObject` codeunit, moves no digest, and the test is not on the fallback;
- R684's stored-reference fold (`Id := Page::PP`): the same;
- `Id := Database::TT`: an edit of TT's `LookupPageId` page moves no digest.

**Who hits it.** Every test that opens a test-app page (R-371's TestPage cases) or runs a test-app object by id, when
the code it changes sits behind one of those properties. A first count: 81 files under test paths in BC.History carry
one of the properties at all; how many name a TEST-APP target is not counted yet.

**To close.** In `enterObject`, for each unit entered, also fold every test-app object named in those properties
(pages and tables with `foldObject`, a codeunit whole); a name the test app does not declare goes through
`outside()`, as parts do. This only widens digests. Red tests: each property's target edit moves the digest. Being
built in R-685 (orchestrator's ruling pending), because R-685's narrowing would otherwise carry the hole further.
