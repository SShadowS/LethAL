**Filed 2026-10-25 by lethal-spare (coord task R-771).** Evidence: leg N1E's line in
`/work/tools/al-runner-v3/held/edge-a157b2d34/receipt.json`; [R771](R771.md) pins it.

**What is true today.**
- On edge `al-runner 3.0.0-alpha.5+edge.20261025 (a157b2d34)` the serve row for a dotted test method now carries
  `"codeunit":78850` and `"method":"Dot.Step"` beside `"name":"Codeunit78850.Dot.Step"` (upstream #5798 fixed).
- LethAL's `serveRow` (`packages/runner/src/al-runner-v3-entries.ts`, around line 206) still takes the codeunit and
  the method from the NAME, with `/^Codeunit(\d+)\.([^.]+)$/`. A dotted method can never match, so the row is
  refused as "a test line without v3's row shape" and the session fails closed by name. That is safe (no row is
  scored), and R771 pins it.
- R722 refuses an explicit `"transport": "serve-entries"` for a project with a dotted test method name before any test
  runs, and R761's default falls back to one-shot for it. So such projects never get serve mode, on any build.

**The opportunity.** On a build whose pin records #5798 as fixed, `serveRow` could take `codeunit` and `method` from
the row's own fields: require both, and require `name` to equal `Codeunit<codeunit>.<method>`. Then R722's refusal and
R761's fallback could be lifted for that build only, keyed by the pin as `sleepRuleRetiredFor` is.

**Before building.**
1. Measure on the pinned build that every N1 name shape (R763's set plus the dot) comes back with both fields and
   matches its one-shot row.
2. Pre-commit N1E's new pass reading.
3. Keep the name-only rule for every other build.

A dotted method that one-shot cannot select either (#5572) is out of scope.

**What was built (coord task R-782, unit work; the live N1E run is still to do).** The pin of a157b2d34 lost its
`n1e` entry and gained `serveRowFields: { issue, evidence }`; `serveRowFieldsFor(version, sha256)` finds it, as
`sleepRuleRetiredFor` finds its flag. `status()` (and `decideTransport`) set the backend's switch from it.
`serveRow(line, fields)` and `decodeEntriesAnswer(sent, answer, fields)` take `codeunit` and `method` from the row on a
flagged build: both are required, and `name` must equal `Codeunit<codeunit>.<method>`, else the request is refused by
name. Other builds keep the name parse. On a flagged build R722's `AlRunnerV3ServeDottedTestNameError` is not thrown,
and R761's default no longer falls back for an inner dot (a leading, trailing or doubled dot still does). Leg N1E on a
flagged build must complete, 36/0/0 over 36, per mutant equal to `bcdev.names.baseline.json`, 0 echo mismatches
(`judgeN1Serve` takes a `flagged` flag; the `n1e.refusedLine` path is gone). Figures that move: `/coord/handoff/R-782/moves.md`.
