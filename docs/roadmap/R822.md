**Filed 2026-11-05 by lethal-code, at the owner's request.** Related: [[R789]].

**What happened.** On R-819's head, a full v3 gate read `C=infra-fail` with the other 17 legs passing
(`/coord/handoff/R-819/v3/gate.log`). `timeout-is-cpu` read `unmeasurable`: "A late: core 13 contended, cpu 2106 of wall
3669 ms, B not run". The load average was above 100, from other lanes' corpus jobs.

**The build was fine, and so was the rule.** A used 2106 ms of CPU for a 2 s limit, as a CPU-time stop should. R789 made a
late A read `unmeasurable` on purpose, so that a loaded machine cannot blacklist a correct build. That still holds.

**What is left.** R789 chooses the least busy core once, just before A, and one late A ends the fact. So a moment of
contention, on a machine that is meant to run heavy jobs side by side, costs a gate of about 7 minutes and a wait for a quieter
machine. A full-gate re-run is the only recovery today.

**Proposed (built, see Fixed).** When A is late, pick the least busy core again and retry the fact, a small fixed number of
times, inside leg C. Each try takes seconds. Only when every try is late does the fact read `unmeasurable`.

**To close.**
- The judgement must not change: a wall-time build still reads `diverged`, loaded or not, and a late A never reads `matches`.
- A retry can only turn `unmeasurable` into a real reading. It must never retry a `diverged`.
- This changes how a gate fact is measured, so pre-commit the rule first, as R789 did.
- Red tests each way, and proof on a loaded and a quiet machine.

**Fixed (2026-11-05).** A contended A now re-runs on a core picked afresh, at most three runs of A in all. The rule and its
addendum are in `docs/superpowers/specs/2026-11-05-r822-timeout-is-cpu-retry-precommitment.md`.
- Not contended: the full v3 gate passed on all 18 legs at head 9ef710a4 with one run of A, `/coord/handoff/R-822/v3/gate.log`.
- Loaded: leg C alone, confined to two cores, with three busy loops on each during A's first try only. It read `matches`,
  with `earlier tries of A: core 20 contended, cpu 2118 of wall 8853 ms`, `/coord/handoff/R-822/v3/legC-loaded.log`.
- Not measured live: a wall-time build under load, or three contended tries in a row. Unit tests cover both.
