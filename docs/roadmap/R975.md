Found by lethal-code, 2026-11-13 (coord R-942, Continia DO x its Test app on al-runner v3, one-shot, isolation test; reports
`/coord/handoff/R-942/dod.w2.report.json`, store `dod.sqlite`; parse sample `/coord/handoff/R-942/survivor-sample.md`). Related: [[R029]],
[[R063]], [[R140]], [[R175]].

**What happened.** DO scored 215 mutants: 11 killed, 204 survived (95%). Every one of the 215 carries `coverageAttribution: "object"`:
`selection.ts`'s FALLBACK 1 (a trigger whose member-level key misses takes every test that touched its OBJECT, R29) credited each
trigger mutant with the tests that merely opened its page. A parse sample of 15 survivors: 10 are statements no covering test executes
(OnAction and OnAssistEdit triggers of pages the 6 covering tests only `OpenView` and check `Visible()` on; OnAfterGetRecord on tables
with no rows), 3 real weak-test survivors, 2 equivalent in the covered path. Across the 204: 90 in OnAction, 4 in OnAssistEdit (never
invoked), 18 OnAfterGetRecord (likely never fired). So "survived" stands where the truth is "no-coverage", and DO's survivor list is
mostly unexecuted code. Not a false kill (a mutant never killed by an unexecuted statement), but a wrong verdict class that hides what
the tests do not reach. No refused or red test was counted (all 1,422 per-mutant test rows of the survivors pass).

**Why the fallback exists.** On bcdev a trigger's member-level key can never hit (R29), so without it every trigger mutant would read
`no-coverage`; over-running costs time, under-running hides bugs. On al-runner v3 the per-test coverage is LINE-level
(`granularity: "line"`, as `baselineReachOf` R-917 uses), so whether the mutated line ran in each test is known.

**Wanted.** On a backend with per-test line coverage, decide a trigger mutant's covering tests by its own line (the R-917/R926 reach
data), not by the object fallback; keep FALLBACK 1 for backends without line coverage. Prove per mutant on a fixture with page actions
that no test invokes (expect `no-coverage`, was `survived`) and on DO's 215; the v3 gate's figures may move (pre-commit). Unverified so
far: whether al-runner fires a part's OnAfterGetRecord/OnAfterGetCurrRecord on an empty table.
