**Filed 2026-10-11 by R-394** (`/coord/handoff/R-394/measure.md` §1).

**What.** `wrapperHoldsObject` counts a `pragma` line inside a `#if` block as an object: `NOT_AN_OBJECT` does not
list `pragma`, while `isTopLevelObject` excludes it. In BC.History's Power BI Report embeddings app, 21 files have a
`#if` block holding only `#pragma` lines, with the real object AFTER the block. The "bare object beside the wrapper"
rule then refuses each file as a wrapped shape, and al-runner coverage is turned OFF for that whole project. No
mutant sits inside those `#if` blocks.

**To close.** Make `wrapperHoldsObject` agree with `isTopLevelObject` about `pragma` (and check other trivia kinds
the same way). Add a test with a pragma-only wrapper. Re-measure which BC.History projects keep coverage on.

**Since R654 (2026-10-23).** The .NET al-runner's coverage guard was deleted in R654 S3 (35f3c67f).
`wrapperHoldsObject` is unchanged and still feeds `alRunnerCoverageSupport`, which turns the Rust al-runner's coverage
off (`al-runner-v3-coverage-off`). So the 21 Power BI files now turn coverage off on `al-runner-v3`. As with [[R580]],
v3 also refuses every multi-object file and every wrapped file ([[R602]]), so re-measure the affected projects under
v3's rule.

## Done by R-579

`wrapperHoldsObject` now treats `pragma` as trivia (it is in `NOT_AN_OBJECT`), so it agrees with `isTopLevelObject`:
a `#if` holding only pragma, namespace, using or comment lines is no object wrapper. Result (post-build census,
`BC.History.json`): 3 of 258 BC.History source projects are off (Base Application, E-Document Core, EU 3-Party Trade
Purchase, all code-bearing), down from 14, together with [[R580]]. CDO, DC and DO were 0 before and after.
