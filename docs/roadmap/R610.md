**Closed 2026-10-23 by coord task R-435, by measurement, with a stated limit.** Probe (invented app, ids
50910-50915, probes in `/coord/handoff/R-435/probe/dyn/`) on alpha.2 (91253f2d6) and edge alpha.4 (57f1e4f98),
also with `--codeunit` set. A test reached each file only through a dynamic call, and `--coverage-json` listed the
file with hits, in the top-level coverage and in that test's per-test coverage:
- `Codeunit.Run(<variable id>)`: the target's `OnRun` lines, hits 1;
- an interface call: the implementation's procedure, hits 1;
- an event subscriber in a separate file: its handler, hits 1.

So the Sleep rule's reading of an unlisted file as "nothing ran" holds for these three shapes.

**Limit (not measured).** A large project (the Q23 CDO call listed 478 of 658 files, so listing is by reach);
the serve-entries transport; an interface implementation chosen through an enum; code in a dependency app reached
dynamically. Open a new item if one of them shows an executed file that is not listed.

Original item:

**Found 2026-10-21** by the Opus build review of [[R586]] (`/coord/handoff/R-586/review-build-opus.md`, Minor 12).

**What.** v3's top-level `coverage` lists the files in the CALLED codeunit's reach, not every compiled file
(measured: `contract-alpha2/cov.json` for `--codeunit 50652` lists 3 of the probe's 10 compiled files; the Q23
CDO call lists 478 of the 658 compiled `.al` files, unreached files included with every statement at 0 hits). The §6
Sleep rule reads a file v3 does not list as "nothing on it ran". That holds for the static reach. It is
UNMEASURED for code reached outside it:
- `Codeunit.Run(<a variable id>)`;
- an event subscriber in a file the called codeunit does not name;
- an interface implementation chosen at run time.

§6 case 4 covers a hit that is listed but owned by no test; it does not cover a file that is executed and never
listed.

**Effect.** If v3 omits such a file, a covered Sleep in it is read as "not reached" and the pass is scored: a
false survive on exactly the shape (a Sleep-retry loop behind a dynamic call) the rule exists for.

**To close.** One probe per shape: a test reaching a `Sleep` only through each dynamic call, with the file's
listing and per-test hits recorded. Then either the rule holds as written, or an unlisted project file with a
Sleep line is treated as case 2 (fail closed). Pre-commit the expected listing first.
