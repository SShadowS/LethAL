**Filed 2026-10-24 by lethal-preproc during R-741.** Related: [[R741]].

**What.** The header comment of `fixtures/sandbox-data/src/DataMainListExt.PageExt.al` says "a pageextension's
procedures are not callable from a test codeunit — nothing outside the page can name them", and gives that as the
reason the fixture's work happens in `OnOpenPage`. R-741's probe measured the opposite on bc2 (BC 28.4 W1): its test
`TestPageOther` called `PageOther` on a `Page "R741 Base Card"` variable, through the target's pageextension, and
passed (`/coord/handoff/R-741/measure.md`). `fixtures/sandbox-wrapped`'s tests also call a pageextension procedure.

**Why it matters.** The comment is wrong, not the fixture: the fixture still measures a trigger reached through a
`TestPage`, which is a valid thing to measure. But a reader who trusts the comment would wrongly believe a
pageextension procedure is unreachable from tests, and could misjudge a `no-coverage` reading.

**To close.** Correct the comment without moving any line the tables gate's figures rest on. Then run
`bun run compile:fixtures` and the tables gate (`itest:tables`), since the file is that gate's fixture.
