Three executable, statement-position candidates with measured populations (658-file Document
Output snapshot, 2026-08-12), listed so the next Tier-2 phase starts from numbers, not names:

1. **`FindFirst` <-> `FindLast` swap** — 236 + 42 sites. The classic wrong-record bug (first vs
   last entry of a filtered set). Kill path: any test asserting WHICH row was processed; needs at
   least two rows in the filtered set, the same decoy-row discipline the tables fixture already
   uses. Watch: return-value consumed vs bare-call forms are both real; the swap preserves both.

2. **`Rec.Validate(F, V)` -> `Rec.F := V`** — <=179 sites (census counts all `Validate(` calls;
   the single-argument form `Validate(F)` has no assignment equivalent and is refused). This
   mutant deletes the OnValidate trigger chain, a BC-specific bug class nothing else models.
   The tables fixture already proves OnValidate coverage kills trigger mutants (R30/R70 arms), so
   the kill path is established. Watch: field name may be quoted; receiver must be a proven
   record (`claimsRecordMethod` precedent).

3. **Extend `swap-modify-flag` to `Insert(true/false)` and `Delete(true/false)`** — today it
   covers `Modify` only (43 `Modify(true)` sites); `Insert(true)` 91, `Delete(true)` 86. Same
   operator shape, same hazards already documented in `swap-modify-flag` (bare-branch sites are
   in scope because the after-form is a rewrite, not a deletion). Cheapest of the three; probably
   a version bump of the existing operator rather than a new one — which moves operatorMajor and
   therefore baselines, so it rides the same per-site re-record procedure as a grammar bump.

Explicitly NOT candidates, with the reason recorded: `Next()` arithmetic mutation (its natural
mutants are non-terminating loops, the M0013 hang class — `itest:hang` exists because of it, and
an operator that mostly produces hangs spends 180 s per verdict to say little); `IsEmpty`/`Find`
negation inside conditions (already covered by `negate-conditional` on the enclosing comparison);
`remove-setfilter` (see R134's refusal).
