**LethAL's mechanism is a runtime guard wrapped around executable code, and a property cannot
dispatch at runtime.** `isMutableSite` therefore drops every declarative site, correctly. That
leaves whole BC bug classes unreachable no matter how many operators ship:

- **FlowField `CalcFormula`** — the `where(field/const/filter)` conditions and the
  sum/count/lookup method ARE business logic; a wrong filter in a CalcFormula is a classic silent
  bug. 91 CalcFormula lines in the 658-file Document Output snapshot. (`remove-calcfields` mutates
  the executable `CalcFields(...)` CALL today; the formula itself is untouchable.)
- **Query objects** — dataitem links, filters, method columns. **Zero query objects in the DO
  corpus** (2026-08-12 census), so this surface has no measured population yet; census a corpus
  that has them (BC.History) before ranking it.
- **Filter-bearing properties** — `DataItemTableFilter`, `SourceTableView`,
  `RunPageLink`/`SubPageLink`, `TableRelation` conditions.

Grammar 4.0.x removed the parsing blocker: single-entry links now parse as `link_value` with named
`where`/`field`/`const`/`upperlimit` markers (this repo measured that change during the 4.0.0
bump), so operators would have precise tree shapes to target. What is missing is deployment:

- **Option A — per-mutant artifact variants**: compile N artifacts, each with one declarative
  mutation applied in source. Publish cost is per MUTANT instead of per batch, which R45/R90
  measurements say is the expensive axis; a campaign's per-mutant cost jumps from ~433 ms to a
  full publish+sync each.
- **Option B — schema-neutral rewrites only**: restrict to mutations that keep table schema
  identical (a `where()` condition flip is schema-neutral; changing a CalcFormula method may not
  be) so ForceSync stays cheap. Still per-mutant publishes.
- **Option C — refuse the class permanently and say so in the report** (the R69 shape: measure
  the foregone population, name it, close by ruling).

The decision needs a measurement: per-mutant publish+sync cost on a container for a
one-property-changed artifact, times the surface's real population. Until then, no operator work
here — an operator spec against a nonexistent mechanism is the speculative-fix shape R11 refused.
