# Examples

Two small Business Central extensions, each with a green test suite that misses something real.

- [`gift-card`](gift-card/README.md): one planted bug in a balance calculation. The shortest path to seeing the point.
- [`credit-limit`](credit-limit/README.md): three gaps, and the only demo that shows `remove-calcfields`.

New to LethAL? Read [Your first week with LethAL](../docs/first-week.md). It walks setup, a run, reading the result, fixing a survivor and re-running, on the gift card.
